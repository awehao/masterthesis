## 兩兩比較

- **B − A**（預測式避障的貢獻）：碰撞 22 → 3，到達 28 → 28，間距中位 -0.300 → +0.180，最差 -0.514 → -0.300，到達時間 79 → 98 s
- **C − A**（純反應式保護的貢獻）：碰撞 22 → 2，到達 28 → 28，間距中位 -0.300 → +0.080，最差 -0.514 → -0.300，到達時間 79 → 88 s
- **D − B**（感知或 CBF 漏失時，shield 的補位）：碰撞 3 → 0，到達 28 → 28，間距中位 +0.180 → +0.150，最差 -0.300 → +0.022，到達時間 98 → 104 s
- **D − C**（CBF 對提前繞行與效率的貢獻）：碰撞 2 → 0，到達 28 → 28，間距中位 +0.080 → +0.150，最差 -0.300 → +0.022，到達時間 88 → 104 s

**這組要回答的**：shield 是否讓 CBF 變得多餘。若 C 單獨就與 D 相當，屏障就沒有
剩下需要辯護的功能；若 C 安全但繞行差、耗時長或卡住，則屏障買到的是**效率與
提前性**而非安全 —— 那是不同、也更誠實的宣稱。
