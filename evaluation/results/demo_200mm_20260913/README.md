## 1. 影片是怎麼來的

| 項目 | 事實 |
|---|---|
| 取像時機 | **這一趟真正執行的當下**，逐物理步取樣 |

| 取樣 | 每 3 個物理步（physics_dt 0.01 s）取一幀 ≈ 33.3 fps；涵蓋 sim 0.33–34.01 s |
| 對應表 | `frames_index.csv`：每一幀 ↔ **取像當下的模擬時間** |

**場景只加了光源**（headless 執行沒有光源，不加就全黑）。
**未改任何幾何、材質顏色、質量或物理參數**，也未做任何顯示著色 ——
畫面中抽屜與櫃體同為灰色，就是模型本來的樣子。

**保護條件不受錄影影響**：30 N / 連續 0.05 s（`v2_sustained`）與 92 °C 熱中止線
照常運作，監看在錄影之外獨立執行。錄影只讀場景、不寫回任何狀態。

**已知限制**：RTX 標註器有數幀延遲，畫面相對物理步可能有固定的小延遲。
`frames_index.csv` 記的是取像當下的模擬時間，不保證畫面內容與該時刻零延遲對應。

**代價**：算繪佔用了 RTF 節流的餘裕，本趟牆鐘比即時慢
（模擬時間語意不變，播放端以 `/clock` 配速）。

## 3. 這是什麼操作

**固定底座 ＋ 理想固定連接**。

抽屜**不接收任何位置或速度命令**（滑動關節的 drive stiffness / damping / maxForce /
target 全為 0），開度由手臂經**理想固定連接**帶動。
**這不是摩擦夾持** —— 摩擦夾持是另一個未驗證的版本，兩者分版記錄，不混稱。

底盤由匯入器的固定關節外部支撐。**不代表輪子靠地面摩擦能承受相同負載**，
移動底盤的操作要另外驗證。

## 4. 實測結果（趟次 `drawer_070142_ffattach200_rec`）

| 相位 | 樣本 | sim 時間 s | 開度 起→末 mm | \|F\| max N |
|---|---|---|---|---|
| engage | 200 | 10.98–12.98 | 0.000 → 0.000 | 6.67 |
| postengage | 99 | 12.99–13.97 | 0.000 → −0.001 | **12.08** |
| **pull** | 834 | 13.98–22.31 | −0.001 → **198.412** | 11.59 |
| **hold** | 201 | 22.32–24.32 | 198.442 → 198.731 | 6.25 |
| release | 99 | 24.33–25.32 | 198.730 → 198.730 | 5.78 |
| retreat | 111 | 25.33–26.43 | 198.730 → 198.730 | 5.77 |
| settle | 758 | 26.44–34.01 | 198.730 → 198.730 | 5.75 |

* **最終開度 198.730 mm，誤差 −1.270 mm**
* **`arrived_sim_t = 23.700 s`，早於 release（24.330 s）0.630 s** ——
  到位是在固定連接仍在時達成的**受控到達**，不是解除後的滑行
* 解除連接後開度未再變化（release → settle 全為 198.730 mm）
* **超過 30 N 的樣本 0 / 3367**；力峰值 12.08 N 出現在 postengage，不在拉開段
* 1209/1209 命令套用、0 拒收；監看無失效（`monitor_failure: null`）
* CPU 溫度 起 77.88 / 峰 **79.25** °C（中止線 92 °C，未觸發、未調整）
* `diagnostic.is_diagnostic = false` ⇒ 計為正式操作成果

**停止原因 `sim_limit` 是程序停止原因，不是任務成功的判準。**
任務完成的依據是 `arrived_sim_t` 與上表的逐相位證據。

## 5. 這趟沒有證明什麼

* **只跑一趟，未重複。**
* 這是**第二趟**達成 200 mm（第一趟 `drawer_065343_ffattach200` 未錄影，
  最終開度 198.731 mm、`arrived_sim_t` 26.700 s）。兩趟結果相近，
  但兩趟之間程式 sha 不同，不是嚴格的重複試驗。
* 前饋補償 b(s) 取自無連接試驗；成功**不等於**已辨識出那個 0.26 N/mm 負載的物理來源。
* 補償的適用條件是「同模型、固定底座、同路徑與配時、同增益」，
  **是本案例的致動校準，不是通用方法**。
* 離線幾何檢查中對環境餘裕為 6.17 mm（門檻 5 mm），是目前最薄的一項。

完整的四步歷程（校準 → 補償 → 無連接驗證 → 有連接操作）見
`evaluation/results/drawer_fixed_stage_20260912.md` §83–§89。
