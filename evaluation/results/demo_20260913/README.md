## 1. 影片怎麼產生的 —— 先講清楚它「不是」什麼

| 項目 | 事實 |
|---|---|
| 影像來源 | `isaacsim.sensors.camera.Camera.get_rgba()`，模擬器內的相機感測器 |
| **不是** | 桌面／視窗擷取。全程未使用任何螢幕錄製 |
| 產生方式 | **已錄狀態回放**：載入同一場景，逐幀把該趟 log 的關節角與抽屜開度**設定**回場景後取像 |
| **不是** | 重新模擬。回放不產生新的量測值，也未改動原始趟次資料 |
| 程式 | `evaluation/render_demo.py`（新增，只讀 log）＋ `evaluation/annotate_demo.py`（疊字與編碼） |
| 已驗證程式 | `isaac_drawer_sim.py`、`gen_drawer_traj.py`、`isaac_manip_sim.py` **未修改** |

回放忠實度（每幀設定後讀回，逐幀記錄於 `replay_check_*.csv`）：

| 影片 | 關節最大差 | 抽屜開度最大差 | CPU 峰值 |
|---|---|---|---|
| 抽屜 廣角 | 0.194 mrad | 0.00048 mm | 83.1 °C |
| 抽屜 近景 | 0.194 mrad | 0.00048 mm | 76.4 °C |
| 預抓取 | 0.065 mrad | — | 76.5 °C |

中止線 92 °C 未調整、未觸發。

顯示用著色（櫃體／抽屜／把手／目標方塊分色）**只改 displayColor**，未改幾何、質量或任何物理參數；
預設材質下櫃體與抽屜同為灰色，20 mm 行程在畫面上讀不出來，所以分色。

**算繪管線延遲**：RTX 標註器會落後數幀，每幀只算繪一次會取到前面幀的畫面
（初版就踩到：影像顯示夾爪不在把手上，但 USD 讀回的 `link_tcp` 在把手上）。
現行版本每幀重複設定同一狀態並算繪 6 次再取像，姿態不變、只讓管線追上。
