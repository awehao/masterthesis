## 三、移植驗收表

按順序做，前一項不過不進下一項。

### 第 1 關：關節命令

| 檢查 | 判準 |
| --- | --- |
| 關節名稱與順序取自控制器本身 | 與上表逐一相符 |
| 單關節正向命令 | 實際位移方向與符號相符，量值在 5% 內 |
| 單關節反向命令 | 同上 |
| **關節能否離開限位** | 推到 `hi − 0.02` 後反向命令**必須能退出**（Gazebo 上觸限即卡死，見 §10.18） |
| 六軸同時命令 | 無串擾，非命令軸位移 < 10 mrad |
| `/joint_states` 頻率與間隔 | 記錄 p50／p95／max，作為 `max_data_age` 的依據（Gazebo 的 0.5 s 不可沿用） |

### 第 2 關：底盤命令

| 檢查 | 判準 |
| --- | --- |
| `/cmd_vel` 三分量方向 | vx／vy／ωz 的正負與實際運動相符 |
| 車體座標 vs 世界座標 | 轉接器的旋轉在非零 yaw 下仍正確 |
| 里程計來源 | 記錄是真值導出或輪速推算；**Gazebo 用真值，Isaac 若用推算則本測試涉及定位** |
| 底盤速度上限 | 實測是否受輪系限制；目前模型是盒約束（§11 已知限制） |
| **輪地接觸模型** | Isaac 若為真實輪地接觸，**打滑／牽引力首次進入迴路**，須另立測試 |

### 第 3 關：停止行為

| 檢查 | 判準 |
| --- | --- |
| 閘門逾時歸零 | 命令歸零時間、**實際停止時間、期間位移**三者分開量 |
| **停止距離** | **Gazebo 的 0.00 mm 不可沿用**（`VelocityControl` 直接寫速度、無減速動力學） |
| reason 7（距離過期） | 命令歸零、reason 正確、恢復後回復 |
| reason 8（帶截斷） | 命令全程為零 |
| JointState／TF／odom 分別停止 | 各自的歸零時間與 reason |
| 減速度是否受限 | 取樣率須足以分辨（Gazebo 上 143 Hz 無法分辨 19.98 rad/s²） |

### 第 4 關：同案例閉迴路

以凍結基線（B, μ = 0.03）重跑同一案例，逐項對照
`evaluation/results/baseline_B_frozen_20260909.md`：

| 量 | Gazebo 基線（3 次） |
| --- | --- |
| 完成 | 3 / 3 |
| 完成時間 | 12.134 ± 0.023 s |
| 位置終值 | 2.293 ± 0.008 mm |
| 末端姿態終值 | 0.055 ± 0.001° |
| 最小安全間距 | 88.816 ± 0.000 mm |
| 發布間隔 p50 / p95 / max | 50.0 / 52.6 / 61.8 ms |
| QP p50 / p95 / max | 2.1 / 6.1 / 16.0 ms |

**驗收判準不是「與 Gazebo 的差距」。** 上表的均值與標準差**僅供參考**——它只有三次測試，標準差
極小（位置 8 µm、間距 0.4 µm），換了物理引擎之後**合理的差異也很容易超過它**，拿它當異常門檻
會把正常的引擎差異判成故障。

實際驗收依下列三項：

| 驗收面 | 判準 |
| --- | --- |
| **任務容差** | 位置 < `tol_p` = 5 mm、姿態 < `tol_r` = 0.02 rad，並在 `settle_s` = 2 s 內維持 |
| **安全限制** | 屏障輸出違反 0；關節位置／速度／底盤速度違反 0；全程無接觸；最小間距為正且與場景幾何相符 |
| **介面／幾何一致性** | 第 1–3 關全部通過；模型 FK 與模擬器 TF 的差異在數值誤差量級；場景物件位姿與尺寸與 SDF／USD 來源逐項相符 |

三項都過即為通過。與 Gazebo 的數值差異只用來**引導查因**（差很多時先看介面與幾何，再看控制器
參數），不作為通過與否的門檻。

## 四、移植前必須知道的已知差異

- Gazebo 的輪與滾輪是**純視覺**，接地是四顆零摩擦球，底盤由 `VelocityControl` 直接驅動。
  Isaac 若用真實輪地接觸，這是**模型層的改變**，不是移植誤差。
- Gazebo 的 `/odom` 是真值導出，**本案例不涉定位**。
- Gazebo 上 `max_data_age = 0.5 s` 是依該模擬器的停頓分布量出來的（曾量到 332 ms 停頓），
  **必須在 Isaac 上重新量測**。
- 關節觸及 URDF 上限後無法退出，是 Gazebo 上的觀察，**底層原因未定位**；Isaac 上要重新確認，
  目前以 `joint_limit_margin = 0.02 rad` 迴避。

## 五、輪速多面體的必要性（由輪 Jacobian 先驗證，不必等打滑）

### 輪系實際構型

四輪**切向全向輪**，接頭皆為 `fixed`（模型中輪子不轉，是純視覺），由掛載 rpy 推出各輪的
滾動方向：

| 輪 | 位置 (m) | 自轉軸 | 滾動方向 | 接觸點線速度 |
| --- | --- | --- | --- | --- |
| `rim_a` | (+0.245, 0) | −x | +y | $s_a = v_y + 0.245\,\omega$ |
| `rim_b` | (0, +0.245) | −y | −x | $s_b = -v_x + 0.245\,\omega$ |
| `rim_c` | (−0.245, 0) | +x | −y | $s_c = -v_y + 0.245\,\omega$ |
| `rim_d` | (0, −0.245) | +y | +x | $s_d = v_x + 0.245\,\omega$ |

四輪皆切向、同手性（ω 項符號一致）。

### 盒約束的來源與其樂觀量

以 $|s_i| \le S$ 為單輪上限，反推目前 `SafetyConfig.vmax[:3]`：純平移時 $|s| = |v_x|$ 給出
$S = 0.2775$ m/s；純旋轉時 $|s| = 0.245\,|\omega|$ 給出 $\omega_{max} = S/0.245 = 1.1327$ rad/s
——**與現有盒約束的三個數字完全吻合**，證實盒是逐軸最大值。

真實可行集把四個 $|s_i| \le S$ 展開後為

$$|v_x| + 0.245\,|\omega| \le S \quad\text{且}\quad |v_y| + 0.245\,|\omega| \le S$$

**盒最多樂觀 2 倍**：$v_x = 0.2775$ 且 $\omega = 1.1327$ 在盒內，但需要
$|v_x| + 0.245|\omega| = 0.555 = 2S$ 的輪速。

**更正一項先前的錯誤說法。** 我曾說「盒允許 $v_x$ 與 $v_y$ 同時滿速，對角線上單輪速度約 1.41
倍超限」。**那是錯的**：那個論證適用於 45° 掛載的麥克納姆輪，不適用於本車的切向構型——切向輪
各只感受**一個**平移分量，$v_x = v_y = 0.2775, \omega = 0$ 時四輪皆恰好 $S$，**不超限**。
真正的樂觀來源是**平移與旋轉同時滿速**。

### 在實測基線上是否被觸發

以凍結基線（B, μ = 0.03）三次執行的 `cmd_out` 底盤分量（世界座標，依當下 yaw 轉為車體座標）
計算輪速使用率 $\max_i |s_i| / S$：

| 執行 | p50 | p95 | max | 超過 1.0 的週期 |
| --- | ---: | ---: | ---: | ---: |
| run1 | 0.155 | 0.613 | **0.624** | 0 / 244 |
| run2 | 0.155 | 0.614 | **0.625** | 0 / 244 |
| run3 | 0.154 | 0.613 | **0.628** | 0 / 243 |

**必要性成立於原理（最壞 2 倍），但在本批實測中從未被觸發**（峰值 0.63）。兩件事都要講：不能
因為沒觸發就說多面體不必要，也不能拿這批資料宣稱曾經違反過輪速。

### 對輪地接觸階段的意涵

依既定拆解：**先在兩種限制共同允許的命令範圍內比較致動差異**（即使用率 ≤ 1 的區域，本批資料
全部落在其中），**再單獨比較盒與多面體**。後者不需要打滑現象才成立——上面的 Jacobian 已經給出
2 倍的樂觀上界。
