# K3-M 正常受控暫停／減速保持（小規格 draft-1；純離線核對，未實作、不開模擬）

依 Codex 20261023_221949 第 3 節：先做「正常受控暫停／減速保持」，**不先做故障後跟隨**；原安全閂鎖全部保留。

## 1. 範圍
- **只限健康狀態下的預定暫停**。觸發當輪與暫停全程都必須滿足：
  - 量測新鮮；求解成功；
  - 兩指橫桿接觸都 ≥ 0.5 N；
  - 走廊內側帶、實測幾何監看、門角與門速監看都通過。
- **不納入**：finger_contact_lost、已越界、門速超限，以及其他任何中止。這些仍走既有 K2 閂鎖（命令立即過期、凍結），不歸為可繼續跟隨的事件。
- **預定暫停點**：
  - P1＝開門完成（q_ref 到 8° 且 SETTLE 條件滿足 1 s）後，取代現行「END_HOLD 3 s → DONE 停求解器」；
  - P2＝開門中途的預定暫停，只作離線驗證，是否納入實跑另議。

## 2. 控制律（明確定義）
- **參考：凍結，不追隨量測**。目標固定為暫停瞬間最後一筆已發布目標（END_HOLD 語意），DoorTargetK3 不再推進。
  - 這和「每輪更新為實測門角」是不同的控制律。後者不會產生保持門的效果，還可能跟著被推動的門走；本規格**不採用**後者。
- **底盤：QP 內的明確等式，不是零速度成本**（cfg.base_hold，整個時域）。
  1. 減速段：把**量測**的底盤本體速度（位姿差分）每週期朝 0 移動一步。線速度每週期 ≤ 0.8·a_base_lin·dt（0.02 m/s），角速度 ≤ 0.8·a_base_ang·dt（0.08 rad/s），預留 20% 給既有 QP 加速度框。
  2. 保持段：量測線速度 ≤ 停車伺服 v_max（5 mm/s）且角速度 ≤ w_max（0.02 rad/s）時，錨點設為當下位姿，改用既有 `park_hold_cmd` 停車伺服（k_p 2.0、k_yaw 2.0）。
  - 「底盤速度參考為零」**不等於**底盤必定停止。是否停止只依 §3 的量測完成判準判定，本規格不宣稱有停止保證。
- **手臂**：持續由 W-GMPC 追凍結目標，吸收底盤剩餘位移；近目標整形維持停用。
- **命令承接**：沿用權威 applied u_prev；減速段第一筆等式以量測速度為起點，所以和承接值相差一個週期內的量測差異。
  - 接入時必須讓 ADM 的停車伺服 u_prev 閘門（目前要求 ≤ 5 mm/s）在減速段放行，並記錄放行理由。

## 3. 完成判準與停止發布（只用量測）
- 底盤線速度 ≤ 1 mm/s、角速度 ≤ 0.005 rad/s、門角速率 ≤ 0.002 rad/s、手臂套用速率 ≤ 1e-3 rad/s，**連續 1.0 s**。
- 完成時記錄最後套用命令的大小：底盤應 ≤ 伺服界、手臂應 ≈ 0。
- **先確認零速命令已實際套用，才停止發布**，不把 0.2 s 命令逾時空窗當作停止機制。
- 未在期限內完成（離線建議 8 s）⇒ 走既有閂鎖並記為暫停失敗；不放寬判準。

## 4. 離線核對（`door_k3m_offline_pause.py` → `results/door/door_k3m_offline_pause.json`；5 s 觀察窗版本保留為 `_v0_after5s`）
同 K3-M 重播 r2 的受控體、控制器與延遲；門角由夾爪推得（門跟隨夾爪，**沒有門動力學**）。

| | P1（8° 完成後 1 s） | P2（門角 4.03°、底盤仍以約 12.8 mm/s 移動） |
|---|---|---|
| 進入保持段 | 立即（已近靜止） | 暫停後 0.15 s |
| 暫停後底盤位移 | 0.0 mm | 1.3 mm |
| 暫停後門角變化 | +0.000° | +0.301°（凍結目標比當下門角超前約 0.3°，手臂把門帶到凍結參考） |
| 達到完成判準 | 1.0 s | 5.2 s（手臂依一階模型收斂，暫停後約 4.5 s 速率降到 1e-3 以下，再加 1 s 連續） |
| 最後套用命令 | 底盤 ~1e-13、手臂 1.2e-7 rad/s | 底盤 ~1e-28、手臂 4.7e-5 rad/s |
| 淨空最小（非手指／手指／底盤／自碰） | 7.2／35.7／203／9.9 mm | 7.2／35.7／201／9.8 mm |
| 殼—橫桿、手指—橫桿（相對暫停瞬間名目值） | −0.00／+0.00 mm | −0.02／−0.75 mm |
| 閉合殘差最大 | 0.01 mm | 1.52 mm |

- 解讀：在健康、無外力的運動學情境下，此控制律能讓底盤在數 mm 內停住，手臂收斂到凍結目標，並在停止發布前讓套用命令降到近零。夾持相關幾何相對名目值的變化 < 1 mm。
- **不能**由此推論：門有慣性或被外力推動時的行為、接觸穩定性，或故障後的停止。

## 5. 待核對（實作前）
- ADM 端的減速段與 u_prev 閘門放行；
- 執行端模式：保持段要不要恢復 HoldMonitor，或延續走廊監看（建議延續走廊＋包絡，並另加伺服上界核對）；
- 暫停期間的握手：沿用三段握手，新增 mode＝pause；
- P1 取代 END_HOLD 時，判定器的對應修改（END_HOLD 固定目標仍成立；完成判準改為上面的量測判準）；
- 門被推動（門動力學）情境的離線補充：本規格的運動學重播做不到，需要另提方法；在那之前不宣稱暫停時能保持門。
