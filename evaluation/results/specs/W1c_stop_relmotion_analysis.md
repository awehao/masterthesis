## 2. 相對位移分解
**方法**
- p(H, B, q)＝(H⁻¹·T_tcp(B, q)) 的位置，在把手座標中表示。
- 逐項替換：Δq（手臂）、ΔB（底盤）、ΔH（把手）。
- 兩種順序都與總變化精確閉合（殘差 0.0 mm），順序差異 ≤ 0.0002 mm。

| 項（把手座標，mm） | x | y | z |
|---|---|---|---|
| **總變化** | 0.047 | **1.632** | 0.004 |
| 手臂關節項 Δq | 0.041 | −0.016 | 0.004 |
| 底盤項 ΔB | −0.060 | 0.001 | 0.000 |
| 把手項 ΔH | 0.066 | **1.647** | 0.000 |
| └ ΔH 把手原點平移項 | 0.081 | 1.648 | 0.000 |
| └ ΔH 把手座標旋轉項 | −0.015 | −0.001 | 0.000 |

- 底盤終點位移 (−0.039, 0.019) mm、偏航 0.034 mrad。
- 門角變化 0.1186°；乘以把手半徑 0.80 m 得 1.648 mm，與把手原點平移項一致（量級對照，不是分解項）。

## 3. 結論
1. **運動學上**，這段相對位移幾乎全由**把手隨門續轉的平移**構成：1.647／1.632 mm。
   - 同期手臂與底盤保持靜止：手臂套用命令為 0、設定點不變、實測 ≤ 0.08 mrad；底盤 ≤ 0.04 mm。
   - 也就是說，橫桿在夾持中相對夾爪沿把手 y 滑移，同時門轉動；把手座標旋轉的貢獻可以忽略。
2. **門續轉不是單調衰減**。0.5 s 窗口的門角速率在約 0 與約 0.9 mrad/s 之間交替，與相對位移的階梯狀增加同步。
   - 這是黏滑樣態，只描述。
3. **受力問題本輪不回答**：運動學分解不能說明是什麼受力造成門續轉。
   - 接觸力矩仍為 NA；先前的被動模型比較只是未驗證的診斷量。

## 4. 唯一控制候選（需規格與核可；本輪不做）
**暫停期提高手指夾持的法向力上限**
- 只改手指閉合驅動（目標或增益）；不改手臂、底盤控制，也不改停止判準。
- 依據：相對位移發生在機器人靜止時，是橫桿相對夾爪的黏滑，而先前分析中 finger2 切向承載接近摩擦上限（μd·N 比值只作幅值參考）。

**未知與風險**
- 指令閉合目標已是 0（全閉）、kp 1e4，實測法向只有約 6.2／3.7 N。法向力上限由什麼決定，需要先只讀核對驅動設定與讀回。
- 若夾持不再滑，門續轉的驅動會轉由機器人承受；在主動保持下可能改以底盤或手臂運動呈現。
- 這不等於已解決續轉來源。
