## 原因：核對腳本的等待條件不完整（我的缺陷）

安全層在 `__init__` 裡把 `~/diag_fields` 以 latched（TRANSIENT_LOCAL）
發一次（`wholebody_safety_node.py:277-281`）。
核對腳本的等待迴圈卻是

```python
if nd.cloud is not None and nd.diag is not None and nd.clock_seen > 5:
    break
```

**從不等 `diag_fields`**，後面卻要用它。負載較重時該 latched 樣本的傳遞
慢於其他三項，迴圈先跳出，檢查就報缺。free4 時剛好來得及。

**確定性重現**（不開 Isaac，替身讓 `diag_fields` 延遲 6 s 才發）：

| 等待條件 | 跳出耗時 | `diag_fields` 收到 |
|---|---|---|
| 舊 | **0.11 s** | **否** |
| 新（含 `diag_fields`） | 5.11 s | 是 |

修法是把等待補齊，**不是放寬門檻** —— 該檢查仍必須通過。
