### 1. 施力點不是你假設的質心

[door_k1_sim.py:160](/home/howardchen/masterthesis/evaluation/door_k1_sim.py:160) 計算的是：

\[
\tau=(p_H-p_{\mathrm{COM}})\times F
\]

但呼叫時 `positions=None`。本機安裝版原始碼及官方文件都說明：省略位置會在 **body/link transform 原點**施力，不保證是質心。你的門扇原點是鉸鏈，因此目前不能宣稱該呼叫等效於把手施力。[官方 API](https://docs.isaacsim.omniverse.nvidia.com/6.0.0/py/source/deprecated/isaacsim.core.prims/docs/index.html)

請明確選一種：

- 世界座標 `positions=p_H`，只施加 F，不再額外補同一力臂的力矩。
- 世界座標 `positions=p_COM`，另施加上述 τ。

質心須使用已核對的 PhysX 讀回值。紀錄實際送入 API 的施力點、F、額外 τ，並由它們重算鉸鏈合力矩：

\[
\tau_{\mathrm{open}}
=\hat a^\top\!\left[(p_{\mathrm{apply}}-c)\times F+\tau_{\mathrm{extra}}\right]
\]

補一個純函式／mock API 反例，確認沒有漏算或重複計入力臂。
