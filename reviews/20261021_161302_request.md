## 1. K1 程式 `door_k1_sim.py`（只有門＋地面；腳本施力不是機器人成果）
- 單位 m／kg（`SetStageKilogramsPerUnit 1`）、physics_dt 0.01、重力預設；門由 `door_asset.build_usd`（含把手材質）。
- **施力**：開門切向 t̂ = â×(p_H−c)/‖·‖（â=(0,0,−1)），p_H＝**每步由實測門扇姿態**算出的桿心；以**等效力旋量**施加：F 施於質心、τ=(p_H−p_COM)×F，`apply_forces_and_torques_at_pos(positions=None, is_global=True)`——不依賴 positions 的座標語意。每步記 F、τ、開門力矩 â·[(p_H−c)×F]。
- 睡眠：門扇 view 睡眠門檻設 0，成功與否寫入。PhysX view 讀回質量／慣量／質心。門扇對兩側牆用 contact force matrix 逐步記錄。
- 短測各自 `world.reset()` 獨立初始化（S5 只在開始前設定 45° 姿態並歸零速度）：

  | 項 | q0 | 力 | 施力 | 觀察 |
  |---|---|---|---|---|
  | S1 靜置 | 0 | 0 | — | 10 s |
  | S2 方向 | 0 | +10 N 切向 | 0.5 s | 5 s |
  | S3 反推 | 0 | −10 N 切向 | 1.0 s | 1 s |
  | S4 上限 | 0 | +20 N | ≤ 6.0 s（到 109.5° 即停力） | 2 s |
  | S5 非零角被動 | 45° | 0 | — | 10 s |
  牆鐘：每項 120 s、全部 600 s；逾時保存已得資料、整體 incomplete。不自動加力、不延長。
- 運行器 `run_door_k1.sh`：先核 `results/door/freeze_door_k1_dev.sha256`，由 `run_guarded_v2.sh` 包 92 °C 熱中止（coretemp），新目錄 `runs/<RUN_ID>`。

## 2. 判定器 `door_k1_check.py`（事前登錄；±1° 只是本次限位診斷容差）
- 讀回：PhysX 質量相對差 ≤ 1e-4（USD 讀回在模擬內再記錄一次）。
- 方向：S2 施力每步開門力矩 > 0 且施力結束 q 增加 ≥ 0.5° ⇒ verified，否則 fail。
- 下限：S3 q_min ≥ −1° 且牆接觸全程 ≤ 0.1 N ⇒ verified；q 未越界但有牆接觸 ⇒ **not_separable**；q_min < −1° ⇒ fail。
- 上限：到 ≥ 109° 後 q_max ≤ 111° ⇒ verified，超過 ⇒ fail；施力時間內未到 ⇒ **unverified**。
- 被動：S1 |q| ≤ 0.5°；**S5 非零角**全程 |Δq| ≤ 0.5° 且離兩限位；S2 撤力後 |q̇| < 0.01 rad/s 起至結束漂移 ≤ 0.5°（未靜止 ⇒ 子項 unverified）。三者皆 verified 才 verified。
- 阻尼只報（擬合 exp 衰減）；睡眠設定失敗、牆接觸或在限位時標「不可解讀」。
- 完整性：五項都在、無逾時、無 fatal 才 complete；all_verified＝complete＋讀回＋四項 verified。
- 反例 `test_door_k1_check.py` 13/13（合成門動力學）：正常、方向反、位移正但力矩負、隱藏回零保持、只有 S1 不足、S3 牆接觸 ⇒ not_separable、S3 越界、S4 未到 ⇒ unverified、S4 超限、逾時 ⇒ incomplete、質量讀回不符、睡眠失敗旗標、阻尼擬合合成值。
