# 一階模型條件重播（依你 20261022_131608 的五條規則）

程式：`evaluation/door_k3a_model_replay.py`。測試：`test_door_k3a_model_replay.py` 6/6。輸出：`results/door/door_k3a_model_replay.json`（每步逐筆與分箱）。

## 依規則實作
1. **只用三趟取證資料**：ev_1、au_ev_1、ax_ev_1。s_k 取 evidence.jsonl 逐物理步的 `arm_sp`（本步寫入 API 的設定點），不用求解請求補。
2. **固定模型與初值**：
   - 模型 q̂_{k+1}＝(I−A)q̂_k＋A(s_k＋d₀)。α 取 `wgmpc_arm_sp_ident_free4.json` 六軸原值，未四捨五入；有測試確認逐軸值直接代入。
   - 辨識檔的 bias 不使用，由 d₀ 取代偏移項；τ 不另加一層落後。
   - 初值＝OPEN 來源步的 room q_arm_meas。
   - d₀＝快照時刻 ≤ OPEN 步 sim_t 的最後一筆 solve_in.offset_d_hat。三趟的 d₀ 快照都恰在 OPEN 步時刻。之後固定，不再重擬。
3. **索引契約與連續重播**：
   - 執行器在同一迴圈內先讀 q_arm_meas、再寫 arm_sp，然後 world.step（`isaac_door_k2_sim_ev.py` 第 1047–1066 行與第 1205、1274 行）。所以 s_k 作用於物理區間 [k, k+1)，與辨識檔的 (sp_i − act_i) → act_{i+1} − act_i 相同；有測試鎖住。
   - 連續重播，不逐輪重設。缺 room 或 evidence 列、arm_sp 非有限、或時刻不符時即停止並記錄，之後不補、不重設；有測試鎖住。三趟皆未停止：重播 166／150／152 步到觸發步。
4. **同一步比較**：模型與實測都用 room 實測底盤與門角，沿用 r2 的共同座標分解。
   - D_QC＝R_qR_cᵀ、D_MQ＝R_mR_qᵀ、D_MC＝R_mR_cᵀ。R_c 為快照 ≤ 本步的最後一筆 T_cyc（零階保持，只作參照）。
   - 逐步閉合誤差 ≤ 1.44e-15。
5. **窗口**：
   - 主窗＝[OPEN, 首次單指 bar < 0.5 N)：ev 1998–2141、au 2102–2224、ax 2000–2122。
   - 首次低值步、之後的間歇承載窗與觸發步都另列在 JSON。
