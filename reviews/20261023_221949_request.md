## 三、停止小規格（`K3_stop_admissibility_spec.md`＋`door_k3m_offline_stop_states.py`）
- **兩種停止分開**：正常減速保持（DONE）與異常閂鎖停止。
- **取樣**（9000 個狀態）：
  - 中止當下：門角 1～8° × 內帶四角／中心；
  - 底盤剩餘：三種反應「超出內帶」的最壞量 × 8 方向；
  - 手臂殘餘：none、load_release＝−(d̂_abort − d̂_open)、full_release＝−d̂_abort（設定點凍結 ≠ 實測凍結）；
  - 門餘轉：0、0.25、0.5、1、2°。
- **結果**：

  | 情境 | 符合門檻的比例 |
  |---|---|
  | executor 反應：門餘轉 0° | 195～200/200 |
  | executor 反應：門餘轉 0.25° | 50～200 |
  | executor 反應：門餘轉 0.5° | 0～183 |
  | executor 反應：門餘轉 ≥ 1° | 0 |
  | policy／chain_timeout 反應：門餘轉 0° | 約半數 |

  - 最差都是**夾爪殼—橫桿**（最負約 −13 mm）；policy 情形手指對門扇也為負。
  - 底盤 ≥ 130 mm、自碰 9.8 mm。
- **可容許與拒絕**：
  - 只有「DONE 時底盤與門都已靜止」可支持；
  - 策略端或命令鏈逾時觸發的中止、以及門以實錄常見量（~1°）續轉的情形都拒絕；
  - 執行端越界且門幾乎不轉時只部分支持。
- **結論**：原停止方式在常見中止情境下幾何餘裕不足，**進入條件未解除**。
- **候選「跟隨減速保持」**（只列方向，未實作、未核可）：非安全臨界中止時 W-GMPC 不停，目標改為實測門角對應的把手位姿（參考凍結在實測門角、不推進），底盤速度參考為 0；靜止後才凍結。安全臨界中止仍立即閂鎖並承認風險。另列推進前需要的離線核對。
