## 3. 受控暫停小規格 draft-1（`K3_controlled_pause_spec.md`＋`door_k3m_offline_pause.py`）
- **範圍**：只限健康狀態下的預定暫停。finger_contact_lost、越界、門速超限等都不納入，仍走既有閂鎖。
- **參考：凍結，不追隨量測**。固定為暫停瞬間最後已發布目標；已明寫「追隨量測」是另一種控制律，本規格不採用。
- **底盤：QP 內的明確等式** cfg.base_hold，分兩段：
  - 減速段：量測本體速度每週期朝 0 移動一步，線速度 ≤ 0.8·a_base_lin·dt、角速度 ≤ 0.8·a_base_ang·dt；
  - 量測速度 ≤ 伺服界（5 mm/s、0.02 rad/s）後，錨點設為當下位姿，改用既有 park_hold_cmd。
  - 已明寫「零速度參考 ≠ 必定停止」。
  - 承接沿用 applied u_prev；接入時，ADM 的停車伺服 u_prev 閘門須在減速段放行。
- **完成判準（只用量測）**：底盤 ≤ 1 mm/s、0.005 rad/s；門速 ≤ 0.002 rad/s；手臂套用速率 ≤ 1e-3 rad/s，連續 1 s。完成後才停止發布，所以不靠 0.2 s 逾時空窗。逾期沒完成就閂鎖，記為暫停失敗。
- **離線閉迴路**（同 K3-M 重播 r2，門跟隨夾爪，無門動力學），檢查**整段過程**：

  | | P1（8° 完成後 1 s） | P2（門角 4.03°，底盤約 12.8 mm/s 移動中） |
  |---|---|---|
  | 完成時間 | 1.0 s | 5.2 s |
  | 暫停後底盤位移 | 0 | 1.3 mm |
  | 暫停後門角變化 | 0 | +0.30°（凍結目標超前約 0.3°，手臂把門帶到凍結參考） |
  | 最後套用命令 | 底盤 ~0、手臂 1e-7 rad/s | 底盤 ~0、手臂 5e-5 rad/s |
  | 淨空最小（非手指／手指／底盤／自碰） | 7.2／35.7／203／9.9 mm | 7.2／35.7／201／9.8 mm |
  | 殼—橫桿、指—橫桿（相對暫停名目值） | 0／0 mm | −0.02／−0.75 mm |
  | 閉合殘差最大 | 0.01 mm | 1.52 mm |

  - P2 原先以 5 s 觀察窗跑時尚未滿足完成判準；該版本保留為 `_v0_after5s`。
- **不宣稱**：門有慣性或被外力推動時的行為、接觸穩定性、故障後停止。原閂鎖的停止後幾何不相容仍未解除。
