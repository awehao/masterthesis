## 2. API 語意查核（isaacsim 6.0.1.0，extsDeprecated 的 core.prims／core.api）
- **RigidPrim**：handle 有效 ⇒ 姿態走 `get_transforms`、角速度走 `get_velocities()[:, 3:6]`；無效 ⇒ USD 回退（角速度屬性為 deg/s，再 deg2rad）。
  - 有效條件：sim view 存在，且 `_physics_view` 已在 `initialize()` 中建立。
  - ev2 在 `world.reset()` 之後才 `initialize()`，所以推定有效，但**沒有紀錄、未驗證**。
- **根速度 setter**：先 `get_root_velocities` 再覆寫一部分，然後 `set_root_velocities`。`set_angular_velocity([0, 0, wz])` 同時把 x、y 角速度寫成 0。
- **world.step(render=False)**：→ `PhysicsContext._step(update_fabric=False)` → `simulate(dt, t)`。
  - 未查證：`simulate` 是否含 fetch results、子步數。
  - ev2 沒有設定求解器、迭代、子步與 CCD，執行期實際值未知。
- **推論界線**：若 handle 有效，姿態與速度同出自 tensor view，不能歸因於 USD／PhysX 不同步；若無效，則可能讀到未更新的 USD 值。兩者目前都不能排除。
