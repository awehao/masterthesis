## 1. 解除確認（裁定 1：候選登錄值）
候選登錄值，**不是已驗證的 30° 解除能力**：
- 開度 ≥ 95 %（兩指 q_finger ≥ 8.46 mm）；
- 兩指手指—橫桿接觸各 ≤ 0.1 N（ambiguous 計入）；
- 以上在逐步有效資料上連續 ≥ 0.5 s；
- 期限：t_open 後 1.5 s 內。

不另開「張爪後停留、不退離」的實跑。張爪、確認、退出近接觸區是**同一受控釋放流程的三個檢查點**（§7）。

**缺欄、非有限、過期（接觸資料年齡 > 0.1 s）、缺步、接觸窗 n_invalid > 0 一律不視為解除**：
- 該步計為無效，持續計時歸零；

  - 夾爪命令凍結在當下值；全身命令不再進鏈。
- **更正 draft-1 說法**：既有閂鎖**不是持續主動保持**。底盤減速到零後沒有錨點伺服，也不宣稱「安全停止」。

「續退」若之後要列為處置，須另行登錄並核可，未核可前不用：
- 可用狀態：例如門速 ≤ 某值、剩餘路徑長度；

- **執行端自行再核**：
  - 已在 mode 3；
  - 最近 0.5 s 逐物理步兩指—橫桿接觸 ≤ 0.1 N；
  - 開度 ≥ 95 %。
- 通過才在物理步設 5 N 並讀回（EV5 同一機制），回 ack；任務端以 ack 的讀回結果餵 effort_readback_ok。
- 執行端拒絕 ⇒ 任務端中止。

**D5 判定器**
- 以 room／task／solver 紀錄重算規格 R1–R8，包括：
  - 執行端 mode 2／3 提交步、手指目標切換步、mode 3 首筆實際套用（C0–C11 擴充）；
  - 任務端 ReleaseMonitor 事件與執行端逐步資料交叉核對：t_conf 由 room 逐步重算，不只信任務端；
  - 不另造新 DONE 語意：DONE＝STOW_READY 後保持 ≥ 3 s。
