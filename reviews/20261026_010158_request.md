## 2. 裁定落實
**D1 模式與求解端交接**
- mode 2 保持形：提交步同步切換 mode_seq、profile（release_open）、手指目標（open）。
  - ev7 在 mode ≥ 1 時，手指命令由權威模式決定；K2 閂鎖後照既有凍結。
- mode 3 准入：執行端 `ExecReleaseMonitor.confirmed_fresh(step)` 須為真，請求時與提交當下各核一次。
- 候選＝以話題退離目標對同一快照、同一 u_prev、同一 base_hold 冷啟動另解，一般流仍保持。
  - 候選另解在一般發布之後，不改暖啟動、偏移估計、u_prev 與一般流目標。
  - 候選**不寫入延遲預測歷史**，只在執行端回報該 source_seq 已實際套用時才插入（不同內容的候選不當作已套用命令）。
- 提交後以原暫停錨點持續底盤保持（不重設錨點、不回 PARK_HOLD 路徑），手臂不再歸零，目標＝話題退離目標。

**D2 本包止於退離終點**
- 完成＝退離終點 s ≥ 0.095、運動收斂（0.5 s 內位移 ≤ 1 mm）、再保持 ≥ 3 s，任務端才 DONE。
- STOW_READY 只是旗標，不是收臂，監看持續到收尾（end）。這 3 s 不取代先前 10 s 停止觀察。

**D3 分層**
- 執行端逐物理步負責：開度、配對力（bar＋ambiguous）、資料有效性與連續性、確認持續窗、期限、模式與手指閘門、5 N 權威。
- 任務端約 20 Hz 負責：配對幾何、工具偏移、門角帶（T_pred 0.2 s 預測）、一般幾何、底盤錨點、退出證據、完成條件。
  - 資料帶來源步、年齡與計算耗時，過期不用；停更 > 0.2 s 判失敗。
- 門速：任務端用同步流 0.1 s 差分（須 valid），tensor 門速 0.05 rad/s 保護保留。
- T_pred 0.2 s 只是候選，不是硬上界。

**D4 5 N 恢復**
- 請求須帶序號與本趟、mode 3、任務端 C_CLEAR 證據（來源步、時間、s、配對 d／d_pred、band_ok）。
- 執行端再核：
  - 證據新鮮（≤ 0.2 s）且 s ≥ 0.02、配對 ≥ 5 mm；
  - mode 3；確認後靜窗 ≥ 0.5 s；開度 ≥ 95 %；
  - 期限 0.5 s。
- 中止優先；ack 帶切換步與讀回結果；非手指上限不變。

**D5 候選數值**
- 18 N、單調帶、[−3, +2.5]° 皆登錄為測試候選，不升格為保證。
- 退離期間門角下界照一般 −1°；[−3, +2.5]° 只作收臂前置旗標。
- 規格「關節 50 mm」更正：K1.evaluate 的關節餘裕門檻 LIM_M＝0.05 是**弧度**（距關節限位 0.05 rad）。

**核心三缺陷**（r2 修正並固定成反例）
- 同一步重送不累積、時間衝突拒收；
- 先查期限再轉移：1.51 s 首次確認判逾時；
- READY／COMPLETE 後監看持續。
- 另補：停更、恢復請求的證據新鮮度反例，以及 20 Hz 餵入執行端判缺步。

## 3. 實作途中發現並修正的問題（照實記）
1. **退離候選首筆飽和**（ADM12 假世界首跑）：假世界以「起始 TCP＋目標偏移」為退離起點，手臂不在該處，首筆手臂 1.0 rad/s，被權威 arm_accel_box 拒收。
   - 這是框架錯誤；真實任務端本來就以 t_open 實測 E_rel 為起點。框架改為 mode 2 提交當下實測 TCP 後通過。
   - 權威的手臂加速度框維持以物理步計（19.984 × 0.01 s），不放寬。
2. **交接競態**（ADM12 第二跑）：執行端在提交步就套用退離候選，求解端在權威狀態送達前收到回報，HELD 監督器以 old_command_in_held 判失敗。
   - 修正：候選 source_seq 被回報實際套用時，先交接再核（候選只可能在提交後被套用，本身即提交證據）。
3. **測試保持期邊界**（任務端策略）：本類以 `< test_hold` 判斷、W2 父類以 `≥ test_hold − 1e-9` 判 DONE。3.0 s 邊界上父類先 DONE，整段 K3-B 被跳過。
   - 修正為同一容差，另加防呆：父類不得在本類流程中 DONE。
4. **沿退離軸監看 1 mm 不可行**：規格 draft-2 §4 的 |y − y_ref(s_cmd)| ≤ 1 mm，小於一個控制週期的退離行程（0.02 m/s × 0.05 s＝1 mm），加上求解延遲必然超出。
   - 改為追蹤落後界限 |s_cmd − s_meas| ≤ 5 mm（候選，0.25 s 落後預算）。
   - 門角帶本來就以實測 s_meas 向下取格查表，沿軸落後不影響淨空依據；離線 ey ±1 mm 對應 s 的格點量化。
   - **此為規格變更，請裁定。**
5. **釋放段底盤錨點**：任務端原沿用 /park/gate 錨點，那是開門前停位 (0.6, −0.533, 90°)；30_1 開門後底盤在 (0.32, −0.80, 79.4°)，相差四百餘 mm，實跑一進 RELEASE 即會判 base_anchor。
   - 修正：任務端與判定器都改以 t_open 基準那一步的實測底盤位姿為錨點。
   - 路由測試改用實跑 gate 錨點重跑仍通過。
   - 求解端保持錨點是暫停期錨點，兩者差在保持伺服的 mm 級範圍內。
6. **舊鏈取代清單依實驗決定**：
   - 做法：W2c2 合成趟（60_3 實錄＋合成 W2）把 t_open 後改為 RELEASE 列、張爪、退離目標，再跑 W1f2 舊鏈；
   - 結果：只出現兩項舊 DONE 理由。
   - 原擬取代的 grip_command_not_closed_after_grasp 未觸發，故不預先取代（測試 J8 固定）。
