  - p_target 來自當輪同步量測的把手 H 與原 G_T_H；p_tcp 由實測底盤與手臂正運動學算出。
  - 偏航與鉛直不修。
- **更新規則**：c 以一階濾波（τ 1.0 s）追 e，每軸變化率 ≤ 2 mm/s，幅度 ≤ 8 mm。

  - 前饋、偏航、k_lin、v_cap／w_cap 限幅都不變，總參考仍受既有速度限制。
- **失效處置**：非有限、維度錯或 dt ≤ 0 ⇒ c 不更新、沿用上一個有效 s，並計數；不拋例外、不新增命令來源。
