# 階段發現（r41 合併包，離線運動學）：內側把手「通過中拉關」串接 v1——static／reverse 走通、k3b_stress 插入段被擋

腳本 evaluation/door_coopen_pass_close_inner_v1.py（commit feefa1b65）；結果 evaluation/results/door/door_coopen_pass_close_inner_v1_{static,reverse_0p5,k3b_stress}.json。
門規格 door_local_v3（內側把手同型、同高、對稱＝建模假設；Isaac 資產尚無內側把手）。

## 串接（同一時間軸，全程 RB3.retime 重定時）
release_outer（沿用 release_bench6_v4 94 點）→ M：A*（0.0125 m 格點，手臂 STOW）到 B1=(0.60, −0.10, 270°)
→ A：底盤鎖定；預抓取 T_pre＝H_in(q)·T_HG·平移(工具 −z 0.06) 以多種子 IK 取（關節餘裕＋5·淨空）最佳分支，自 STOW **關節空間內插**（逐點核）
→ I：沿工具 +z 插入 0.06 m（指—內側橫桿 ≥ 0）→ G：閉爪 3 點（指—內側橫桿 ≥ −1 mm 為指定接觸）
→ P：持握拉關，門角每步 {−0.5°, 0}、底盤方向候選，到 Q_END=2°（不是 0°，揭露）→ R_open → R_slide（工具 −z 0.06，無再穿入）→ R_stow。
分階段接觸規則：外側橫桿全程為障礙；手指—內側橫桿只在 I／G／P／R_slide 豁免（I、R_slide ≥ 0，G、P 為指定接觸）。

前一版 A 段改法紀錄：直角座標 TCP 線性內插在第 54/60 點關節餘裕 0.034 rad（< 0.05）被擋 → 改成上述「多種子 IK 預抓取＋關節空間內插」，門檻不變。失敗紀錄改名保留（*_cartA_fail.json 等）。

P 段結束時底盤 y 0.404／0.399（< 0.44），門已 2°；底盤在放開後的 R_slide 才越過 0.44。重定時後閉爪前門角重核：無不合格（recheck_after_retime 空）。

k3b_stress 阻點：I 段第 3 點單步關節 0.142 rad（> 0.10），當時門角 59.44°（I 段門角固定，非門在動造成）。
原因脈絡：k3b_stress 殘差（1.0°/s 0.16 s 後 0.24°/s，線性無界）原為退臂窗（12.6 s）設計；本串接把它外推到閉爪 ~43 s ⇒ 門自 47.9° 飄到 59.4°，抓取構型與 static 差 12°。

## 請裁定
1. k3b_stress 外推到 43 s 是否仍為合理壓力情境？選項：(a) 照原定義外推（目前做法；結論＝此情境未走通）；(b) 另訂「殘差有界」情境（例如對齊門阻尼 ≈0.5/s 的衰減），作新版情境、不改舊結果；(c) 兩者都報。
2. I 段被擋可否以加密取樣（12→24 點，單步門檻 0.10 rad 不變）重試？或應改為重新選預抓取分支（以插入全段可行性選分支）？
3. 措辭：「在離線運動學、對稱同型內側把手假設下，static 與反向殘差兩情境找到一條完整串接：放手退臂、移到門洞入口、抓內側把手、底盤進入門洞同時拉關至 2°、放手退出，整機越過牆遠側面。壓力殘差情境未走通。」是否可用？Q_END=2° 而非 0°、無接觸力、無 W-GMPC 閉迴路皆揭露。
