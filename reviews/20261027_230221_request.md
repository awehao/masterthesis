# r42 §1 時間化修正完成（static）——請核，並確認 W-GMPC 名目閉迴路的接法

腳本 evaluation/door_coopen_pass_close_inner_retime_v1.py（commit 9191ad29b）；結果 results/door/door_coopen_pass_close_inner_retime_v1_static.json（含 20 Hz 參考）。
只改時間化，不改構型路徑（來源 door_coopen_pass_close_inner_v1_static.json）。

## 方法
- 經過點版 LSPB：每段有號速度；接點混合 τ_j＝max_i |Δv_i|/a_i（底盤以接點偏航轉車體座標），兩端混合半長和 > 段長則拉長該段重算；起訖由靜止混合。
- 速度：底盤車體 x、y 取該段偏航區間內的精確最大值；門角 ≤ 0.6°/s＝bench_6 登錄 r_max_dps（遠低於 door_abort_rate 0.05 rad/s，未放寬）；手指 ≤ 0.0089 m/s（finger_open／close_ramp_s）。
- 規劃用 0.995 倍上限，核對用 1.0 倍。
- 20 Hz 取樣後全部重核：有號差分速度、二階差分加速度、門速、每點淨空（分階段規則）、抓持段 TCP 對當時內側把手相對位姿與 T_HG 的誤差（門檻 drift_abort_m 5 mm／2°，另對照 grip_tol 2 mm）。
- 補一條規則（揭露）：release_outer 段手指—外側橫桿沿用 release_bench6_v4 只禁穿入（≥ 0），不套一般 5 mm；首版重核在此段 t 0–0.3 s 報 2.3–5.0 mm 即因此。
- 首版另有報表錯（門角已是度又轉一次 ⇒ 誤報 34°/s）與門速上限單位錯（時長 4431 s），兩者已修，首版結果改名 *_r1_unitbug.json 保留。

## 結果（static）
- 總時長 127.0 s（舊 63.0 s 作廢）；P 段 45.2–122.0 s。
- 最大比值：速度 底盤 x 0.995、y 0.995、偏航 0.452，關節 ≤ 0.995；加速度 底盤 x 0.904、y 0.995、偏航 0.426，關節 ≤ 0.870。
- 門速最大 0.597°/s；門角加速度 9.28°/s²（無登錄值，只報）。
- 2540 點淨空 0 失敗；最小 非手指 7.2、自碰 6.4、底盤 20.4 mm。
- 抓持段（45.2–122.3 s）TCP 對把手誤差最大 6.6 µm／3e-8 rad（取樣構型是 6 維精確解，混合偏差小）。
- 底盤越過 y 0.44 前關門 45.85°（47.87→2.0°），重疊 76.8 s；底盤越過時在 R_slide（門 2°）；整機 y≥0.14 於 R_stow 125.9 s，末態 ymin 0.159 m。

## 下一步提案：W-GMPC static 名目閉迴路（離線，非 Isaac）
- 用真正的 W-GMPC 求解器（ammr_wholebody_mpc，H5 設定）＋既有延遲／設定點受控體（手臂 α=0.095／τ=0.100 s 辨識模型；底盤 E2 執行端 0.05 m/s／0.20 rad/s），20 Hz，追蹤上面 20 Hz 參考的 TCP 與底盤。
- 門角：抓持段由受控體 TCP 對把手的切向位移推得（剛性持握、只投影到門弧，揭露）；未抓持段照 static 固定。
- 報：TCP 追蹤誤差、抓持段 TCP 對把手誤差（5 mm／2° 門檻）、各段淨空（分階段規則）、限值比、重疊與整機清空時刻；不重新設計控制器、不調權重（沿用 P 的權重並揭露）。
