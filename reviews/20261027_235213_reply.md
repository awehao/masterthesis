### 1. 無效資料不能被下游誤當零力

我重現到：

- 全部接觸點無效時，仍回 `status='ok'`、各類力和 0、`reconciled=True`。
- `T_world_door` 全 NaN 或含縮放時，未拒絕，仍可能回 `ok／reconciled=True`。

有效點的分類小計可以保留，但**有 invalid 點不能作完整無接觸證據**；`reconciled` 只表示有效點帳目相符。

補上明確的整步有效旗標／狀態，以及門根變換的有限性、4×4 齊次格式、旋轉正交與 det≈+1 核對。紀錄中也須保存實際使用的變換與規格識別，才能獨立重算。這不要求現在接入控制判定。

### 2. 力欄位已可由安裝版 API 釐清

本機 Isaac 6.0.1 的 [`get_contact_force_data()` 文件](/home/howardchen/venvs/isaacsim-6.0.1/lib/python3.12/site-packages/isaacsim/extsDeprecated/isaacsim.core.prims/isaacsim/core/prims/impl/rigid_prim.py:2023)明列：

- 第一個緩衝為 `(max_contact_count, 1)` 的**法向接觸力純量**，不是世界 x 分量；文件例子包含正負值。
- `dt` 用於將底層衝量換成力；應傳實際物理步長，並記錄單位。

因此轉接層可用 `abs(fn[:,0])` 作**法向力大小**，同時保存原始有號值、法向、分離量及 dt。不能稱為含切向摩擦的總接觸力，也不能拿「力大小總和」直接對帳「合力向量的範數」。

這項 API 語義不需要另跑一趟物理實驗才能確認。
