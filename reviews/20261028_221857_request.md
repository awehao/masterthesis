# 「張爪＋退離重疊」的接線切法：請二選一（影響工作量）

現況接線（讀碼確認）：
- 參考 seg 3（ref pb1）：0–0.8 s 原地張爪（qf 0.0017→0.0089，s＝0），0.8 s 起沿工具 −z 退（約 21 mm/s），4.8 s 到 61 mm。
- pb1_4 張爪後門速約 0.0178 rad/s（橫桿 ≈14 mm/s 朝掌心），掌心名目淨空 7.6 mm ⇒ 原地張爪的 0.8 s 內必觸發；退離一開始（21 mm/s）就快於門。
- mode 2 提交：權威 finger_target＝open；執行端 Gate3Release（ExecReleaseMonitor）在 mode 2 期間確認「張開＋接觸力小」持續 confirm_hold_s，為 mode 3 准入；
  求解端 HeldSupervisorP4b8：mode 2 提交起 sub＝release_open，任何移動 ⇒ FAIL moved_in_release_open，收斂 ⇒ release_settled，mode 3 交接只准自 release_settled。

## 切法 A（你上一則的方向）：mode 2 變運動形＝張爪＋退離前段
改：權威 mode 2 入 MOTION_MODES（mode5 表）；求解端運動集合加 2、HeldSupervisor 新 sub（release_retreat：允許跟隨參考運動、仍核偏離參考與腕力，收斂改以「接觸已解除＋退離量 ≥ s1」）；
任務端 mode 2 改跟隨新 seg 2（＝張爪同時退的前 s1，例如 20 mm）、mode 3 以實際退離量對齊 seg 3 剩餘段；Gate3Release 在運動中確認（door_q 判據需確認是否容許門動）。
工作量：權威＋求解端＋監督器＋任務端參考銜接＋執行端 gate，五處各一版本，加單元測試。估半天以上。

## 切法 B（較小）：mode 2 保持夾持做原地靜止觀察（不張爪），張爪移到 mode 3 提交步，與退離同時開始
改：權威 FINGER_OF[2]＝closed、[3]＝open；Gate3Release（放手確認）由「mode 3 准入」移到「mode 4 准入」的必要條件（與 Gate4Exit 並列：退離量 ≥ S_EXIT 且放手已確認且新鮮）；
seg 3 去掉前 0.8 s 原地段，qf 在退離前 0.8 s 內同步張開；求解端監督器 release_open／release_settled 在 mode 2（夾持靜止）照原規則收斂，語義改記為「放手前靜止確認」（名稱不改、揭露）。
求解端運動集合、HeldSupervisor 程式不改；mode 3 本來就是運動形。工作量：權威表＋exec core gate 對應＋seg 3 改寫，約 1–2 小時。
放手確認沒有被繞過，只是改在退離過程中完成、且仍是進 mode 4 的必要條件。
