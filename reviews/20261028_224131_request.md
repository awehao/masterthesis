# 有界診斷結果：為什麼夾住停很久、張爪後門仍會動（只讀既有紀錄；evaluation/door_release_velocity_diag.py → results/door/door_release_velocity_diag.json）

## 1. 讀值後端與取樣（已確認，排除快取／單位／混步）
執行端 door_q_qd()：同一個門扇 RigidPrim tensor 視圖，world.step 之後同一時點讀 get_world_poses 與 get_angular_velocities；q＝−atan2(R10,R00)、q̇＝−ω_z（rad、rad/s）。
張爪後（無接觸）讀值與位移率一致：pb1_3 0.00905／0.00902、pb1_4 0.01638／0.01634、pb1_6 0.01772／0.01767 rad/s ⇒ 讀值就是 PhysX 剛體速度，不是讀法錯。

## 2. 持握期「讀值 − 位移率」（excess；三趟高度重現）
| 時段 | pb1_3（暫停 20 N） | pb1_4（5 N） | pb1_6（5 N） |
|---|---|---|---|
| 閉爪後、開門前（門 0°，靜止） | 0.00397 | 0.00398 | 0.00398 |
| OPEN 中段（實際 0.01745） | 0.01396 | 0.01376 | 0.01378 |
| PAUSE（門角範圍 < 0.011°） | 0.00981 | 0.01540 | 0.01559 |
- 偏差**在閉爪當下就出現**（門尚未動），不是開門殘留速度；開門中變大；暫停中與夾持出力有關（20 N 較小）。
- 張爪前最後接觸步讀值 ≈ 張爪後 0.1–0.3 s 位移率（見 1）。

## 3. 持握期接觸與驅動（暫停窗，逐步快照）
- 門扇接觸部位只有 finger1、finger2（無掌心、無 panel、無牆）；法向約 ±z（上下夾），4.6／5.4 N（5 N 趟）、11.7／12.0 N（20 N 趟）＝手指驅動實測力（位置目標 0 vs 實際 0.0017 ⇒ 出力飽和於上限，零速命令≠零力）。
- 摩擦合力平均 2.1–2.5 N（水平），對鉸鏈 z 力矩正負交替（5 N 趟 −4.4…+7.1 N·m、平均 −0.07；20 N 趟 −0.58…+0.24、平均 −0.13）⇒ 逐步快照**看不出**單一同號外力在推門。

## 4. 已確認 vs 未確認
- 已確認（數值機制層級）：持握中門扇剛體速度與位移不一致，接觸求解只修位置、未消去該速度；放開即以該速度運動。符合你引的 PhysX 說明（位置積分速度≠跨步回報速度），屬模擬數值現象。
- 未確認：是哪個約束持續維持此速度（為何角阻尼 2.0 不使其衰減；為何閉爪即出現 0.0040）。
