# Howard 最新動作要求：開門後朝前移動，穿越與關門同步操作

日期：2026-10-29（Asia/Taipei）。交付對象：Claude。

Howard 原話：「它開門後車頭沒有朝前，超不順的，然後關門是停定，我想要移動中操作。」

最新補充（Howard 要求）：**關門時，底盤要能很順滑地銜接到關門姿勢。** 重點是行進、調姿與操作的連續過渡，不是只把車頭改一個固定角度。

## 0. 最新補充：從行進姿態連續轉入關門姿態

- 一般移動車頭朝行進方向；進入關門接近區後，底盤平移、偏航與手臂預對位應一起連續調整，到適合抓取／拉關的全身姿態。不能切成「停車 → 原地轉完 → 才移動手臂 → 再起步關門」。
- 關門操作需要的朝向可以在操作接近區平順調整；不要把「車頭朝前」誤做成所有操作階段都鎖死同一偏航。這不是取消朝前通行目標，也不把舊長段倒退參考直接升格為符合要求。
- 接近、換抓、穿越拉關與退出應按同一條全身動作銜接。模式切換不能靠跳變底盤目標、關節姿態或重設命令歷史完成；保留既有速度／加速度限制與權威承接。
- 正式閉爪或接觸切換若需短暫穩定，仍沿用必要准入；不要把它擴成一整段先停定才開始準備的流程。不得為畫面連續而取消保護或強迫全程非零速。
- 這項銜接直接納入正在準備的正向接近→穿門拉關→退出候選，不另開一套平順性評估包，也不只靠影片倍速改善觀感。

## 1. 這次要求的是實際動作，不只是狀態機接通

目標流程：

**移動中預夾取 → 正常後退拉開門 → 解除外側持握 → 車頭朝行進方向移往內側接近位置 → 移動中預對位、准入後換抓 → 底盤穿越與手臂拉關重疊 → 放手退出 → 朝前續行。**

- 開門往後拉仍是允許的操作形態；不改回邊開邊繞。
- 開門後的空手移動不得一直維持操作朝向、長段倒退或側滑。不要把現有 mode 4 的原地大角度轉向＋低速平移直接當作最終順暢方案。
- 穿門拉關的目標也要朝前通行並由手臂協同操作，不能把舊 mode 7 倒退參考當成已符合。若手臂可達、限位或碰撞確實阻擋，直接短報具體構型與最小改法，不自行把倒退永久列為例外，也不宣稱朝前不可能。
- 關門須在底盤實際穿越時有實測門角減少。不能停住底盤，把門拉關完才重新起步；不能用參考推進、原地旋轉、噪聲級位移或播放倍速冒充同步操作。
- 已有成功版、影片與判定保留，不回改歷史。既有某些區間有移動與拉關重疊，不等於目前所有路段已符合車頭朝前、順暢銜接的要求。

## 2. 保留交棒與安全，刪減不必要的串行等待

- 沿用滾動交棒與預夾取；不能退回先完整停車，再開始展臂與接近。
- 正式閉爪、換抓及必要准入可以短暫穩定；安全中止永遠允許停止。不新增每瞬間速度都非零的條件，也不因追求流暢取消既有停止、接觸或幾何保護。
- 一般移動用導航 GMPC＋導航 CBF／掃描護盾；操作接近、持握穿越與拉關由 W-GMPC 協調底盤與手臂。單一實際命令權威、設定點與套用命令連續承接。
- mode 4 先前已選定「收臂後交回導航朝前移動，到操作接近區再交回全身」的整合方向；目前尚未實現的部分不可當作已完成。操作朝向在接近區逐步調整，不要求全程預先對準把手。
