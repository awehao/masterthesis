# 瓶子移動夾取：最小設計審查（未實作、未啟動模擬）

設計全文在 第七次進度報告素材/規格/瓶子移動夾取_最小設計.md。要點：

- **假說**：在相同上限與監看下，W-GMPC＋設定點模型＋延遲補償＋時域內未來參考＋底盤進度協調，比 C1（MotM 式：五次多項式到達時間同步＋單步全身 QP，沿用 wg4b_b1_core）與 C2（理想執行模型 MPC），在底盤不停下的前提下有更高的夾取＋抬離成功率，接觸前 TCP 誤差、峰值減速度、停等也較小。另做兩個消融：拿掉未來參考、拿掉進度協調。
- **場景**：Isaac 現有平台；瓶子夾持段直徑 30 mm（夾爪名目開口 22.4–36.2 mm）、高 0.2 m、0.2 kg；位姿取真值；桌高與路徑偏移先以 IK 離線掃描決定；側向水平抓取；沒有障礙物。
- **單一 W-GMPC** 從 CRUISE 一路控制到 CARRY，中途不換控制器。內層新增時域內每步一個目標 T_des(t＋kΔt) 與每步一個底盤 v_ref，未給時逐位元不變。外層 10 Hz 進度協調：
  - 可達窗 [s_in, s_out] 離線取樣；
  - t_arm 用設定點模型推演；
  - 停留預算 v_b ≤ 窗內剩餘長度／(插入＋閉爪＋證據＋抬升)；
  - v_b 低於 v_min 時判定不可行，退回停車夾取，記為降級。
- **證據**：
  - 兩指各 ≥0.5 N 逐步連續 **1.0 s**、閉爪後 5 s 內成立。這是新任務的新判準，請核定；門段的 2 s 不動。
  - 瓶底離桌 ≥40 mm 並保持；持瓶 3 s 內相對 TCP 漂移 ≤5 mm／3°。
  - 閉爪前推瓶 ≤5 mm／3°。
  - 非手指連桿碰瓶或碰桌即失敗。
- **條件**：進場速度 0.03／0.05／0.07 m/s；瓶位偏移 ±15 mm（3 個種子）；另做手臂伺服變慢的執行擾動組；每格先 n＝3。
- **順序**：(1) 核心未來參考＋單元測試 → (2) 離線運動學閉迴路比較 C1、C2、C3 → (3) Isaac 場景與 bottle_task_node → (4) 冒煙測試後另送實跑申請。

請審：
(a) 假說與對照組是否足以支撐「改善 MotM」，C1 的移植方式是否需要調整；
(b) 抓持證據 1.0 s、抬離 40 mm、漂移 5 mm／3° 等門檻；
(c) 是否核可先做 (1)＋(2)（純離線：核心改動、單元測試、運動學閉迴路），(3) 等 (2) 的結果出來再申請。
