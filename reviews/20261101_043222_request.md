# 第一項：停止有效未通過的對齊分析與修正提案（只用既有紀錄）

**對齊結果**（兩趟都在 LOWER 中、瓶底貼桌面且仍被夾持時停止）

| | p1_1（判有效） | p1_2（判無效） |
|---|---|---|
| 設定點最後變動 | 52.67 s（停止後 0.07 s） | 52.57 s |
| 停止 0.5 s 後逐步 \|dq\|/dt＞1e-3 的比例 | 52% | 62% |
| 逐步最大 | 0.0049 rad/s | 0.0066 rad/s |
| 主要關節 | j4 | j4（交替 j5） |
| 1.5 s 淨位移最大 | 1.3e-5 rad | 6.6e-5 rad |
| 0.5 s 窗口位移速率最大 | 1.3e-4 rad/s | 3.1e-4 rad/s |
| 峰峰值最大 | 7.4e-5 rad | 1.75e-4 rad |
| 追蹤誤差 q−s 標準差 | 1e-5–4e-5 rad | 同左 |

p1_2 的接觸力：停止後 fz p10／p50／p90 為 0.25／0.69／1.11 N；|dq| 與 |Δfz| 相關係數 0.41，與 |Δ指1力| 相關係數 0.21。

**判讀**
- 停止後設定點固定，手臂沒有在移動：淨位移與窗口速率都比 1e-3 rad/s 小 1–2 個數量級。實際是 1e-5 rad 等級的每步微抖，和瓶↔桌接觸力跳動有關。
- 現行 stop_effect 取第 1 s 那一刻的單步差分 max|dq|/0.01，對這種微抖非常敏感。p1_1 通過只是取樣落在低點，兩趟本質相同。
- 所以 p1_2 的「停止有效未通過」不是手臂沒停住，是估計方式把接觸抖動當成速度。但這是我的判讀，門檻不放寬。

**提案（判準估計方式變更，需你裁定）**
- S1：門檻值 1e-3 rad/s 不變，估計改成「停止後第 0.5–1.5 s 窗內，各關節位移對時間的最大窗口速率（窗長 0.5 s）」。另加峰峰值上限 1e-3 rad，避免低頻擺動被窗口平均掉。底盤同理（窗口位移速率 < 0.01 m/s）。
- S2：停止估計維持單步，但改善接觸中保持策略，例如停止時若在 LOWER 且已接觸，先把下降目標回抬 1–2 mm，讓瓶離開桌面、消除接觸跳動。代價是停止動作會改變物件狀態。
- 我建議 S1：它反映的是「是否還在運動」的原意，抖動幅度另有峰峰值約束。S2 改的是停止行為本身，風險較大。
- 既有趟次不回改判定，p1_2 仍記為停止無效。

**第二項（接觸就緒→釋放→獨立支撐）** 還沒開始，等這項裁定後一起做離線設計與假世界負測。
