# V1 視覺旁路：選相機結果與設計 draft-1（請確認後我實作估計器與合成資料核對）

設計全文寫在 第七次進度報告素材/規格/瓶子第二桌放置_最小設計.md 的「V1 視覺旁路設計」一節。

**選相機**（純幾何，沿 bottle_p1_3 量測軌跡）
- 底盤相機（URDF base_camera）：
  - 導航段 1.8–3.4 m：70% 看得到，瓶寬 3–6 px。
  - 展臂接近 0.5–1.8 m：53%，6–20 px。
  - PREGRASP 以後：0，瓶在車側出視野。
- 手腕相機（門任務用過，hfov 69°）：
  - 導航段：61%，4–8 px。
  - 展臂接近：30%，8–100 px（手臂在轉）。
  - PREGRASP 看得到（0.14 m、100 px）；INSERT 13%；CLOSE 0。
- 選底盤相機：外參固定，接近段一路可見。手腕留作 V1b 近距補強。
- 限制：遠距瓶寬只有幾個像素，遠距誤差會大，結果會依距離分層報告。

**設計要點**
- 時間戳：模擬時鐘擷取時刻。
- 內外參：URDF 外參加讀回內參；擷取時刻相機位姿由底盤量測位姿乘外參，並和渲染端回讀核對。
- RGB 與深度對齊：同一渲染產物、同一擷取時刻。
- 估計器：深度反投影 → RANSAC 桌面 → 桌上點分群 → 已知瓶型固定半徑圓擬合 → 瓶中心與軸方向。不估繞軸朝向，不用真值遮罩或 ROI。
- 架構：估計節點另一程序走 ROS，記資料年齡與處理耗時。
- 評估：有效率、xy／z 誤差、軸角誤差，依距離與相位分層；沒有估計就記失敗。
- 不進控制，物理步與控制週期不改。
