## 文獻依據：實驗要回答什麼

1. Burgess-Limerick et al., *An Architecture for Reactive Mobile Manipulation On-The-Move*：接近／最後操作／全身分配，實驗比較 pick-and-place 的時間、成功、運輸效率與 gracefulness。不能說他們只停車或沒有聯合控制。
   https://arxiv.org/html/2212.06991v1 （§III–V）
2. Burgess-Limerick et al., *Reactive Base Control for On-The-Move Mobile Manipulation in Dynamic Environments*：靜／動態避障、轉彎成本、下一目標；§VIII-1 明述其該版本未預測障礙運動，§VIII-2 說明二維掃描替代手臂三維幾何的限制。可據此設計預測運動與持物幾何的配對比較，不能說 MotM 沒有避障。
   https://arxiv.org/html/2309.09393v1
3. Haviland et al., *A Holistic Approach to Reactive Mobile Manipulation*：全身反應式控制、隨機到達與重複取放。反應式全身 QP 是合理比較方向，不是虛構停車稻草人。
   https://arxiv.org/html/2109.04749v2
4. Wang et al., *Whole-Body Model Predictive Control for Mobile Manipulation with Task Priority Transition*：時域內任務轉換，對照追蹤、過渡峰值速度及受擾。應以底盤／末端過渡實際運動檢驗順暢，不能把單一控制器當成首創。
   https://wbmpc.github.io/static/pdfs/paper.pdf （§IV-B/C）

以上為設計來源，不表示已完整重現這四套方法；外部移植不忠實時一律稱「受文獻啟發的移植基線」。
