- PCK 淨空、自碰、關節餘裕兩案相同；最小值都出現在兩案一致的抬升與持瓶段。
- 外伸淨空閘：兩案的觸發邊距都是 inf，監看最小值未更新（報告欄位為 None）。這表示假世界裡外伸掃掠點從未落入桌面區；兩案相同，我沒有再往下查。

**未過點的成因**（除錯程序量到）
- 48.55 s 是 HOLD 的第一拍，放置控制器使用停車 MPC，底盤速度界為 0。
- 回傳命令 u_opt＝[0, 0, 0]；xi_ref[0]＋δ₀＝[~1e-26, ~1e-25, **−9.73e-10**]。
- `gmpc_wb` 的一致性判定是 `np.allclose(u_opt, xi_ref+δ₀, atol=1e-12, rtol=0)`，差值 9.7e-10 超過容差 ⇒ seq_consistent False ⇒ 回退並受控停止。
- 全趟 972 次判定只有這一次不一致，其餘差值都 ≤ 2e-16。基線趟沒有碰到。
- 看起來是零速界停車 MPC 的數值殘差，碰上 1e-12 的嚴格容差；與外伸時長沒有物理上的關聯，是時序位移後才碰到。
