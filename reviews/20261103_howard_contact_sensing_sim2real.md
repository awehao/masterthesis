# Howard 補充要求：接觸力與瓶底間隙是實機移轉的關鍵缺口

日期：2026-11-03（Asia/Taipei）。Howard 指出：「接觸力與瓶底間隙目前仍來自模擬器，尚未完成實機感測方式的驗證，這會是之後實機的大問題，請加入考量。」

本檔新增實機移轉的設計與驗收要求，不更改目前控制、判準或實驗結果，不授權感測器採購、訓練或實機／模擬起跑，也不撤銷已核可的模擬任務。後續設計與報告須明示此缺口，不再只以「真值安全網」一語帶過。

## 1. 不只是評分：已影響控制流程

目前即使抓取目標 xy／支撐高度已改由視覺取得，下列狀態仍依賴模擬接觸回報或模擬瓶位姿／桌面幾何：

| 用途 | 現行來源與依賴 | 實機化缺口 |
|---|---|---|
| 抓持證據、失抓 | 每指對瓶接觸力與時間連續條件 | 實機是否有對應感測、能否辨識夾住瓶而非碰到桌面，尚未驗證 |
| 初段抬升參考切換 | `bottle_w1_liftb_ctrl`：抓持成立、桌面力 ≤0.02 N、瓶底間隙約 ≥11 mm，持續一控制週期 | 這會改變全身任務參考，不是事後評分；不能把模擬器的桌面力和瓶底真值視為實機現成訊號 |
| 完整離桌確認 | `bottle_s0_logic`：桌面力、瓶底間隙 ≥40 mm 與持續時間等條件 | 與初段參考切換是不同事件，兩者都需要可觀測性與延遲驗證 |
| 放置／鬆爪准入 | `bottle_place_ctrl`：瓶對第二桌的支撐力、幾何間隙、傾角與時間條件 | 普通居家桌面不預設裝有測力設備；實際卸載／支撐證據尚未接通 |
| 滑移與持瓶包絡 | TCP FK 與模擬瓶位姿形成的相對變換 | 不能以「瓶永遠固定在夾爪內」取代滑移觀測，或據此宣稱瓶底淨空可靠 |

瓶底間隙目前由模擬瓶底位姿、瓶軸傾斜及桌面高度算出，不是 RGB-D 已直接量到的瓶底間隙。圖像被手指遮擋時，不能假定該量仍可觀測。上述數字僅說明現行模擬設定，不是可直接搬到實機的門檻。

## 2. 感測設計原則（待實作、待驗證）

- 先盤點實機確實可取得的夾爪位置／電流、關節狀態、腕部力矩、觸覺與 RGB-D 介面；未確認硬體與校正前，不宣稱已有任一接觸感測能力。
- 桌面對瓶作用力不等於夾指接觸力，也不等於夾爪馬達電流或腕部受力。若改為由其他訊號推估卸載／承重狀態，應標為「估測狀態」，交代重力、動態負載與偏移影響，不能沿用「實測桌面力」名稱。
- 瓶底間隙可研究由可見深度、支撐面估計及抓持相對位姿融合取得；但遮擋、瓶型先驗與滑移不確定性必須傳遞。僅由 TCP 上升不能證明瓶已跟著離桌。
- 將觀測／估測介面與事後真值評估分開，逐項帶來源（感測／估測／模擬真值）、擷取戳、座標系、有效旗標、年齡及誤差描述。禁止在資料失效時靜默回填模擬真值。
- 例如未來可用間隙保守下界 `g_lower = g_est - error_bound` 判斷，而不是只比較點估計；誤差界必須包含幾何、標定與延遲影響並經驗證。無法建立有效誤差界時，標為未知，不能把形式上的下界當成保證。
- 現行判定含 `pose_fresh_s = 0.02 s`，而相機是約 5 Hz，還有傳輸與處理延遲；不能直接把影像輸出接到原高頻真值接口，也不能只放寬期限來消除失效。須設計非同步狀態估測與不確定性／時效處理，再重核參考切換和停止行為。
- 缺測或矛盾時不宣告新抓持、離桌或支撐成立；持續監看、逾時及安全處置須另核對，不能靠永久等待或沿用過期狀態冒充安全。

## 3. 後續最小驗收路線（不是本次起跑授權）

1. **訊號／用途盤點**：列出每個相位准入、幾何閘與評分用到的量，哪些有實機感測、哪些需估測、哪些目前不可觀測。
2. **模擬中隔離真值**：候選觀測器只讀實機可提供的訊號；真值只在獨立評估端。以噪聲、偏移、延遲、遮擋、不同步和斷流核對錯誤准入及拒絕行為，不拿理想模擬精度代替實機證據。
3. **實機小範圍對照**：在受保護的抓持、微抬升、放置情境，以獨立量測比對事件判斷；先驗證感測與判斷，不直接從完整移動抓放開始。
4. **通過後才接 MotM**：重核誤判抓持／離桌／支撐、錯誤鬆爪、事件延遲、可觀測率、缺測處置與停止後物件保持，再申請整合實機試驗。未建立實機停止品質前，不宣稱相同安全性。

實機感測缺口尚未解決前，模擬可以繼續累積方法與任務證據，但不能稱為「視覺接上後即可直接居家部署」。不要求先把所有感測研究做完才執行已核可的模擬，也不把這項要求變成另一串同配置重跑。

## 4. 報告採用的限制文字

> 目前抓持、離桌參考切換與放置鬆爪的部分准入條件，仍使用模擬器接觸力及由模擬瓶位姿／桌面幾何計算的瓶底間隙。這些量尚未由實機感測或估測驗證，是全身協調流程實機移轉的關鍵缺口；視覺目標接入不等於接觸狀態感測已完成。
