# B2 最小版：定義、符號與限幅核對、真管線強制晚到停止（申請第九趟）

commit 2029c5568（已推）。Isaac 未跑。綁定恢復剛性（B3 程式保留、預設關）。

## 1. 定義（evaluation/door_preload_release.py）
- 輸入：外界對夾爪的旋量 W_ext＝(F, M)，世界座標、作用點 TCP。執行器每物理步算：joint6 量測（link6 座標、link6 原點）轉世界＋下游（link6／夾爪／兩指）模型重力，扣**自由狀態基線**（前導 0.1–0.4 s、未接觸時同式殘差的平均：力在世界座標、力矩在 link6 座標），取負，再把力矩換到 TCP（含力臂項）。基線不在接觸後重取；樣本不足或非有限 ⇒ B2 不啟用。
- 運動／約束分離：門只容許繞世界 z 過原點的鉸鏈轉。τ_h＝(p×F＋M)·ẑ；等效切向力 λ＝τ_h/|p_xy|；約束反力 W_c＝(F−λ·t̂, M)，對鉸鏈軸力矩為零。只釋放 W_c，λ（開門負載）不動。
- 偏置律：δ̇＝KI·JᵀW_c/kp，KI＝2.0 /s；每關節 |δ̇|≤0.02 rad/s、|δ|≤0.03 rad（夾住，不再累積）；輸入非有限該拍不更新。每控制拍更新一次（20 Hz）。
- 命令鏈：δ 加在手臂設定點目標（開門閉鏈手臂全部節點、提早派工的那一筆、閉鏈一致停法同式），所以經 u＝(S−s)/DT 進速率／加速度／設定點限位驗收、在途管線、候選核對與停止預測（預測期間 δ 視為定值）。同時把內部受控對象模型的穩態偏置改為 bias0−α·δ——δ 等同「靜態偏置估計的修正」，預測的關節位置不因 δ 位移（剛性綁定下手臂不會跟著 δ 動）。執行器末端沒有另加補償。

## 3. 真管線強制晚到停止（door_cstop_check_r8.json，b2_release）
真入口（DoorOpenExec.step，旋量由同一局部模型提供；假世界手臂以「δ 由約束吸收」的剛性替身）：開門 3.0 s 強制晚到 ⇒ 閉鏈一致停法（現在停預測閉鏈 2.24 mm）⇒ **1.02 s 停穩**、底盤保持啟用、無中止；約束反力 218→0.5 N（停止時）→0.14 N；δ 最大 9.3 mrad、未飽和；手臂命令最大 0.078 rad/s。既有八案（B2 關）逐值不變。名目鏈（B2 關）2 次開完，中位 32.5–33.1／最大 40.6–42.2 ms。
- 中間踩到的一點（已修）：最初 δ 只加在設定點、沒改內部模型偏置，假世界自由手臂被 δ 推近橫桿，停止掃掠判淨空違反——所以才把 δ 定義成偏置估計的修正。

## 4. 照實的限制
- B2 是低頻的：第 7、8 趟的力在開門命令生效後一拍內就到 28–30 N、峰值 33.6／39.07 N。以 0.02 rad/s 的變化率，要釋放約 10 mrad 級的偏置需 0.5 s 以上 ⇒ **起步峰值不會因 B2 而明顯降低，仍可能碰 40 N 中止**。B2 針對的是靜止時的 26–29 N 與其造成的腕部逐步抖動（假說）。
- 基線以模型重力為準（下游質量模型比 Isaac 少約 1.7 N，由基線吸收）；姿態改變後基線的力矩分量有近似。
- 約束／運動分離假設鉸鏈在世界原點、門軸鉛直（與現有門模型同）。
- 期限未解：Isaac 內前幾拍仍可能晚到。
