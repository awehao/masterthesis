## 判讀與命名

- 成功／失敗依整體任務判定，不以單一階段或影片產出成功代替。
- 30°成功僅支持持續主動保持期間的停止，不代表撤除保持後仍停住、實機能力或安全驗收；其暫停期手指驅動上限為20 N，屬執行器上限變更。
- 既有影片保留歷史命名；2026-10-29 起的新影片依上方日期時間置前規則命名，同名 `.mp4.keymoments.json` 保存關鍵時刻。
- 重播只渲染原趟姿態，不重新執行控制；來源與逐幀核對紀錄在 `evaluation/runs/`。
