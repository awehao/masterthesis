1. 整體目標：起點 → 開門 → 通過中關門 → 開關抽屜 → 返回。這是目標，尚非已完成的同趟成果。

3. 已通過的單趟 60° 開門與主動保持停止：有影片，非通行成果。
4. 約 47.74° 的繞行開門接觸證據：獨立判定未通過，不能改稱可靠成功。
5. 通過中拉關：舊版完整串接的離線名目模型；不是 Isaac 接觸實跑。
6. 最新換抓：承接實錄控制狀態的名目追蹤與待整合部分，不能接到舊版數字後冒充同趟。
7. 視覺預抓取與誤差契約：放備用頁，必要時移入主頁。

## 影片與圖像

成功開門和繞行開門的截圖，皆從既有「實錄姿態重播」影片擷取；沒有新增控制或物理模擬。PowerPoint 影片文字是指向原有影片的超連結，沒有把多支影片嵌入簡報。

跨電腦移動時，請一併攜帶 `第七次進度報告素材/影片/` 並重新連結；可直接用原資料夾播放側視與近景。PDF 超連結是否可開啟本機檔案取決於閱讀器權限。
