## 0. 核心段範圍（A-1）

**只驗**：繞緣持握成立後，協同開門到約 48°，觀察開門末段的出口繞行，再沿既有受控結束路徑收尾。受控結束路徑即 W 系列的 SETTLE → 受控暫停 → 主動保持停止 → DONE。

**不做**：放手、收臂、穿越，也不做導航接近。

**實驗初始化（須揭露）**：
- 執行端以 `--start-pose` 把底盤直接放在停位，不經導航接近。
- 手臂由 K2_READY 經既有展開節點展開到繞緣預抓取構型。
- 這不算自主抓取成果。

**來源**：聯合搜尋 q48 候選（`door_coopen_joint_v2_phi60_s0.85_q48.json` full[0]），以及核心控制 v2 的設定（`door_coopen_wgmpc_v2`）。

## 2. 繞緣夾持證據與中止規格（B）

沿用 K3-M／W 系列既有准入與中止，條件不放寬：
- 兩指接觸（contact_min_n 0.5 N）、閉合開度、腕力 30 N 保護、一般幾何監看（d_min 5／5／20／5 mm＋預測）、走廊（內帶與外帶）、狀態新鮮度。
- 接觸失效、幾何不足、走廊越界、狀態過期 ⇒ 中止閂鎖，**不自動加力、換抓或重試**。

**新抓法另加的准入（ENGAGE → HOLD）**：
- 兩指首觸開度都落在離線契約範圍 ±0.5 mm 內（契約 1.8／1.6 mm）。
- 夾持後 TCP—把手相對位姿的線上估計，與凍結把手位姿之差在既有對齊門檻內（K2 誤差 < 2 mm）。
- 不另訂新門檻。

**禁止**：
- 不得以離線徑向殘差約 4 mm 為依據，另訂一個容許它通過的新門檻。
- 不得只以「有兩指力」宣稱穩定持握。
- 持握穩定只以全程無失接觸中止、相對位姿漂移在既有門檻內，兩者一起作為證據。

## 3. 接入真鏈（C）

- 沿用 W1e／W2c 的單一命令來源：ADM9／11 → adapter → E2 → 執行端。
- 版本化（複本，不改原檔）：
  - **任務節點**：讀完整 T_HG 4×4 與 a_H（grasp_basis 擴充欄位 `T_HG_full`、`a_H`；沒有這兩欄時行為同原版）；門速取自登錄檔。
  - **登錄檔** `coopen_core_params_48.json`：θ、門速、OPEN 逾時、走廊表＋sha256、包絡（同 W1e 規則：±40 mm／±4.5° 在參考位姿座標合成角點）、觀察器上限 θ＋4°、引導設定、協同話題。
  - **跑法** `run_door_coopen_core.sh`：STAND、Q_PRE、登錄檔、凍結核對。
- **座標與錨點**：走廊與引導都用以 STAND 為錨點的同一張表。初始承接沿用 W 系列握手，不重設底盤位姿。初始追蹤誤差照實記錄：表起點等於候選起點，因為平滑採縮窗，0° 點仍可能偏移，會照實報出。
- **相位開關**：引導只在 OPEN 啟用，PAUSE 起 w_vref＝0（同 W1e）。

## 4. 假世界測試
- 正常路徑：UNFOLD → 對準 → 接近 → 夾持 → OPEN 到 48° → SETTLE → PAUSE → DONE，命令來源單一、相位與引導開關正確。
- 中止傳遞（三種）：
  - 失接觸：finger_contact_lost 閂鎖；
  - 幾何越界：geometry 中止；
  - 狀態過期：stale 中止。
- 既有測試能覆蓋的部分直接引用。
