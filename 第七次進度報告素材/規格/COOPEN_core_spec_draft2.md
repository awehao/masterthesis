## 0. 範圍（同 draft-1）
**只驗**：繞緣持握成立後，協同開到 48°，觀察開門末段的出口繞行，再沿既有受控結束路徑收尾（SETTLE → 受控暫停 → 主動保持停止 → DONE）。

**不做**：放手、收臂、穿越，也不做導航接近。

**實驗初始化（揭露）**：
- 底盤以 `--start-pose` 直接放在停位。
- 手臂由 K2_READY 經既有展開節點到繞緣預抓取。
- 不算自主抓取成果。

## 2. 量測（A-2；已實作於判定器報告，只報告）
- **門關節實測角**（room_run `door_q_rad`）與 **TCP 推得門角**（FK(base_xyth, q_arm_meas)·T_HG⁻¹ 的把手方位）之差。
- **TCP—把手完整相對位姿殘差**：取證 T_WH·T_HG 對 FK TCP，報把手座標三軸位置與姿態角。
- **出口進展**：實測底盤位姿在門角包絡 [46, 53]° 淨空場上的雙線性測地距離；報首次達 38° 到紀錄末的變化，以及下降輪次中門關節速率 > 0.05 °/s 的占比（輪次占比，不是進展量占比）。
- **命令分層**：執行端套用底盤命令（合速度、每軸、偏航最大值）、applied_src 分布；任務端引導開啟筆數沿用 w1b 判準。
- **離線一致性測試**（`test_door_coopen_check_core.py` D3）：以候選軌跡合成的理想資料，TCP 推得門角與門關節角之差 ≤ 0.05°，殘差位置 ≤ 1 mm、姿態 ≤ 0.1°。

## 3. 繞緣夾持證據與中止規則（B）
**全部沿用既有規則與門檻，不新增、不放寬**（K2Config／K3AConfig／K3M）：

**准入**：
- 預抓取對準誤差 ≤ 5 mm；
- 接近 0.02 m/s；
- 夾持前對準誤差 < 2 mm 持續 0.5 s 才閉爪；
- 閉爪後兩指對橫桿接觸各 ≥ 0.5 N 並持續（contact_held）才進 HOLD。

**中止（閂鎖，不加力、不換抓、不重試）**：

| 類別 | 門檻 |
|---|---|
| 失接觸 | 單指 < 0.1 N 持續 0.2 s ⇒ finger_contact_lost |
| 夾持漂移 | TCP 對「夾持時凍結的把手關係」：平移 5 mm、旋轉 2° ⇒ grasp_drift |
| 腕力 | 30 N |
| 門速 | 0.05 rad/s |
| 門角 | 超出 [−1°, θ＋1°] |
| 底盤漂移 | 20 mm／2° |
| 狀態年齡 | 0.2 s |
| 求解器狀態 | 0.5 s |
| 幾何監看 | d_min 5／5／20／5 mm＋預測 |
| 走廊 | 內帶 20 mm／0.8°、外帶包絡 |
| 觀察器 | 52° |

- **與 draft-1 的差異（揭露）**：draft-1 寫的「新抓法另加准入（首觸開度落在契約 ±0.5 mm、夾持後相對位姿差）」**本版不實作為准入**，以免新增未經審的門檻。首觸開度與相對位姿殘差改列 A-2 報告；夾持後相對位姿由既有 grasp_drift（5 mm／2°）持續監看。
- **主要風險（照實）**：離線閉迴路的持握幾何閉合殘差，徑向最大 3.6 mm，相對 grasp_drift 平移門檻 5 mm 只剩約 1.4 mm 餘量。實跑若中止，最可能是 grasp_drift。依規則不調門檻。
- 不得以「有兩指力」宣稱穩定持握。持握證據＝全程無失接觸中止，且 grasp_drift 未觸發。
