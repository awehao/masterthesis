## 1　任務拓撲（同一趟、不拼接）

```
起點（外室） ─導航→ 門前停位 ─開門（全身）→ 釋放・收臂 ─導航穿門→ 內室
   → 抽屜停位 ─開抽屜／關抽屜（全身，沿用）→ 收臂 ─導航→ 門前（內側）─穿門→ 外室 ─導航→ 起點
```

| # | 相位 | 控制權擁有者 | 前往下一相位的必要條件（實測） | 狀態 |
|---|---|---|---|---|
| P0 | NAV_TO_DOOR | 導航（gmpc_node） | 進交棒區、速度進全身速度框（`check_nav_handover`） | 沿用；路徑需改多段 |
| H1 | 交棒 導航→全身 | 執行層 `DualSourceExecutor` | 交棒閘門 13 項 | 沿用；需支援第 1 次 |
| D1 | DOOR_ALIGN／ENGAGE | 全身（W-GMPC） | 預抓取到位、每指接觸力夾持成立（沿用抽屜判準） | 對位／夾持沿用，目標改門把 |
| D2 | DOOR_COOPEN | 全身（底盤＋手臂） | 實測門角達 θ_open（由通行幾何定，非固定 90°）並保持 | **新**：圓弧目標 |
| D3 | CLEARANCE_CHECK | 全身（保持） | 釋放後剩餘路徑可行、門角／角速在保持界內 | **新** |
| D4 | RELEASE | 全身（夾爪） | 每指接觸 < release_max_n 且張開 ≥ 80%（沿用） | 沿用 |
| D5 | RETRACT／RESTOW | 全身→關節空間收臂 | 夾爪脫離把手間距＋收攏姿態到位（沿用 j3 最後動） | 沿用；脫離方向需改 |
| B1 | 交還 全身→導航 | 執行層 | 交還確認 | 沿用；第 1 次 |
| P1 | TRAVERSE_IN | 導航 | **整機越界餘裕 c_exit ≥ m_exit** ＋門框開口內＋入口區保持 | **新**：穿門判定 |
| P2 | NAV_TO_DRAWER | 導航 | 同 P0 | 沿用（室內段） |
| H2 | 交棒 導航→全身 | 執行層 | 同 H1 | 第 2 次 |
| W | 抽屜 ALIGN…RESTOW | 全身 | 沿用現行判準（開 200 mm、停、關、停、放、退、收臂） | 沿用（見 §3 Q2） |
| B2 | 交還 全身→導航 | 執行層 | 同 B1 | 第 2 次 |
| P3 | NAV_TO_DOOR_INNER | 導航 | 門前內側停位；**再量門角** ≥ θ_pass | **新**：返程門狀態閘門 |

同一時刻只有一個命令擁有者；每次交棒／交還都是顯式事件並記錄。導航目標發出或把手到位**不算**穿門。

## 2　首版假設（全部明示；違反即不屬本版）

| 面向 | 首版設定 | 界線 |
|---|---|---|
| 場景 | 新世界：外室＋內室，中隔牆含門框；抽屜櫃移入內室；牆、門框、地面為靜態碰撞幾何 | 不沿用現行四面封閉房間假裝有門 |
| 門 | 單扇、已解鎖、無閉門器、被動 revolute；鉸鏈位置／軸、質量、慣量、阻尼、摩擦、限位讀回 | 不直接命令門角度、不瞬移、不鎖定門角度冒充通行 |
| 開門方向 | 從外室側**拉開**（計畫 §6.2 優先）；返程時機器人在推側，門已開，**不接觸門**穿過 | 推門、左右鉸鏈、雙向門另立版本 |
| 把手 | 沿用已驗收夾持的 bar26 型橫桿（同摩擦夾持判準），裝在門板；高度與離鉸鏈距離由離線可達性定 | 門把高度可能低於日常門（為可達性）——須揭露 |
| 開門角 θ_open | 由「收攏姿態整機 ＋ 門板厚度 ＋ 門框」通行幾何反推，取保守側；首版凍結一個值 | 不固定假設 90° 必要或充分 |
| 返程 | 首版**不再次開門**：返程前量門角，未達 θ_pass ⇒ 中止（記錄門回動） | 有閉門器／回彈另立版本 |
| 抽屜 | 沿用現行抽屜資產、開 200 mm、關回（見 Q2） | 本版不取物，不稱 D5 取放與關閉整合驗收 |
| 目標來源 | **已知場景／真值基線**：門把位姿、門角、抽屜把手位姿用 USD 真值；/odom 真值 | 不稱視覺閉迴路成果；視覺目標來源另行驗收 |
| 導航 | 真 gmpc_node；/plan 由已知地圖產生**多段路徑**（門前停位 → 門框中線 → 入口區 …）；CBF 現為關閉 | 線上無門框／門板避碰 ⇒ 靠離線幾何核對＋執行時監看（見 G6） |
| 底盤／致動 | 沿用速度驅動根部、輪級限制、低速介面界限、關節限制、30 N 手腕保護、92 °C 中止線（沿用的工程中止線） | 不放寬任何限制 |

## 3　缺口盤點（G）與驗證層級

| G | 缺口 | 工作 | 驗證層級 |
|---|---|---|---|
| G1 | 場景／門資產 | 雙室世界、門框、鉸鏈門（版本化資產＋讀回）；Isaac 端發 `/door/state`（門角、角速、把手真值位姿） | 讀回＋無外力靜置／正反向短推（M1） |
| G2 | 門把局部目標 | 旋轉版 `opened_handle_pose`（T_WH(q_d)＝鉸鏈軸旋轉，把手方向隨門轉）；DL1 `object_target` 直接吃 T_WH(q_d) | 單元測試（等距性、q=0 一致、方向隨門轉） |
| G3 | 開門目標產生器 | `DoorTarget`（類比 `DrawerTarget`）：依**實測門角**有界超前；底盤參考速度／名目姿態（MotM 協同項）沿用框架 | 離線閉迴路（重播式）＋單元測試 |
| G4 | 任務相位機 | `DoorTaskPolicy`（D1–D5）＋整趟編排：三次交棒（H1、H2）、兩次交還（B1、B2）、返程門狀態閘門 | 相位機單元測試（含逾時、首次達標不被抹除） |
| G5 | 多次交棒 | 現行任務節點只做一個循環（`handback_sent` 單次）；`ControlAuthority` 是否支援來回多次須核對並補反例 | 執行層單元測試＋功能確認 |
| G6 | 穿門判定與幾何 | c_exit（全身碰撞幾何：底盤、收攏手臂、夾爪、相機凸包，沿用 GC2 外殼）、門框開口內判定、對門板／門框／牆最小間距；**離線**：路徑×收攏姿態掃掠 vs 門板在 θ_open／θ_pass | 離線幾何（先做） |
| G7 | 多段路徑 | 已知地圖的分段路徑（門前停位、門框中線、入口／出口區）；GMPC 追蹤分段路徑的轉角行為 | 離線＋功能確認 |
| G8 | 開門可達性 | 門把高度／離鉸鏈距離／停位：手臂在 D1–D2 全程的可達性與關節餘裕（離線 IK 掃描） | 離線（先做） |
| G9 | 故障處置 | 見 §4 | 規格先定、單元測試 |
| G10 | 紀錄與判準 | 門角／角速、命令所有權時間線、c_exit、接觸事件來源（`undesignated_contact` 現無量測，須揭露或補） | 規格先定 |

## 4　事前定義的中止與處置（首版）

| 事件 | 偵測 | 處置 |
|---|---|---|
| 開門中夾持失效（單指接觸 < 門檻持續） | 每指接觸力 | 停止門角推進；底盤／手臂保持；記錄 grasp_slip；**不自動重抓**（首版） |
| 手腕 ≥ 30 N | 既有保護 | 既有停止路徑；記錄 |
| 開門未達 θ_open（逾時／停滯） | 實測門角 | 保持→釋放→收臂→中止；不改 θ_open |
| 釋放後門回動（角速超界、角度跌破 θ_pass） | `/door/state` | 不進 TRAVERSE；中止並記錄；不鎖門 |
| 穿門中間距不足／門角跌破 θ_pass | 執行時幾何監看 | 導航停車；中止（不倒退穿越，避免困在門框） |
| 返程前門角 < θ_pass | P3 閘門 | 中止（首版不再次開門） |
| QP 不可行／求解失效／命令逾時 | 既有 | 既有受控停止 |
| CPU ≥ 92 °C | 守護 v2 | 熱中止 |

## 5　執行順序（每一步通過才進下一步）

1. **離線幾何**（不開模擬）：G8 可達性掃描定門把高度／停位；G6 通行幾何定門寬、θ_open、θ_pass、m_exit 候選；G7 路徑。結果送審後凍結場景參數。
2. **離線接線**：G2／G3／G4／G5 單元測試與反例。
3. **小範圍功能確認**（開模擬、各自有界）：門資產讀回＋被動短測（M1）→ 固定底盤短弧開門 → 協同開門到 θ_open＋釋放收臂 → 單獨穿門（門預先開在 θ_open 的對照幾何，只驗穿門判定，不算任務成功）。
4. **單趟端到端**：§1 全程一趟，失敗也保留。
5. 之後才談正式重複、方法比較（SEQ／B／P）與泛化。
