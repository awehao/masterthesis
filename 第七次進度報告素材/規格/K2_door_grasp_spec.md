# K2：局部通行門 v2 的固定停位對準與夾持（draft-1，2026-10-21；規格，未實作、未執行）

**只回答**：機器人在候選停位，能否在門關閉狀態下安全建立、保持並解除把手夾持。**不推進門角、不承載開門、不宣稱可開門。**
上位：Codex 20261021 裁定（K1 v2 部分驗證後可做 K2 離線與規格；K2 實跑另核）。

## 1. 場景與起始
- 門 `door_local_v2`（`door_asset_v2`，門根在世界原點、yaw 0）＋地面；機器人 omni_bot＋Lite 6（現行 URDF／USD 與抽屜實跑同版）。
- **不導航**：機器人直接生成在候選停位（見 §6 Q1），手臂起始收攏姿態（START_MODE=spawn 同既有）。這是 K2 的明示簡化；導航到停位屬後續整合。
- 夾持面摩擦：手指＋把手橫桿綁同一明寫材質 μs 1.0／μd 0.8（同抽屜實跑），讀回實際綁定。
- 熱監控 v2（coretemp）＋ 92 °C 中止線；新 RUN_ID、每趟獨立保存。

## 2. 控制與目標
- 底盤：**正常控制保持**——W-GMPC 增廣核心 H5（與 DL3 實跑同權重）＋PARK_HOLD v2.1 停車伺服（錨點＝生成後實測位姿），不凍結剛體；量測實際位移／偏航。
- 目標：`object_target(T_WH_meas, T_HG, a_H, s)`，T_WH_meas＝**實測**把手位姿（門角取實測 q，不另推進），T_HG＝實錄基準（6.8 mm），a_H＝(0, −1, 0)（退讓離門扇）。
- 相位（沿用抽屜任務的實測推進，不靠時間到期）：
  1. ALIGN：先到 s = 0.10 預抓取；誤差 < pre_tol 後以 approach_rate 把 s 斜坡到 0（沿用抽屜值）。
  2. ENGAGE：誤差 < grip_tol 持續 grip_settle_s 後，close_ramp_s 內閉爪；**雙指**接觸力各 ≥ contact_min_n（0.5 N）持續 attach_hold_s ⇒ 夾持成立（沿用抽屜判準），當下以實測 TCP／把手建抓取關係。
  3. HOLD：保持 3.0 s；目標＝實測把手位姿 × 抓取關係（零超前，不推門）。
  4. RELEASE：張爪；每指接觸 < release_max_n 且張開 ≥ 80% 持續 release_hold_s ⇒ 解除確認。
  5. RETREAT：s 0 → 0.10；結束後停在退讓位（K2 不收臂、不交還導航）。
- 所有抽屜相位參數沿用現行凍結值，逐項在實作的規格副本登錄，不為門另調。

## 3. 量測（逐步時戳）
實測門角 q／q̇（`/door/state`）、把手實測位姿、TCP、雙指接觸力、腕力（既有量測與 30 N 保護）、抓取漂移（`DoorTarget.drift_vs` 同式）、底盤實測位姿／速度、命令（求解／安全層／套用）、相位轉移與首次達標事件；**門扇／牆對機器人非手指連桿的接觸力**（contact force matrix，作為非預期接觸來源——抽屜流程目前沒有此來源）。

## 4. 事前登錄的中止條件（觸發即受控停止並記錄，不重試）
| 事件 | 偵測 | 處置 |
|---|---|---|
| 非預期門角 | \|q\| > 2° 或 \|q̇\| > 0.05 rad/s（ALIGN／ENGAGE／HOLD） | 停止推進；若已夾持先張爪再退離 |
| 抓取漂移 | HOLD 中 drift > 5 mm | 張爪、退離 |
| 單指失接觸 | HOLD 中任一指 < contact_min_n 持續 0.2 s | 張爪、退離 |
| 腕力 | ≥ 30 N（既有保護） | 既有停止路徑 |
| 非預期接觸 | 門扇／牆對非手指連桿 > 0.1 N | 停止；退離 |
| 底盤偏移 | 相對錨點 > 20 mm 或偏航 > 2° | 記錄違規；停止 |
| 求解失效／命令逾時 | 既有 | 既有受控停止 |
| CPU ≥ 92 °C | 守護 v2 | 熱中止 |

## 5. 判定（全部成立才「K2 通過」；任一缺資料 ⇒ 未驗證）
夾持成立（雙指、持續時間）；HOLD 3 s 全程 drift ≤ 5 mm、雙指持續接觸；全程 \|q\| ≤ 1°、無中止事件；解除確認；退離完成；腕力 < 30 N；非預期接觸 ≤ 0.1 N；底盤 ≤ 20 mm／2°。另報：夾持時實際 TCP 對目標誤差、接觸力分布、關節餘裕、j3 行為。
