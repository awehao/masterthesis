## 2. 兩項規格變更
**(a) 5 mm 追蹤落後：以 s_meas 查表的幾何推導與格點間覆蓋**
- 比較對象：任務端每輪樣本以「上一輪已發布、目前正被追蹤的目標」s_cmd 與本輪量測 s_meas 比較。
  - r1 先推進再取樣，量測比的是尚未發布的新目標，平白多一個週期。
- 推導：
  - 線上門角帶以**實測 s_meas** 查表（取不大於 s_meas 的最大格點），幾何前提只與工具實際位置及門角有關，與 s_cmd 無關。
  - 所以追蹤落後不改變帶的依據，前提是帶在每個實際 s 都成立。
  - 離線 ey ±1 mm 是對實測 s 的量測／模型誤差擾動，**不是**格點量化餘量。
- 格點間覆蓋：
  - `door_k3b_offline_v4d.py`：逐 0.5 mm 取 s（涵蓋 2.5 mm 與 10 mm 格距內所有中間點），以線上同一查表函式的上界與下界 −1°，套 v4c 同一剛體擾動驗證。
  - **v4d 以 draft-2 帶執行，發現缺陷**：s 0.020～0.0245 m、Δ＋0.5° 時，退出後配對只有 2.15～4.97 mm（< 5 mm），10 點不成立。
    - 根因：draft-2 帶取自 v4c 摘要的「成立 Δ 之最大值」，沒有要求「自 0 起連續成立」。
    - 門再轉越過橫桿後配對距離又變大，致 s 0.02 處誤判上界 +5°。v4c 原始數值與 v4d 一致，錯在摘要規則。
  - 帶 r3：以 v4c 原始資料「自 0 起連續成立」重算，再取 running min：

    | s_meas（m） | 上界 Δ |
    |---|---|
    | [0, 0.0025) | +0.1° |
    | [0.0025, 0.0225) | **+0.15°** |
    | [0.0225, 0.025) | +0.3° |
    | [0.025, 0.03) | +0.5° |
    | [0.03, 0.0325) | +0.75° |
    | [0.0325, 0.0375) | +1.0° |
    | [0.0375, 0.04) | +1.25° |
    | [0.04, 0.0475) | +1.5° |
    | [0.0475, 0.06) | +2.0° |
    | [0.06, 0.08) | +3.0° |
    | [0.08, 0.09) | +4.0° |
    | ≥ 0.09 | +5.0° |

    下界 −1° 不變。
  - `door_k3b_offline_v4e.py`（v4d 同法、帶 r3）：0.5 mm 細格**全成立**。最小餘量很薄，明列：
    - 非手指高於 5 mm 0.42 mm；
    - 近區配對 1.06 mm；
    - 退出後配對高於 5 mm 0.007 mm，在 s 0.06、Δ＋3.0° 處。
- 影響：近區上界 +0.15° 遠比 draft-2 嚴。以 K2 0° 曾見的 0.047°/s 無接觸漂移估，退到 22.5 mm（名目約 2 s）累積約 0.09°，餘量約 0.06°。張爪釋放 12 N 預載時門若被推動，更易判失敗，屬保守方向。
- 5 mm 仍為**候選**追蹤落後界限，請裁定。替代方案是維持較小界限、改採受追蹤誤差約束的參考推進：退離較慢，且須重定近區退出期限。

**(b) t_open 實測底盤作釋放監看基準（Codex 已接受）**
