# K3-M 暫停 p4：主動保持停止（Howard 選定；實作＋測試＋凍結 p4 r1）

## 0. 決策
- Howard 2026-10-24 在三個選項中選定「**改成主動保持停止**」。另兩個選項是：維持命令歸零定義並封存為平台限制；先做零命令漂移診斷。
- 新定義：受控暫停的停止＝**手臂零命令＋底盤主動保持命令**下，實測四項速度連續 10 s 低於原門檻。
- 門檻數值不放寬，但這是**停止判定定義的變更**，不得稱原停止判準完全未變。報告必須寫「主動保持下的停止」，**不得**寫成「命令歸零即停住」。

## 1. 依據（實跑，只描述）
| 趟 | 暫停控制 | 結果 |
|---|---|---|
| p2c_2 | 手臂追蹤＋底盤錨點伺服 | 底盤、門靜止；手臂 p95 0.0078 rad/s ⇒ 逾時 |
| p3_1 | 九軸全零 | 手臂 p50 0.0009；零命令下底盤 2.6 mm/s、門約 0.003 rad/s ⇒ 走廊越界 |
| p3b_1 | 手臂零＋底盤主動保持 | **四項全低速約 1.7 s 並進入 ZERO_PUB**；手臂單點 0.0011 判失敗；閂鎖後零命令 0.1 s 內底盤 2.55 mm/s、門 0.0033 |

結論（只描述）：既有這些配置與趟次中，夾持時底盤命令歸零都未達成停止；主動保持下四項可低速。不外推為「平台必然不可達成」（Codex 20261024_231908 更正）。

## 2. 定義差異（p4 相對 r2 監督器／r3 判定器）
| 項目 | r2／r3（命令歸零） | p4（主動保持） |
|---|---|---|
| ZERO_PUB 發布 | 手臂 0＋底盤 0 | 手臂 0＋底盤**錨點伺服**（線速度向量 ≤ 5 mm/s、\|ω\| ≤ 0.02 rad/s，即 park_fixed hold 界） |
| CONFIRM | 已發布底盤＝0 | 已發布手臂 0 且底盤在保持界內 |
| STOPPED（套用回報 5 個連續物理步） | 全部 ≤ 1e-6 | 手臂 ≤ 1e-6、底盤在保持界內、來源序號 ≥ 零速段第一筆 |
| STOPPED 後 | 停止發布、只觀察 | **持續發布保持命令**到 DONE（相鄰 ≤ 0.2 s）；DONE 後停止 |
| 停止後套用違規 | 非零或舊序號 ⇒ FAIL | 手臂非零、底盤超界、舊序號或 −1 ⇒ FAIL |
| 實際停止 | 四項門檻、10 s | **不變** |
| LOWSPEED、逾時 8 s、新鮮度、握手、凍結目標 | — | **不變** |
