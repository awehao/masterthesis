上位：Codex 20261021 K2 封存裁定（K3 合併小規格：小角度開門＋減速—釋放—餘轉）。

## 1. 起始與沿用（不改）

## 2. 開門目標與控制（OPEN）
- θ_goal＝**8°**（候選；離線 6／8／10° 皆 27/27 可行，8° 底盤–門扇最小 0.083 m、10° 為 0.058 m；選 8° 為解除後餘轉留空間）。
- 目標＝`DoorTarget`（door_target.py）：抓取關係用夾持成立當下量測（同 K2 的 G_T_H）；參考門角 q_ref **閉在實測門角**上，
  **限速 rate_max = 1.0°/s（0.01745 rad/s）、超前 lead_max = 0.5°（0.00873 rad）同時成立**；兩區間無交集 ⇒ `on_conflict='reject'`
  ⇒ 中止（**不悄悄重建**）。門角是被動物體狀態，只經抓取帶動，不直接致動門。
- 剖面（事前登錄）：q_goal 由 0 → θ_goal；距 θ_goal ≤ 2° 起 rate_max 以線性降到 0.25°/s（減速段）；q_ref 到 θ_goal 後不再前推。
  q_ref **不得追隨實測門角無限前推**：q_ref ≤ θ_goal 恆成立；實測門角超過 θ_goal＋1.0° ⇒ 中止（門被拖過頭）。

## 3. 先減速再釋放（SETTLE → RELEASE）
- SETTLE：q_ref＝θ_goal 保持；釋放條件（全部成立且**持續 1.0 s**）：|q_meas − θ_goal| ≤ 0.5°、|q̇_meas| ≤ 0.005 rad/s（≈ 0.29°/s）、

- RELEASE：張爪；解除確認同 K2（每指 < 0.1 N 且張開 ≥ 80% 持續 0.5 s），上限 10 s。

## 4. 解除後觀察（POST_RELEASE）與退離（RETREAT）
- POST_RELEASE：手臂保持（目標＝解除時 TCP），**觀察固定 3.0 s 模擬時間**（牆鐘上限 60 s）；記錄：解除時刻門角 q_rel、
  觀察窗內門角變化 Δq、峰值 |q̇|、手指／夾爪殼／相機與門的接觸。阻尼不當作位置保持。
- RETREAT：沿**解除時實測門角下**的把手退讓方向（H(q_rel)·Trans(s·a_H)·T_HG）s 0 → 0.10，0.020 m/s；到位（誤差 < 5 mm）⇒ DONE。
  離線：門餘轉 +1°／+3° 時退離仍可行（27/27）。
