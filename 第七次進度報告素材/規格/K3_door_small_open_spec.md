**只回答**：K2 已確認的夾持關係下，固定停位的機器人能否以受控速率把門由 0° 拉到 θ_goal（≤ 10°），在門真正減速並保持後才解除夾持，
並量到解除後的門餘轉與退離結果。**不要求達到可通行角度、不穿門、不導航、不宣稱門會保持在指定角度。**
上位：Codex 20261021 K2 封存裁定（K3 合併小規格：小角度開門＋減速—釋放—餘轉）。

## 1. 起始與沿用（不改）
門 v2（door_local_v2）、K2_READY 起點、停位 (前距 0.50, 側向 −0.20)、展開→ALIGN→APPROACH→ENGAGE（夾持成立）流程與參數、
抓取基準（實錄 T_HG 6.8 mm）、K2 監看與閂鎖中止機制、W-GMPC 參數（同 K2）、摩擦／阻尼／碰撞偏移。**不改摩擦、阻尼或抓取深度。**

## 2. 開門目標與控制（OPEN）
- θ_goal＝**8°**（候選；離線 6／8／10° 皆 27/27 可行，8° 底盤–門扇最小 0.083 m、10° 為 0.058 m；選 8° 為解除後餘轉留空間）。
- 目標＝`DoorTarget`（door_target.py）：抓取關係用夾持成立當下量測（同 K2 的 G_T_H）；參考門角 q_ref **閉在實測門角**上，
  **限速 rate_max = 1.0°/s（0.01745 rad/s）、超前 lead_max = 0.5°（0.00873 rad）同時成立**；兩區間無交集 ⇒ `on_conflict='reject'`
  ⇒ 中止（**不悄悄重建**）。門角是被動物體狀態，只經抓取帶動，不直接致動門。
- 剖面（事前登錄）：q_goal 由 0 → θ_goal；距 θ_goal ≤ 2° 起 rate_max 以線性降到 0.25°/s（減速段）；q_ref 到 θ_goal 後不再前推。
  q_ref **不得追隨實測門角無限前推**：q_ref ≤ θ_goal 恆成立；實測門角超過 θ_goal＋1.0° ⇒ 中止（門被拖過頭）。

## 3. 先減速再釋放（SETTLE → RELEASE）
- SETTLE：q_ref＝θ_goal 保持；釋放條件（全部成立且**持續 1.0 s**）：|q_meas − θ_goal| ≤ 0.5°、|q̇_meas| ≤ 0.005 rad/s（≈ 0.29°/s）、
  抓取漂移 ≤ 5 mm、雙指橫桿接觸各 ≥ 0.5 N。**不以參考角速度為零就張爪。**SETTLE 上限 10 s，逾時 ⇒ 中止（不張爪）。
- RELEASE：張爪；解除確認同 K2（每指 < 0.1 N 且張開 ≥ 80% 持續 0.5 s），上限 10 s。

## 4. 解除後觀察（POST_RELEASE）與退離（RETREAT）
- POST_RELEASE：手臂保持（目標＝解除時 TCP），**觀察固定 3.0 s 模擬時間**（牆鐘上限 60 s）；記錄：解除時刻門角 q_rel、
  觀察窗內門角變化 Δq、峰值 |q̇|、手指／夾爪殼／相機與門的接觸。阻尼不當作位置保持。
- RETREAT：沿**解除時實測門角下**的把手退讓方向（H(q_rel)·Trans(s·a_H)·T_HG）s 0 → 0.10，0.020 m/s；到位（誤差 < 5 mm）⇒ DONE。
  離線：門餘轉 +1°／+3° 時退離仍可行（27/27）。

**中止處置不變**：任何中止只受控停止並保持、不放爪、不退離；**門已在動時不自動放手**。

## 6. 判定（缺資料不通過）
夾持成立（同 K2）；OPEN 期間 q_ref 同時滿足限速與超前、無衝突；到達 |q − θ_goal| ≤ 0.5°；SETTLE 釋放條件確實持續 1.0 s 才張爪（逐步重算）；
全程 q ≤ θ_goal＋1.0°（解除前）／θ_goal＋5°（解除後）；解除確認；POST_RELEASE 觀察 3.0 s 完整；RETREAT 到位；
腕力 < 30 N；非預期／牆接觸 ≤ 0.1 N；底盤 ≤ 20 mm／2°。**只報**：Δq、峰值 |q̇|（解除後）、開門所需實測關節速度峰值與求解器飽和次數。

## 7. 速度說法限定
離線取樣解所需關節速度（門 1°/s）約 0.46 rad/s（j3），退離 ≤ 0.17 rad/s；只稱「1°/s 慢速帶動的取樣解存在」。
門速若達中止門檻 0.05 rad/s，需求可能超過手臂速度框（K2 已揭露）。

## D. 釋放條件（取代 §3 速率門檻；請裁定）
- 線性阻尼估計（門角阻尼 2.0 ⇒ 等效 ≈ 0.5 s⁻¹，忽略摩擦）：張爪當下速率 q̇₀ 造成的自由餘轉總量 ≈ q̇₀/0.5。
  - q̇₀＝0.005 rad/s：總量 0.57°，RELEASE（K2 實測約 0.74 s）內 0.18°，貼近 0.25° 上界。
  - q̇₀＝0.002 rad/s：總量 0.23°，RELEASE 內 0.07°。
- 因此**提議把釋放速率門檻收緊為 |q̇_meas| ≤ 0.002 rad/s**（其他照舊：|q − θ_goal| ≤ 0.5°、漂移 ≤ 5 mm、雙指 ≥ 0.5 N，持續 1.0 s）。
  這只是估計，用來挑門檻，不是保證；實際餘轉以實錄為準。
- 以 0.002 估算，CLEAR 期間的餘轉每點都低於 §C 表（例：CLEAR 起算 0.5 s，s=0.01，累積 ≈ 0.10° < 0.5°）。
