# 有限區間等效偏移觀測：候選規格（2026-10-22；純離線，未接入、未實跑）

上位：Codex 20261022 旋轉定位 r4 裁定。r4 封存為「兩趟既有資料的探索性旋轉追蹤診斷」。

## 0. r4 說法修正
- 「約十倍」撤回，改為：兩趟 OPEN 期間，相鄰快照的繞桿旋轉殘差多為負向（83%），平均約 −0.08°／區間；HOLD 約 +0.01°／區間。
  兩者平均絕對值相差約 8–9 倍。運動期間的模型預測落差較大，但尚不能區分負載、估計誤差與其他動態因素。
- 求解區間是 4 或 6 個物理步（各約一半），不是固定 50 ms。跨相位切換的區間依起點歸類。

## 1. 觀測式
手臂模型（每物理步、逐軸）：q⁺ = q + α(s − q) + α·d，s⁺ = s + dt_p·u（α、dt_p 取自 `wgmpc_arm_sp_ident_free4.json`）。
d 在區間內近似恆定時，m 步後 d 對 q 的貢獻為 d·[1 − (1 − α)^m]，對 d 為線性。所以先用前一估計 d̂ 預測區間終點 q_pred，再得

  **d_obs = d̂ + (q_meas − q_pred) / (1 − (1 − α)^m)**，m＝區間實際物理步數。

d_obs 是「區間內近似恆定的等效偏移」，**不是真實負載**。

## 2. 更新與界線（事前登錄）
- 只在區間結束、資料完整時更新：q_k、s_k、各步套用速度、q_{k+1} 都有限，且 m ≥ 1。否則保持 d̂ 並記錄原因。
- 濾波：d̂ ← clip(d̂ + (m·dt_p/τ)(d_obs − d̂), ±max)，**沿用** τ＝0.5 s、max＝0.05 rad。不把殘差當固定前饋。
- 預測一律用**更新前**的 d̂；回報的是樣本外殘差。不以同區間反解後的近零殘差當改善證據。
- 不改其他控制、安全參數或門檻；不接節點。

**完整性條件**（任一不成立 ⇒ 該區間保持並記原因，不提交）：

7. 過期：快照年齡沿用節點既有的新鮮度判定；過期快照不形成區間。

# 修訂 3（2026-10-22；依 Codex 20261022_112752 三項缺口；未實跑）

## 13. 何時可提交更新
1. **單調高水位**（防倒退與重播）：
   - IntervalFeed 記錄 high_water＝已處理的最大快照步號（設為錨點或區間終點時更新）。
   - 步號 ≤ high_water 的快照一律保持，**且不改錨點**。與錨點同步號時記 snapshot_not_advancing，其餘記 step_not_after_processed。
   - 清錨點（停止等）之後，重設錨點也須 step > high_water。
   - ⇒ 倒退或重播資料不能重開舊區間，區間不重疊，每區間至多提交一次。
   - 反例：
     - 1010→1014 更新後，倒退 1010 保持，再重播 1014 也保持（只提交 2 次：1010→1014、1014→1020）；
     - 停止後來一個更早的快照（12 ≤ 14）不能設錨點；
     - 重疊快照（16 之後來 13）保持，下一區間為 16→20。
2. **端點時間綁定**：|t_snapshot − t_buffer(step)| ≤ 1e-6（起訖兩端）且 t1 > t0；不符則保持（snapshot_time_mismatch）。
   - 反例：你的「兩快照時間各 +1 s」案例被保持；時間未前進也保持。
3. **訊息頭在轉型前驗證**（`as_step`／`as_time`／`as_flag`）：
   - 步號須為有限、整數值，不接受 1.5、inf、nan、bool、字串、list，也**不截斷小數**；
   - 時間須有限；mode 須為有限整數值；旗標只接受 bool 或 0／1；
   - 非法時：緩衝拒收（n_bad），快照記 snapshot_invalid，**不拋例外**；
   - 反例：step＝inf、nan、1.5、True、'x'、None、[1]，t＝inf；以及八種緩衝入口非法組合。整數值浮點加 0／1 旗標則照常接受。
