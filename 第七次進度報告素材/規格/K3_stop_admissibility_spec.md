# K3-M 停止可容許條件與減速保持（小規格 draft-1＋r1 定位修正；純離線，不開模擬）

**r1 定位修正（Codex 20261023_221949 第 2 節）**——本文件降為**探索性停止狀態篩選**：
> 探索性停止狀態篩選顯示，多個指定擾動情境下殼—橫桿等近似幾何距離不足。這不足以建立原停止方式的可容許域，也不能預測實際接觸力或必然碰撞；實跑進入條件仍未解除。

已知缺陷（保留原輸出，不再據此判定可容許域）：
1. **走廊座標不一致**：取樣程式在停車錨點座標加內帶偏移，線上卻在當前走廊參考座標判定（8° 的 ++ 角點實際為 18.79／21.14 mm，不在宣稱的 ±20 mm 內）。後續一律用同一套 SE(2) 組合（door_k3m_corridor.se2_compose(ref_pose, 偏移)）。
2. **「最大走廊誤差 − 內帶寬」不是底盤剩餘位移**：它含移動參考的影響，不能轉成底盤本體位移再任意配方向。後續須保存同一條停止推進的底盤、門角與時間序列，沿途核對幾何。
3. `−Δd̂`、`−d̂` 只是**關節擾動情境**，不是已辨識的負載解除反應，也不是保守上界，不能涵蓋設定點凍結後所有響應。
4. **DONE 不能列為已支持**：現行流程沒有底盤靜止判準；進入 END_HOLD 後也不以 SETTLE 條件重新計時；門速 < 0.002 rad/s 不等於之後的餘轉為零。§4 表的第一列作廢。
5. 手指—橫桿本來就是設計接觸，距離為負不能單獨證明異常擠壓，須與名目接觸狀態比較。
下一步改做「正常受控暫停／減速保持」（`K3_controlled_pause_spec.md`），不先做故障後跟隨。

依 Codex 20261023_210920 第三節：只記錄中止門速、停止後再監看淨空，**不足以解除**「停止後局部幾何可能不相容」這項進入條件。
本規格先以純離線取樣回答：原停止方式（凍結設定點＋底盤經輪級限制減速）在哪些狀態有足夠幾何餘裕、哪些沒有；
若不足，列明需要另設計的停止方式。**不自行放爪、退離或加理想門鎖**；不要求本輪證明完整接觸穩定性。

## 1. 兩種停止（分開）
| | 正常減速保持 | 異常閂鎖停止 |
|---|---|---|
| 觸發 | DONE（END_HOLD 3 s 後）；或之後定義的「可跟隨中止」（§5） | 任何中止：接觸／腕力／抓取漂移／新鮮度／求解失效／門角或門速／走廊／幾何／自碰／熱中止 |
| 現行行為 | 求解器停止發布 ⇒ 命令鏈 0.2 s 後逾時 ⇒ 底盤減速、手臂速率 0 | K2 閂鎖 ⇒ 命令立即過期 ⇒ 同一逾時路徑；夾爪凍結閉合 |
| 當下底盤 | DONE 時底盤已在走廊終點、速度近 0 | 可能在內側帶邊緣、以框上限速度運動 |

- **「設定點凍結 ≠ 實測關節凍結」**：模型 q⁺＝q＋α(s−q)＋α·d 的平衡為 q＝s＋d。
- 接觸負載改變或消失時，即使 s 凍結，實測手臂仍會移動。所以自碰與殼—橫桿距離在停止後都可能改變。

## 2. 離線取樣（`door_k3m_offline_stop_states.py` → `results/door/door_k3m_offline_stop_states.json`）
**中止當下狀態 S0**
- 門角 1、2、4、6、8°；
- 底盤取走廊參考，加上內側帶四角或中心（±20 mm、±0.8°）；
- 手臂 IK 以候選構型暖啟動，維持夾持。

**停止後狀態 S1＝S0 加上以下三項**
- **底盤剩餘位移**：取 `door_k3m_offline_stop_r3_inner20.json` 各反應情形「超出內帶」的最壞量，8 個方向，位置與偏航保守地同時取滿：
  - executor：1.5 mm／0.21°；
  - chain_timeout：14.9 mm／2.88°；
  - policy：19.7 mm／3.77°。
- **手臂殘餘**，三種情形（d̂ 取 door_k3ab_ev_1 實錄；OPEN 時 j2 16.9／j3 −8.4 mrad，中止時 j2 24.3／j3 −13.2 mrad）：
  - none：負載不變；
  - load_release：−(d̂_abort − d̂_open)；
  - full_release：−d̂_abort。
- **門餘轉**：0／0.25／0.5／1／2°（實錄中止後 3 s 內 +0.87～+1.05°，是經驗值，不是上界）。

共 9000 個狀態；門檻沿用監看值 5／5／20／5 mm。

## 3. 結果（每格的 n＝200）
**executor 反應**

| 手臂殘餘 \ 門餘轉 | 0° | 0.25° | 0.5° | 1° | 2° |
|---|---|---|---|---|---|
| none | 195 | 50 | 0 | 0 | 0 |
| load_release | 200 | 150 | 38 | 0 | 0 |
| full_release | 200 | 200 | 183 | 0 | 0 |

**policy 與 chain_timeout 反應**
- 即使門餘轉為 0°，也只有 100～150 個符合門檻。
- 門餘轉 2° 時只有 10～50 個。

**哪些量會不符**
- 所有不符的最小者幾乎都是**夾爪殼—橫桿**（nonfinger 類，最負約 −13 mm）。
- 其次是手指對門扇／立柱：policy 情形在門餘轉 ≥ 0.25° 時為負。
- 底盤淨空全部 ≥ 130 mm；自碰全部 9.8 mm（停止後構型不變時）。
- 手指—橫桿（設計接觸區）在大部分停止後狀態為負，表示夾持幾何被擠壓，而不是保持名目夾合。

**解讀**（近似幾何、門與手臂獨立擺放，沒有接觸力模型）
- 手臂凍結時，只要底盤再移動數 mm 以上，或門再轉約 0.25° 以上，被夾的橫桿就會與夾爪殼或手指在幾何上不相容。實際會以接觸力、變形或滑動呈現，尚未模擬驗證。
- 原停止方式**只在**「執行端逐步反應＋門幾乎不再轉（≤ 0.25°）」時大致有餘裕。對策略端或命令鏈逾時的反應、或門餘轉 ≥ 0.5°（實錄常見約 1°），**沒有足夠幾何餘裕**。

## 4. 可容許與拒絕（以原停止方式而言）
| 狀態 | 判定 |
|---|---|
| 正常減速保持：DONE 時底盤速度 ≈ 0、門已穩定（SETTLE 條件 \|q̇\| ≤ 0.002 rad/s 持續 1 s）| **可支持**：底盤剩餘 ≈ 0、門餘轉 ≈ 0，對應上表 executor/none/0° 附近；仍須實跑紀錄確認 |
| 執行端走廊越界（逐步反應）且中止時 \|q̇_door\| 小（門餘轉 ≤ 0.25°）| 部分支持（50～200/200），**不足以宣稱可容許** |
| 策略端或命令鏈逾時才觸發的中止（反應 0.21～0.27 s）| **拒絕**：門餘轉為 0 時也只有約半數符合 |
| 任何中止且門仍以實錄常見速度續轉（~1°）| **拒絕** |

- 經驗餘轉量（+0.87～+1.05°）不能冒充上界；本表只用取樣值，不外推。

## 5. 結論：需要另設計停止方式（候選，未實作、未核可）
- 原停止方式（凍結設定點＋底盤減速）在常見的中止情境下**幾何餘裕不足**，所以這一項實跑前進入條件**仍未解除**。
- 候選方向只列出、不實作：**「跟隨減速保持」**。非安全臨界的中止（例如 finger_contact_lost、走廊越界、門角速率）發生後：
  - W-GMPC 不停止，目標改為**實測門角對應的把手位姿**（DoorTargetK3 參考凍結在實測門角、不再推進）；
  - 底盤速度參考為 0，經既有速度與加速度框減速；
  - 手臂吸收底盤剩餘位移與門餘轉，維持夾持幾何；
  - 門角與底盤都靜止後，才進入凍結停止。
- **安全臨界的中止**仍立即閂鎖凍結，並承認本規格 §3 的幾何不相容風險：量測失效、非預期接觸、牆接觸、自碰、腕力超限、熱中止。
- 候選若要推進，需要另做的離線核對：
  - 跟隨期間的速度需求與關節餘裕；
  - 門餘轉期間追蹤與殼—橫桿距離；
  - 「哪些中止可跟隨」的分類理由；
  - 與現有閂鎖鏈的互斥（跟隨期間不得收到任何新的開門參考）。
- 本規格不宣稱候選能解決接觸穩定性；也不把「跟隨」當成放寬中止門檻。

## 6. 限制
靜態取樣、點雲／盒／膠囊近似、取樣之間未核；門與手臂獨立擺放，沒有門被手臂推動、夾持變形或摩擦的模型；d̂ 只取一趟實錄；門餘轉為經驗值。
