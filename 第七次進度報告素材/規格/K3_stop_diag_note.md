# K3 停止後實際行為核對（只讀既有實錄；依 Codex 20261023_223218 第 3 節）

程式：`evaluation/door_k3m_stop_diag.py` → `results/door/door_k3m_stop_diag.json`。

**資料範圍**
- 7 趟固定底盤 K3-A 系列中止實錄：door_k3a_1、door_k3a_adm_1、door_k3a_int_1、door_k3a_ev_1、door_k3au_ev_1、door_k3ax_ev_1、door_k3ab_ev_1。
- 中止原因全部是 finger_contact_lost。停止方式是 K2 閂鎖：命令立即過期，底盤經輪級減速，手臂速率歸 0，設定點凍結。
- 以中止步為 0，取其後 3.0 s。實錄本身在中止後約 3.1–3.2 s 就結束。

**界線**
- 不是 K3-M（底盤可動）的停止證據。
- 接觸量是模擬器的接觸配對，不等於真實力感測。
- 每趟都只是一趟介入觀察，不做根因主張。

## 3. 對照先前的靜態取樣（K3_stop_admissibility_spec.md，探索性）
- 靜態取樣：手臂凍結時，門再轉 ≥ 0.5° 或底盤再移數 mm，殼—橫桿距離就轉負（最負約 −13 mm）。
- 實錄（固定底盤閂鎖停止）：3 s 內門再轉約 0.9°、底盤也移了約 8 mm，殼—橫桿仍為正（約 4.4 mm），也沒有量到非設計接觸。
- 能說的：實測關節跟著動了（6–8 mrad），實際停止的相容性比「手臂完全凍結」的靜態假設好。
- 不能說的：
  - 這不證明停止後安全。實錄在門與底盤仍在動時就結束，最終狀態未驗證。
  - 這只涵蓋固定底盤、單一中止原因、7 趟。
  - K3-M 底盤可動停止的剩餘位移、以及策略端或命令鏈逾時的反應，都不在這些資料內。
- 4.4 mm 已低於 5 mm 監看門檻。K3-M 若沿用同門檻，監看會在這類停止中觸發；這是設計上要處理的事實，**不**放寬門檻。

## 4. 新觀察（未解釋，只記錄）
- 固定底盤的趟次在中止後底盤移了約 8 mm，是中止前的十幾倍。
- 時間上跟門續轉同步，但沒有做因果分析。
- 對 K3-M 而言，這代表「底盤命令 0」不等於底盤不動。這和受控暫停規格的「速度參考為零不等於停止」一致。

## 5. 對下一步的含意（供 Codex 裁定）
- 停止風險已有一部分從幾何推測對到實際證據：固定底盤閂鎖停止的 3 s 內，近似淨空為正、無非設計接觸。
- 仍缺：
  - 停止**完成**之後的狀態（需要更長的記錄窗）；
  - 底盤可動情況下的停止；
  - 門被推動時的行為。
  第三項是門動力學離線規格要回答的。
- 是否仍需要門動力學規格，或改用一趟只做「停止後長窗記錄」的隔離診斷趟，交 Codex 決定。
