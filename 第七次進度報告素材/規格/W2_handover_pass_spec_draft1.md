# W2：大角度開門 → 放爪／退離 → 繞自由端通行的交接規格 draft-1（純規格；**未核可實跑**）

依 Codex 20261025_025410：把「通行」與「夾持上限恢復時機」合併成一份後續規格。

- **30° 尚不是通行角度**，本規格交代後續的順序、門檻與交接。
- **DONE 不等於解除保持，也不等於自動恢復 5 N。**
- 通行回到 GMPC＋動態預測 CBF 主線，**不以直接設定底盤位姿代替**。

## 0. 依據
**實跑**：door_wide_w1e_30_1（單趟；依事後修正的 w1e2 判定器通過）
- 30° 協同開門、SETTLE、受控暫停、主動保持停止、10.01 s 觀察通過。
- 暫停期手指上限 20 N。
- 不代表撤除保持後仍停住，也不代表重複性；重複趟 door_wide_w1e_30_2 進行中。

**離線**
- 通行門角 θ_pass ≥ 79.5°：收攏包絡 0.341 m＋5 cm。
- 拉到可通行角時，機器人會在門扇後方 ⇒ 選定「放手後繞過門扇自由端再進門洞」，門前預留約 1.5 m 淨空（Codex 20261021_154448）。
- W1 掃描：90° 運動學可行；底盤相對錨點後退 0.35–0.40 m、側移 +0.99 m、偏航 −16°。

**已知限制**
- 解除後的近接觸區（s < 0.02 m），手指全開每側約 5 mm，淨空先天 < 5 mm（K3 規格 K3-B 節，未核可）。
- 門只有質心角阻尼，沒有閉門器與鉸鏈摩擦 ⇒ 放手後門角可能漂移，須實測。

**原則**
- 上限只在「確認張開且解除接觸」後恢復，不在 DONE 時、也不以計時恢復。
- 每次交接都由執行端權威在明確物理步切換，並回覆 ack；沿用 K3-M 握手樣式。
- 交接前要有「前一段完成」的判定證據，不靠時間推定。

## 3. 分支
- **正常**：依 §1 順序；每段完成判準不成立 ⇒ 該段逾時中止，不跳段。
- **中止**（任一監看越界、讀回異常、判準逾時）：
  - 走既有 K2 中止閂鎖：鏈內命令過期，底盤經輪級限制減速，手臂設定點凍結，夾爪凍結於當下目標。
  - **上限維持當下值，不恢復 5 N、不張爪、不加力**，因為夾持中恢復可能導致滑脫。
  - 中止後只做觀察，不自動重試。
- **通訊失效**（任務端心跳逾時、求解端停發、ack 遺失）：
  - 執行端鏈逾時，走既有停止路徑；觀察器照常。
  - 上限與手指目標維持；**不在失效狀態下自動恢復 5 N 或張爪**。
  - 恢復只能經人工核可的新趟次。
