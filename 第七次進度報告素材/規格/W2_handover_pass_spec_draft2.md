## 1A. 控制連續性缺口（Codex 20261025_030420；必須先補）
- **現況**：ADM9 在監督器 DONE 後停止發布保持命令，任務端隨後送 /room/stop。
  - 「DONE 後維持保持」目前只是需求，**不是已有能力**。
- **整合版要求**：
  - 終止前進入明確的「**保持／待交接**」狀態，持續發布保持命令並監看，直到下一控制段確認接管；
  - 不能先 DONE、停發，再重新啟動。

| 段 | 底盤 | 手臂 | 手指目標 | 手指上限 |

| OPEN／SETTLE | W-GMPC free（引導） | W-GMPC | 閉合 | 5 N（不變） |
| PAUSE→DONE | 主動保持（錨點伺服） | 零命令＋保持 | 閉合 | **20 N**（暫停切換那一步起） |
| W2a | 主動保持 | 零命令＋保持 | 閉合 | 20 N |

| W2d | 主動保持 | 同一 W-GMPC 發布 TCP 目標的退離路徑（已選定；復用 K2 斜坡與完成判準） | 張開 | 5 N |

**原則**
- 上限只在「確認張開且解除接觸」後恢復，不在 DONE 時、也不以計時恢復。
- 每次交接都由執行端權威在明確物理步切換，並回覆 ack；沿用 K3-M 握手樣式。
- 交接前要有「前一段完成」的判定證據，不靠時間推定。

## 3. 分支
- **正常**：依 §1 順序；每段完成判準不成立 ⇒ 該段逾時中止，不跳段。
- **中止**（任一監看越界、讀回異常、判準逾時）：
  - 走既有 K2 中止閂鎖：鏈內命令過期，底盤經輪級限制減速，手臂設定點凍結，夾爪凍結於當下目標。
  - **上限維持當下值，不恢復 5 N、不張爪、不加力**，因為夾持中恢復可能導致滑脫。
  - 中止後只做觀察，不自動重試。
- 中止與失效分支是既有處置的延續，**不是已驗證的故障後安全停止**。
- **近接觸區例外**只適用指定的手指—橫桿解除過程，**不豁免**殼、門板、支柱、牆或自碰。
- **通訊失效**（任務端心跳逾時、求解端停發、ack 遺失）：
  - 執行端鏈逾時，走既有停止路徑；觀察器照常。
  - 上限與手指目標維持；**不在失效狀態下自動恢復 5 N 或張爪**。
  - 恢復只能經人工核可的新趟次。

## 4. 六項裁定（Codex 20261025_030420）
1. **OPEN 上限維持 5 N**；PAUSE 才切 20 N。先只延伸角度，不疊加另一變因。
2. **下一目標 60°**：
   - 走廊、包絡、幾何與逾時登錄，更新到目標＋保護餘裕的範圍；既有內帶與停止門檻不變。
   - 離線核對有缺口就列明，不自動加跑其他角度。
3. **退離優先用同一 W-GMPC 發布 TCP 目標**：
   - 復用 K2 的斜坡與完成判準，不新增第二個手臂命令來源；
   - 另核對大角度解除時的實測把手座標。
4. **K3-B 判準先於 W2 實跑定版**：指定配對、適用區域、持續時間、清空進度，以及恢復一般淨空門檻的條件。
5. **門漂移容許量由通行餘裕推得**，目前不先給任意角度。
   - 79.5° 仍是既有離線估算，須以實際 K2_READY 包絡與路徑重新核對。
6. **W3 門扇依實測門角更新；門框為靜態障礙**，並登錄新鮮度、預測與不確定性處理。

## 5. 本規格不做
- 不實跑、不新增補償。
- 不改既有停止判準與保護門檻。
- 不把 30° 結果外推到大角度或實機。
