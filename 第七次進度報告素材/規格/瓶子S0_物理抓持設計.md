## 3　接觸分類（相位准入）
| 接觸對 | CRUISE／PREGRASP | INSERT | CLOSE／LIFT／HOLD |
|---|---|---|---|
| 手指 ↔ 瓶 | 禁止 | 禁止（插入中不得先碰）| **指定接觸** |
| 非手指連桿（含夾爪殼）↔ 瓶 | 禁止 | 禁止 | 禁止 |
| 任何機器人剛體 ↔ 桌面／桌腳 | 禁止 | 禁止 | 禁止 |
| 瓶 ↔ 桌面 | 支撐 | 支撐 | 抬離後須為 0（無支撐判據） |
量測：PhysX 接觸力追蹤＋過濾對（同抽屜 `track_contact_forces` 寫法），每指對瓶、瓶對桌、各禁止對分開讀。
**噪聲處理**：禁止接觸以「力 ≥ 0.05 N 且連續 ≥ 3 物理步」或「幾何穿透 ≥ 1 mm」判定（**候選**），不以浮點非零判碰撞；
門檻待「只放瓶子」冒煙與 S0a 量測後凍結。**所有短脈衝、峰值與穿透一律照錄**，未達門檻也不稱「未碰撞」，只稱「未觸發判定」。

## 4　判定（設計 §9 暫定值；分開記錄，接觸力不代替承重）
1. 抓持證據：雙指各 ≥ 0.5 N **逐物理步**連續 ≥ 1.0 s；期限 5 s 自**閉爪請求**起算，不因重送刷新；只在接觸資料與瓶位姿皆有效時累計。
2. 離桌：同時成立且持續 ≥ 1 s——(i) 瓶位姿資料有效（新鮮 ≤ 0.02 s）；(ii) **幾何**：瓶底最低點 − 桌面 ≥ 40 mm；
   (iii) 瓶↔桌接觸**資料有效**且法向力 ≤ 量測容差（候選 0.02 N，待冒煙量測靜置時的讀值分佈後定）。缺資料 ≠ 零力，缺資料期間不累計。
3. 持瓶保持：抓持成立時固定瓶對 TCP 相對位姿基準；抬離後 3 s 內相對位移 ≤ 5 mm、轉角 ≤ 3°；不逐步重設基準。
4. 未推瓶：閉爪請求前瓶位移 ≤ 5 mm、傾角 ≤ 3°。
5. 無禁止接觸（第 3 節）。
全部成立才算成功；任一不成立記第一阻點，不自動補跑。

## 5　停止處置
| 情況 | 處置 |
|---|---|
| 抓持證據逾期、閉爪前推瓶、禁止接觸 | 底盤有界減速停止（或維持 PARK_HOLD）、手臂設定點凍結、夾爪維持當下命令（不自動張開）；記第一阻點 |
| 抬離後失抓：**任一指**對瓶力 < 0.2 N 連續 0.2 s（較門段「兩指」判準保守，須揭露差異），或滑移超限 | 停止抬升與底盤、手臂凍結；**不嘗試接住或放回**（第一版） |
| 資料失效（接觸／瓶位姿過期 > 0.1 s）、求解失敗 | 腳本內停止處置：底盤以加速度上限有界減速至 0、手臂設定點凍結。**不是既有命令鏈的重用**，須在腳本內另行驗證 |
停止本身的有效性另核：停止後 1 s 內底盤速度 < 0.01 m/s、手臂關節速度 < 1e-3 rad/s。

## 6　輸出與核對
逐物理步：時間、底盤位姿、手臂角／設定點、指位、每指對瓶力、瓶對桌力、各禁止對力、瓶位姿；事件：相位、證據成立、離桌、停止原因。
