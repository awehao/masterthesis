# 瓶子區域任務 R-B1＋迎面移動物：設計與前置

依據：Codex `reviews/20261102_200625_reply.md`（回應 Howard 問的複雜環境；不先展開多障礙批次）。

## 1. 設計

- **基線**：凍結為 carrygov（`bottle_w1_carrygov_ctrl`，不含已封存的 approachsched）。Isaac 腳本 dynsr34＝dynsr33 加登錄新案例。
- **場景**：沿用 R-B1。區域偏移 O＝(0.6, 0.8)，第一桌 0.58，瓶 區域 (−0.03, 0.44)，第二桌世界 (2.4, −1.0)，原障礙世界 (−2.0, 0)。只增加一個掃描可見的迎面移動圓柱。
- **劇本生成**：同既有 `w1_dyn_pass1`。程式 `bottle_dyn_case_region.py`，結果 `experiments/20261102_rb1_dyn_case.json`，在任何閉迴路之前產生。
  - 尺寸與速度沿用 arena 交通 dyn_obs_0：0.30 m/s、半徑 0.25 m、高 1.0 m。
  - 以名目趟 `bottle_rb1_gaze_1` 持瓶導航段的量測軌跡為準。交會點取弧長分率 f 處，P_m＝底盤位置，d＝前後 0.5 s 位移方向。
  - 障礙在行進方向右側法向 0.80 m 處沿 −d 反向等速：起點 P_m＋2.2 d＋0.8 n_右，終點 P_m − 2.5 d＋0.8 n_右，t_start＝t_meet − 2.2／0.30（任務時刻排程，不追機器人）。
  - **f 的選法**（事前宣告、只依幾何前提，不依成敗）：候選依離中點順序 0.5、0.4、0.6、0.3、0.7…，取第一個四項前提全過者。
    - 中點 0.5 的直線錯身線離第一桌桌面只有 0.031 m、離規劃路徑 0.563 m（R-B1 持瓶路徑先下行再轉東），所以不過。0.4、0.6、0.3 也不過，**0.7 起全過**。
  - **結果**（世界座標）：交會 29.06 s，底盤 (1.162, −0.628)，方向 (0.404, −0.915)；障礙起點 (1.320, −2.964)、終點 (−0.580, 1.335)、21.73 s 起動。
- **幾何前提**（同 test_bottle_w1_dyn）：

| 前提 | 結果 |
|---|---|
| 1 障礙軌跡離靜態物 ≥ 0.05（第一桌最近） | 0.393 m |
| 2 障礙中心離持瓶規劃路徑 ≥ 0.74（不觸發路徑阻擋） | 0.801 m |
| 3 最接近時刻在持瓶導航段、底盤到障礙表面 < 0.69（進動態 CBF 範圍） | 29.06 s、0.55 m |
| 4 不反應時連桿與持瓶到障礙 > 0 | 0.505 m |

- **座標**：
  - 劇本是世界座標，Isaac 場景驅動、真值評估與安全網都用世界座標。
  - 控制器只經掃描 → 追蹤器看到障礙，追蹤器輸出由 dynsr 的 `obs_to_region` 轉成區域座標，與其他障礙相同。障礙真值不送進控制器。
  - 假世界整體用區域座標，只在 `test_bottle_w1_rb1_dyn.py` 把起點／終點各減 O 一次。

## 4. 物理實跑：bottle_rb1_dyn_1（n＝1；凍結 6724e2782）

- **配置**：dynsr34、`--dyn-case rb1_dyn_pass1`，其餘同 R-B1。守護：CPU 峰值 70 °C，熱中止 0 次，收尾殘留 0 組。
- **結果碼 6**：完整抓放到 DONE（52.95 s），但**原抓持品質不合格**（平移滑移 > 5 mm）。兩者分開報告。
- **本案例的正確稱法**：最新版在單一迎面動態會遇下完成抓放並保持距離，但原抓持品質不合格。不能稱穩健成功。無反應重播本來就不會接觸（本體最近 0.505 m），所以也**不能稱避免了原本必然發生的碰撞**。
- **性質**：本案屬底盤避讓配合手臂相對任務，不是手臂主動繞開移動物的證據。

### 時間鏈

| 事件 | 時刻 | 當時相位 |
|---|---|---|
| 障礙起動（排程 21.727 s） | 21.74 s | LIFT |
| 起動後首次被追蹤為動態 | 23.51 s（起動後 1.77 s） | CARRY_NAV |

| 最接近（名目交會 29.06 s） | 31.95 s | CARRY_NAV |

- 離桌確立 23.08 s、閉爪與抬升都在障礙被追蹤之前完成，所以這趟**沒有影響閉爪與抬升**；這是本案例的時序，不代表一般情況。
- **起動前誤判**：障礙還靜止在起點時，追蹤器在 4.61–4.81 s 把它判成動態 3 次，求解器收到 6 拍（4.65–4.90 s，CRUISE）。
- **動態項計數**（求解器 1100 拍都有紀錄，所以以下是實際計數，不是未記錄）：對應真障礙 228 拍（起動後 222 拍）；其他動態項 8 拍（32.95–33.30 s，不在真值 0.6 m 內，可能是追蹤器假動態）。
- **追蹤對照**（真值僅評估用）：追蹤位置對圓柱真值**中心**的差，中位 0.249 m、最大 0.274 m；速度差中位 0.034 m/s、最大 0.490 m/s。
  - 這個位置差與圓柱半徑 0.25 m 幾乎相同。若追蹤的是可見表面叢集，它就不是同一語義的中心定位誤差，**不能直接判為追蹤失準**；追蹤器輸出語義這裡沒有另外核對。

### 對無移動物基線（bottle_rb1_gaze_1）

基線是 gaze 版、本趟是 carrygov 版。即使 R-B1 離線退化相同，這仍**不是嚴格只切換障礙的物理消融**；下表的 +4.55 s 與滑移差異是觀察值，不全數因果歸給障礙。

| 指標 | 基線 | 本趟 |
|---|---|---|
| 首次合格目標、承接 | 8.61、8.70 s（餘裕 1.004 m） | 相同 |
| 抓持、離桌確立 | 21.04、23.08 s | 相同 |
| CARRY_NAV → PLACE_APPROACH | 22.25 → 31.85 s | 22.25 → **36.85 s** |
| 完成 | 48.40 s | **52.95 s（+4.55 s）** |
| 放置偏差、傾斜 | 1.91 mm、0.19° | 2.20 mm、0.28° |
| 全程滑移 | 3.75 mm（合格） | **10.39 mm（不合格）**，35.39 s（外伸段）首次 > 5 mm |
| GMPC 求解 p50／p95／最大 | 14.4／20.9／26.3 ms，超過 50 ms 0 拍 | 15.4／22.3／**152.5** ms，超過 50 ms 4 拍 |
| 每拍推進 advance p50／p95／最大 | 0.19／9.3／12.2 ms | 0.98／22.3／29.3 ms |

- **求解耗時超過 50 ms**：4 拍在 0.00、8.60、**32.05、32.10 s**；後兩拍（152.5、62.7 ms）正好在最接近、CBF 鬆弛最大的時候。152.5 ms 是求解耗時峰值；同步模擬中不等於已發生命令期限逾時。
- **會遇窗車速**（圓盤外緣到表面 < 1.5 m，25.7–34.9 s）：平均 0.146 m/s、最低 0.016 m/s，速度變化率峰 0.66 m/s²、p95 0.37 m/s²；27–31 s 明顯振盪（v_carry 0.25 m/s）。
