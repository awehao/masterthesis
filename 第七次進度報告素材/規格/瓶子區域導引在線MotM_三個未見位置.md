# 區域導引在線 MotM：三個未見位置

日期：2026-11-02，Asia/Taipei。

依據：
- `reviews/20261102_howard_region_guided_online_motm.md`
- Codex 072116、072949、075357

每案 n＝1。這是指定新位置，不是隨機獨立重複，不能推成成功率。

## 任務定義與先驗

- **任務輸入**：已知區域（第一桌所在、導航路徑、抓取車道），以及目標類別「同型直立瓶」。
- **本趟視覺給的量**：物品精確 xy 與支撐高度。學習遮罩＋深度產生 known_type 快照。
- **任務先驗**：
  - 備妥分支（資產名目）；
  - 抓持帶 0.10 m；
  - 第一桌 xy 範圍（收近閘用）；
  - 第二桌（放置）。
- **真值安全網**，只負責拒絕，不修正計畫：
  - 判定器的離桌判定與 liftb 切換；
  - 持瓶淨空拒絕；
  - 穿透估計；
  - 禁止接觸。
- **未見位置的產生**：
  - 種子 20261102，實跑前已提交（`experiments/20261102_online_unseen_positions.json`）。
  - 抽樣範圍是「本批設計域」：dx ∈ [−0.08, 0.08]、dy ∈ [−0.025, 0.04]、桌高 ∈ [0.55, 0.65]。這個範圍不稱為已核可的連續區間。
  - 精確值只交給場景端，控制器不讀。

## 在線計畫

背景子程序規劃工作者，控制拍不阻塞。

- **抓取計畫**：
  - 以實際執行的備妥構型為唯一種子，核對平移後的全窗分支連續性。
  - 承接條件：觀測年齡（以來源擷取戳計）、目標一致性、最晚處置點。
- **轉回計畫**：
  - 逐案用 IK 延續求收近、升高、外伸的時長與轉回高度。
  - 承接條件：側持姿態與持瓶包絡的容差；最晚處置點依運送進度計算。

## 後續：排程提速（提前安全轉回、與運送重疊；Codex 080657 唯一候選）

- 版本：`bottle_w1_online3_ctrl`，凍結紀錄 `experiments/20261102_online3_earlyret_freeze.json`。只改升高與外伸的起點排程：
  - 升高起點：在運送路徑上，到停車位的剩餘距離 ≤ v_carry ×（升高＋外伸時長）時就開始升高；
  - 外伸起點：升高完成後，在「沿規劃路徑運送」（CARRY_NAV）階段也可開始外伸，但仍須通過外伸淨空閘並逐拍監看；
  - 速度、時長、淨空閘、停止條件、下放前 TCP 收斂都不變。
