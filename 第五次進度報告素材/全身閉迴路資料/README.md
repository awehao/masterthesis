## 三條界線（引用數字時必須一併帶上）

### 1. 最小誤差不是最終精度

0.364 mm 是**全程最小值**。到達後長尾末值為 **21.71 mm**（sim 140 s）；
觀察窗後底盤又移動 17.99 mm，已知零命令漂移外推僅 9.1 mm，**對不上全部**。
**長時間保持尚未驗收**，列入下一階段 —— 但這不取消已達成的短時到位成果。

`27.21 s` 是**連續符合到達條件的時間**，**不是到達耗時**。
判定同時檢查位置與姿態，不是各自取最小值。

### 2. 「無上限」須正名

診斷中 `speed_cap = −1` 表示**未施加該項退化速度上限**，
**不是所有速度限制取消**。仍在作用的有：關節位置限位、
速度框（底盤逐軸 0.035255 m/s、手臂 0.9999 rad/s）、加速度框、jerk 框，
以及 E2 執行端的最終檢查（線速 0.05、角速 0.2、手臂速率 1.0）。

### 3. 方法定位與安全限制分開

* 本配置**不是 B 基線**（B 凍結於 `baseline_B_frozen_20260909.md`）、
  **不是 WGMPC**
* **修改後命令的上游全身安全性未重新論證**
* **停止掃掠範圍無避碰保證**
* **接觸操作不在本趟範圍內**
* 本次完成的是**自由空間到位**，不是整個 S2、不是接觸操作、不是 WGMPC

## 失敗趟次與修正沿革（保留，不刪）

| 趟次 | 結果 | 性質 |
|---|---|---|
| `wb_solver_iso_093451` | 場景閘用子字串比對到相機自身網格 | 啟動失敗（檢查誤判），ABORTED |
| `wb_solver_iso_093853` | 白名單把匯入產生的資源節點當成物件 | 啟動失敗（檢查誤判），ABORTED |
| `wb_solver_iso_094246` | 起動前檢查未設 `use_sim_time`，TF 全判為不新鮮 | 啟動失敗（檢查缺陷），ABORTED |
| `wb_solver_iso_094406` | `/joint_states` 缺 finger joint，TF 9/11 | 啟動失敗（執行端缺漏），ABORTED |
| **`wb_solver_iso_094526`** | **18/23 未通過**：守住界限但未到達 | **任務結果，保留** |
| **`wb_solver_iso_100502`** | **23/23 通過** | **任務結果** |

四次啟動失敗**都沒有降低任何條件**（TF 仍要求 11/11、場景仍要求 0 個外部碰撞體）。

未通過趟次的根因以**既有資料**重播定位，輸出與觀測**差 0.000000**：
自由空間下距離節點對每個連桿產生 `STATUS_NODATA` 列，
濾波器據此套用 `nodata_speed_cap = 0.05`，壓住整個 9 維速度框；
底盤命令 0.0353 < 0.05 原樣通過，手臂約 0.9 rad/s 被壓到約 0.004。

修正的是**狀態分類**，`nodata_speed_cap` 的值**未動**。
