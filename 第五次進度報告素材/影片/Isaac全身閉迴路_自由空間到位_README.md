# 影片說明：Isaac 全身閉迴路 — 自由空間到位

檔案：`Isaac全身閉迴路_自由空間到位.mp4`
1920×1080、20 fps、33.0 s、660 幀。

---

## 這支影片是什麼

**模擬器內相機在趟次執行當下錄下的畫面。**

* **不是**桌面螢幕錄影
* **不是**姿態重演（replay）—— 是求解器真正在跑的那一趟
* 影片內**沒有任何文字**：無片頭、字幕、數值、時間戳、階段標籤或浮水印
* 場景**未加任何標記或目標物**；只加了錄影用相機與燈光，
  兩者皆無碰撞體，不影響 `solver_freespace` 的場景條件

唯一的後製是**時間裁切**：只錄 sim 12.0–45.0 s 這段（任務區間），
實際首末幀為 sim 12.03 → 44.98。20 fps 錄、20 fps 播，**等於原速**。

## 畫面裡發生什麼

底盤與手臂同時運動，把 TCP（`link_tcp`）送到 `odom` 座標
**(0.300, 0.000, 0.550) m**、姿態為「工具 +z 指向世界 +x、工具 +x 指向世界 +z」，
到位後保持。畫面中看不到目標點 —— 它是座標，不是場景物件。

兩趟數字略有差異（例如最小位置誤差 0.364 mm vs 1.636 mm）——
**這是趟間差異，不是同一趟的兩種說法**。引用時請指明是哪一趟。

## 三條界線（與報告一致）

1. **最小誤差不是最終精度。** 上表是全程最小值；到達後仍有長尾漂移，
   **長時間保持尚未驗收**。
2. **速度限制沒有被取消。** 關節位置限位、速度框、加速度框、jerk 框
   與執行端最終檢查全程在線；命令拒收 0、執行端失效無。
3. **本配置不是 B 基線、不是 WGMPC。** 修改後命令的上游全身安全性未重新論證、
   停止掃掠範圍無避碰保證、接觸操作不在本趟範圍。
   本影片呈現的是**自由空間到位**，不是整個 S2、不是接觸操作。
