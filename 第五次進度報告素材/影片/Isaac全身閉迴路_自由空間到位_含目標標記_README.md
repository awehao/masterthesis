## 性質

**模擬器內相機在趟次執行當下錄下的畫面** —— 不是桌面螢幕錄影、不是姿態重演。
畫面內**沒有任何文字**：無片頭、字幕、數值、時間戳或浮水印。

## 目標標記（本版新增）

* 半透明目標點（半徑 20 mm）＋ 短三軸（長 80 mm）表示**目標姿態**
* 姿態定義與判準同一組：工具 +z → 世界 +x、工具 +x → 世界 +z
* **純視覺：無碰撞體、無剛體**。執行端建立後自我查核，
  驗到 `UsdPhysics.CollisionAPI` 或 `RigidBodyAPI` 即中止
* 不會被距離節點當成障礙物 —— 該節點的障礙物來自自己的 `obstacles` 參數，
  **不掃 stage**
* 只在錄影時建立；不錄影的趟次場景完全不受影響

1. **最小誤差不是最終精度。** 表中為全程最小值；到達後仍有長尾漂移，

   與執行端最終檢查全程在線；命令拒收 0、執行端失效無。

   停止掃掠範圍無避碰保證、接觸操作不在本趟範圍。
   本片呈現的是**自由空間到位**，不是整個 S2、不是接觸操作。
