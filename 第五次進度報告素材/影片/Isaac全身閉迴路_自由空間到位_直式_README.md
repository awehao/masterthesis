## 三條界線（與報告一致）

1. **最小誤差不是最終精度。** 表中為全程最小值；本趟末值 **22.48 mm**（sim 140 s），
   **長時間保持尚未驗收**。
2. **速度限制沒有被取消。** 關節位置限位、速度框、加速度框、jerk 框
   與執行端最終檢查全程在線；命令拒收 0、執行端失效無。
3. **不是 B 基線、不是 WGMPC。** 修改後命令的上游全身安全性未重新論證、
   停止掃掠範圍無避碰保證、接觸操作不在本趟範圍。
   本片呈現的是**自由空間到位**，不是整個 S2、不是接觸操作。
