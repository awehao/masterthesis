# 影片說明：朝向偏好 OFF／ON 對比

檔案：`朝向OFF_ON對比_狀態重演.mp4`
1920×1080、30 fps、26.8 s、805 幀。

---

## ⚠ 這是**狀態重演**，不是當時的實錄畫面

該批趟次的 bag 內**相機話題 `Count = 0`** —— 執行當下沒有錄任何影像。
本影片是用 bag 裡記錄下來的**真值位姿**重畫的俯視圖：

* `/model/omni_bot/pose` —— 機器人真值位置與朝向
* `/model/dyn_obs_*/pose` —— 10 顆動態障礙物的真值位姿
* `/goal_pose` —— 用來對齊兩趟的同一事件

靜態物件（牆、`known_obs`、`unknown_obs`）不會移動，直接讀場景 SDF
`src/ammr_bringup/worlds/bigarena.sdf`，不需要 bag 資料。

因此畫面裡的形狀是**示意的幾何**，不是模擬器算繪的畫面。
與 `Isaac全身閉迴路_自由空間到位.mp4`（模擬器內相機、執行時錄影）**性質不同**，
不可混稱。

## 這支影片要回答什麼

> **加上朝向偏好，機器人走起來到底差在哪？**

重點是**車頭與行進方向是否一致**。
**不是**用影片證明 ON 比較安全 —— 間距在 5 組配對中沒有一致模式（見下）。

## 製作規則

| 項 | 作法 |
|---|---|
| 左右 | **固定左 OFF、右 ON** |
| 鏡位 | 兩格**同一鏡位、同一比例**（65.6 px/m），取兩趟路徑聯集 + 1.2 m 邊界 |
| 對齊 | **同一事件**：各趟自己的 `/goal_pose` 首次發布時刻為 t = 0 |
| 速度 | 兩邊**同一播放速度**：sim 10 Hz 取樣、30 fps 播放 = **3 倍速** |
| 變速 | **沒有為了讓兩邊同時到達而各自變速** |
| 剪輯 | **全程保留**，不剪片段；轉向與繞行完整呈現 |
| 文字 | 畫面內**沒有任何文字**；身分、版本與結果寫在本說明 |
| 場景 | **靜態與動態物件都畫**：16 面牆、18 個 `known_obs`、7 個 `unknown_obs`（共 41 個靜態，皆為 box、yaw = 0）＋ 10 顆動態障礙物 |
| 顏色 | 取 SDF 自己的 `diffuse`：牆灰、`known_obs` 藍灰、`unknown_obs` 黃、動態淺灰。**沒有另外配色或加分類標註** |
| 幾何 | 動態障礙物畫**真實碰撞幾何**（`as_generated`，含長方體），不用外接圓近似；機器人畫成半徑 0.30 m 圓盤 —— 與淨距定義 `‖p−p_obs‖ − r_obs − 0.30` 一致 |

> **第一版只畫了 10 顆動態障礙物**，41 個靜態物件全部漏掉，
> 畫面看起來像機器人在繞空氣，繞行的原因看不出來。已修正並重新算圖。

### 結束時刻

影片到 t = 80.5 s。OFF 的真值位姿記錄到 t = +78.68 s（到達 78.63 s），
**其後 OFF 那一格保持最後一筆位姿不動**；ON 到達 80.43 s。
**兩邊時間軸完全相同**。

> **凍結畫面是展示處理，不是量測。** OFF 在 78.68 s 之後沒有資料，
> 畫面不動只代表**沒有後續記錄**，**不是**「該趟之後仍停在原處」的證據。
> 停止後行為不在本片的證據範圍內。

## 不可從這支影片推論的事

1. **不是安全性證明。** 五組配對的動態最近距離**沒有一致模式**：
   兩組 ON 較大（seed 8 大 0.334 m）、兩組幾乎相同、seed 1 則 ON 小 0.067 m。
   **n = 5 不足以說 heading 會壓縮或改善間距。**
2. **不能宣稱「ON 的側移是避障反應」**，也不能反過來說「沒有避讓」——
   逐次遭遇事件的分析尚未做。
3. 本片只是**一組 seed 的一次配對**；跨 seed 的一般性見
   `heading_pairs_5seed_20260911.md`，那裡已寫明各項證據程度。
4. 倍數（如 28.6×）**要小心解讀**：OFF 幾乎不轉車頭，分母很小。
   應以各趟的**絕對轉角**為主。
