# TPAS：手臂相位跟底盤實測進度＋切換一致性閘門（離線結果 r1）

日期：2026-11-11
依據：Codex 20261111_032519 第 1、2 項；物理反例 bottle_motm_tpa_A_1
程式：`evaluation/bottle_w1_tpas_ctrl.py`（基線 tpa_cj 的子類）、`evaluation/tpas_offline_check.py`
結果：`evaluation/results/bottle/tpas_offline_r3.json`（以 r3 為準）。r1、r2 是閘門定義修正前的版本，保留作紀錄：
- r1：閘門比較時刻不一致，名目情境也誤拒；
- r2：有「等待」邏輯，等待中位置差會越等越大。

## 做法

- **相位跟進度**：手臂軌跡的相位 τ 由底盤實測沿路徑進度換算（承接時的預期進度剖面取反函數）。τ 只進不退，速率不超過計畫；底盤被拖慢或停下，手臂一起慢下或停下。
- **切換閘門**：τ 到終點時，兩側在同一世界座標、同一命令生效時刻比較——相對側用控制器實際送出的同一參考函式，世界側是 T_pre。比較位置、姿態、TCP 世界速度三項。
  - 差 ≤ 10 mm／2°／0.03 m/s：直接切換。
  - 差 ≤ 40 mm／5°（速度仍 ≤ 0.03 m/s）：有界重接。PREGRASP 的世界目標從相對側位姿以 ≤ 3 cm/s、min-jerk 接到 T_pre，時長 0.3–1.5 s。
  - 更大：受控拒絕（tpa_switch_inconsistent）。
  - 不再依時間切換，也不先切換再靠追蹤拉回。
- **完整停止軌跡**：用既有停止模型 `stop_traj`（設定點模型、在途命令、逐物理步）跑「現在停」與「延後一拍停」，每個取樣構型都核對桌、自碰撞、對瓶（含開爪手指）、底盤對桌腳。每 0.2 s 取一次，涵蓋接近段、切換、重接段。

## 發現（照實列）

1. **橫向偏 5 cm 往瓶側時，拒絕來得太晚。** 接近段開爪手指對瓶已經 −2.9 mm，完整停止軌跡 −6.1 mm——碰撞風險在切換之前就出現。原因：相對底盤參考不知道底盤偏離車道。這種情況目前靠既有線上對瓶淨空停止（5 mm＋預測停止點）擋，閘門擋不到。物理趟 tpa_A_1 避讓時曾偏離車道 3.5–7 cm（往離瓶側）。
2. **INSERT 段（和舊流程相同，不在本次範圍）**：延後一拍停的完整停止軌跡，夾爪殼對瓶 4.5 mm，比 5 mm 拒絕線少 0.5 mm。此核對的設定點用當下構型近似；物理趟線上預測值 6.8–7.6 mm。另案處理。
3. 這版仍沿用目標專屬車道模板（Y_REACH 0.4275、RUNUP 0.55、偏航 0）。依 Howard 11/11 新要求（車頭沿路徑、站位在線選），下一版會再改。

## 限制

- 只是離線核對：底盤沿車道直線、情境以速度上限模擬（無 CBF 幾何）、控制拍 0.05 s。
- 停止模型的設定點與在途命令是近似值。
- plan_tpa 的牆鐘耗時仍未記錄。
- 物理尚未跑；依 Codex 032519，A 案不熱改、不補跑。

## r6 修正（依 Codex 20261111_042529；結果 `tpas_offline_r6.json`，24/24）

修正內容：
- **計畫位姿偏差補償**：每拍以命令生效預測底盤位姿，相對「計畫底盤位姿」（路徑上同一進度點、計畫偏航）取橫向偏差 dy 與偏航偏差 dθ，從相對參考扣除。TCP 世界路徑因此維持規劃值，由手臂吸收底盤橫偏；切換閘門用同一偏差。|dy| > 8 cm 或 |dθ| > 8° 時在接近段就受控停止。
- **rate 不濾波**：rate＝實際相位增量；超過剖面終點時，依最後一個完整區間的速度延伸。r4、r5 曾因最後一拍截斷，rate 失真，名目情境被誤拒。
- **重接時長**：依 min-jerk 峰值（1.875 倍平均）使峰值 ≤ 3 cm/s；超過 1.5 s 就拒絕，不截短。
- **速度、加速度**：改由實際送出的參考序列（每拍 q）差分計算；有偏差時手臂構型以 IK 求得。

| 情境（各 3 種起點） | 結果 |
|---|---|
| 名目／A 型減速／停走／末段慢 | 12/12 直接切換，位置差 ≤ 4.8 mm、速度差 ≤ 0.025 m/s |
| 往瓶側橫偏 +3 cm、+5 cm（漸增） | 6/6 直接切換；接近段淨空與完整停止軌跡都 ≥ 門檻（最差：自碰撞超出門檻 2.2 mm） |
| 往離瓶側橫偏 −7 cm（仿 tpa_A_1）＋A 型減速 | 3/3 直接切換 |
| 往瓶側橫偏 +9 cm（漸增） | 3/3 在 dy＝8.1 cm 時於接近段受控停止，停止前淨空與完整停止軌跡都 ≥ 門檻 |

整體最差：關節速度比 0.907、加速度比 0.408（由序列差分）。
