# 住宅場景：偏航抽屜接線核對 r1（無機器人）

依據：Codex 20261112（住宅格局 r1 裁定）。登錄 `evaluation/experiments/20261112_m8_house_drawer_check_registration.json`（判準事前固定）；腳本 `evaluation/isaac_m8_house_drawer_check.py`；結果 `資料/m8_house_drawer_check_r1/m8_house_drawer_check.json`。一次 Isaac，CPU 峰值 77 °C。
**判定：未過（B 項一個子條件）。抽屜接線四項通過；代理物靜置的讀回速度超過門檻。失敗保留，沒有重跑。**

| 項 | 內容 | 結果 |
|---|---|---|
| A 讀回 | 滑動軸在世界的方向：世界側框架 (1, 0, 0)、抽屜側框架 (1, 0, 0)，與登錄拉出方向 (+x) 相同；限位 0–0.22 m；驅動最大力 0 | 通過 |
| B 零位靜置 2 s | 抽屜：開度 0.0000 m、橫向 0、偏航 90.0°、傾斜 0°。代理物：位移 x −0.005／y +0.001 mm、z 差 +0.001 mm、獨立動態剛體；**讀回線速度 3.26 mm/s（門檻 2）、角速度 0.061 rad/s** | **未過** |
| C 沿 +x 施 3 N、4 s | 開度到 0.2200 m（上限）；橫向 0、z 0、偏航 90.0°、傾斜 0°；放開 1 s 後仍在 0.2200 | 通過 |
| D 反向 3 N、4 s | 回到 0.0000 m（下限） | 通過 |
| E 橫向 3 N、2 s | 開度不變、橫向 0、偏航不變 | 通過 |

- 沒有用瞬移；C／D／E 都是外力作用下的物理滑動。
- B 未過的讀法：代理物 2 s 內位置只變 0.005 mm，但讀回速度 3.3 mm/s、角速度 0.06 rad/s——位置幾乎不動而速度讀值不為零，可能是六角柱在面上的微小晃動或讀值抖動；先前兩房場景的靜置核對（讀回 0.9 mm/s、位移速度 0）用的是同一個門檻。判準沒有改，這項照實記未過，原因未定。
- 另一個觀察：抽屜被拉出 220 mm 時，代理物沿拉出方向移動了 233 mm，**比抽屜多 13 mm**——代理物在抽屜底板上相對滑動了（抽屜到限位急停時往前滑）。3 N 推 2 kg 抽屜到限位的撞擊比機器人拉抽屜劇烈，不能直接當成任務時的滑移量，但說明代理物在抽屜內不是固定的，取物時的位置要靠當次感知。
- 範圍：無機器人、外力作用在抽屜質心；不含夾爪抓拉、不含代理物夾取。
