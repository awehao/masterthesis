## 二、代理物靜置診斷（`evaluation/isaac_m8_house_marker_rest.py`；先登錄後執行；`資料/m8_house_marker_rest_r1/`）

同配置、不施力、3 s 逐物理步記錄。**這是診斷，不取代抽屜接線核對 r1 的 B 項失敗。**

| | 結果 |
|---|---|
| 3 s 淨位移 | x −0.0005 mm、y 0、z +0.0002 mm |
| 位置範圍（3 s 內最大−最小） | x 9.5 µm、y 0.5 µm、z 0.5 µm |
| 位置逐步差分速度 | 各時段中位 0.91 mm/s、最大 0.96 mm/s（來回，不累積） |
| 速度讀回 | 各時段中位 2.1–3.3 mm/s、最大 3.3–3.5 mm/s |
| 角速度 讀回最大／姿態差分最大 | 0.061–0.071／0.017 rad/s |
| 2 s 時刻照原規則 | 位移、z 差通過；讀回速度 0.91 mm/s（這一趟在 2 s 那一步剛好低於 2 mm/s） |

- 代理物在 x 方向（垂直於它的桿軸）以約 9.5 µm 的幅度在兩個位置之間來回跳動，3 s 內沒有淨移動；跳動從第一步就開始、到 3 s 沒有衰減。
- 速度讀回在約 −0.8 與 +3.1～3.3 mm/s 之間交替，所以「某一步的讀回速度」會隨取樣時刻落在門檻兩側：接線核對 r1 在 2 s 讀到 3.26（未過），這一趟在 2 s 讀到 0.91（照原規則會過）。**同一個判準在兩次相同配置下給出不同結果，原因是判準取的是單一步的讀回速度。**
- 讀回速度（約 3 mm/s）比位置差分速度（約 0.9 mm/s）大三倍以上，兩者不一致；哪一個才反映實際運動，現有資料不能定。
- 原因未定：可能是六角柱面接觸的求解抖動。沒有改摩擦、阻尼或門檻。
- 對任務的含意不變：抽屜打開後必須重新感知代理物位置。
