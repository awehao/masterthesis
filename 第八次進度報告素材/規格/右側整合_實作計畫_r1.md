2026-11-11。依 Howard `reviews/20261111_howard_smooth_motion_and_right_side.md` B、Codex `20261111_161442`、`20261111_163931`。速度設定不變、不混入 A0。

## 場景（整場景鏡射，指定右側場景驗證）

- 鏡射軸＝世界 y＝0（起點 (−3.6, 0) 與原障礙方塊 (−2.0, 0) 在軸上）。所有場景物件的**世界座標**套 M＝diag(1, −1, 1) 一次：第一桌、瓶、第二桌、放置目標與放置車道、起點 y／偏航、出口、地圖桌腳。
- 區域座標：RO′＝(RO_x, −RO_y)，區域＝鏡射後世界的平移；控制器仍沿 +x。第一桌在區域 y<0（車道右側），第二桌在放置車道右側。
- 執行端 `isaac_bottle_w1dynsr44.py --mirror-y`；地圖 `bottle_map_write.py --mirror-y`（預設關，舊行為不變）。物理、地圖、掃描、接觸判定、真值安全網同一份幾何。
- 機器人運動學、關節、相機外參、速度命令、安全門檻不鏡射。`--mirror-y` 只決定場景與公開區域先驗，不是抓取側答案。

## 控制端（版本化，左側呼叫逐元素不變）

| 項目 | 做法 |
|---|---|
| 抓取側 grasp_side | 看到前：區域先驗只決定觀看方向。看到後：導引量測 xy 對**預定操作段**（區域車道線，+x）的有號側距；∣距∣ < 0.15 m 判不明、保持。再核預測操作構型下物件在機身右側。綁定目標／車道／計畫版本；接近中改變 ⇒ 舊計畫作廢（本版受控停止並記錄） |
| 放置側 place_side | 由放置目標相對放置車道的幾何決定，與瓶量測無關 |
| 觀察 | 區域觀看點依先驗側取號（`bottle_side.look_point`）；`bottle_view_gen` 已支援 |
| 站位 | `bottle_standoff.evaluate(side)`：右側 y_lane＝y＋y_reach、右側抓取姿態、桌腳取鏡射先驗 |
| 車道 | `bottle_tlane.lane_from_target/decide(side)` |
| 抓取計畫 | 線上請求帶 side（`plan_grasp(side)` 已有） |
| 抓取目標 | `_Tg`、`_gp_poll` 目標核對改經同一 `_grasp_T` hook（預設左側＝原函式） |
| 收近持瓶 | TCP_C 依抓取側取號，**由實際抓持構型重解並核完整過渡**，不把關節取負 |
| 第一桌先驗 | `cc_t1`、收近淨空用鏡射先驗 |
| 候選節點 | 可達檢查等控制端回傳選側（/bottle/grasp_side）；未選側不檢查、不背書；快照帶 side，控制端只收同側 |

## 前置核對（B.5）

兩相機可見性／來源時間、座標與側別一致、全身路徑與切換（TPA／TPAS 右側）、收近過渡、放置、車體／光達／自碰／桌／瓶淨空、現在停與晚一拍停、既有左側回歸（反例與回歸重跑）。之後不動作接線檢查 → 登錄 → 凍結 → 右側名目一趟（Isaac＋2D 疊圖，顯示物件與 TCP 機身側別、生效計畫、速度與停頓原因）。
