# 導航修改紀錄 01：輪級限制器（GUARD）與掃描護盾（Shield）的串接

日期 2026-11-12。依 Howard 指示「該開的開、有瑕疵可以修、修改內容完整紀錄」（`reviews/20261112_howard_navigation_baseline_and_change_log.md`）。
狀態：**離線核對完成；還沒在 Isaac 或假世界全鏈跑過。**

## 1 問題與證據

- 啟動檔 `omni_bot_dynamic.launch.py` 同時設 `GUARD=1`、`SHIELD=1` 時，輪級限制器和護盾**各自直接發布 `/cmd_vel`**（平行發布）。底盤收到的是兩個來源交錯的命令，哪一層說了算不確定。這是讀啟動檔發現的（Codex 20261112_144755 指出），沒有實跑紀錄。
- 單純改成前後串接也不夠。用兩個節點的真函式做離線閉迴路（`evaluation/nav_guard_shield_chain_check.py`，300 個隨機場景、每種 72,000 拍）：

| 串接 | 最終命令違反輪速／輪加速度（拍） | 最終命令仍在靠近近距障礙（拍；最大靠近速度） | 限制器「卡住上一筆命令」（拍） | 撞到靜態物的場景數 |
|---|---|---|---|---|
| A 護盾→限制器（上游命令刻意不合輪速） | 0／0 | 1221（0.257 m/s） | 33,674 | 5／300 |
| A 護盾→限制器（上游合輪速、含移動物） | 0／0 | 120（0.108 m/s） | 2,747 | 0 |
| B 限制器→護盾（上游刻意不合輪速） | 2057／41 | 0 | — | 0 |
| B 限制器→護盾（上游合輪速、含移動物） | 1761／42 | 0 | — | 0 |

- A 的問題：護盾的輸出不一定在四輪的可行集合內；限制器用「上一筆→目標」的線段縮放，碰到貼邊又朝外的輪子時縮放量變 0，等於**原樣保持上一筆命令**——護盾叫它煞車，它沒煞。
- B 的問題：護盾最後才改命令，改出來的命令會超過輪級限制，也違反「限制器是 `/cmd_vel` 唯一發布者」的既有裁決（`evaluation/results/design_wheel_limit_chain.md` 第 7 節）。
- 原因以外還沒確認的：這些數字來自運動學閉迴路與刻意刁難的上游命令，不是實際 GMPC 輸出；實際導航中發生頻率未知。

## 3 設計理由

- 兩層要同時成立，就得有一個點同時看得到兩組限制。護盾本來就是做投影的，把輪級列放進同一個投影集合，輸出就同時滿足「不靠近」與「輪級限制」；下游限制器不必再改它，只是把關並維持唯一發布者。
- 內縮 0.002 m/s 的理由：護盾投影的收斂容差是 1e-3，不內縮時輸出可能落在限制器集合外不到 1e-3，而限制器對這種情況會整筆卡住。不內縮的版本實測還有 82 拍靠近違反（1,573 拍卡住）；內縮後為 0。
- 屬一般缺陷修正（接線＋兩層集合不一致），不改變方法或適用範圍。

## 5 結果與限制

- 解決了：平行發布；串接後最終命令在離線核對中同時滿足輪級限制與「不靠近」。
- 沒解決／代價：
  - 「完整屏障」（不只是不靠近，還要保持停止距離）的殘差在 C 與 B 同量級（含移動物時約 5% 的拍），這是護盾原本就有的退讓行為（被移動物逼近時做不到完整屏障，退到「不靠近」），不是這次修改造成，也沒有因此變好。
  - 輪速上限少 0.7%（內縮）。
  - 護盾每拍計算量增加（列數＋迭代上限），耗時未量。
  - 護盾的輪加速度列以「自己上一筆輸出」為基準；若限制器曾改動輸出，兩者基準會差一拍。離線核對中限制器改動 0 拍；實跑要從 `/wheel_guard/status` 的 λ 確認。
- 未驗證：ROS 節點實際接線（話題、時序、QoS）、Isaac、真實 GMPC 命令、住宅場景半徑（`SHIELD_RADIUS`）、掃描延遲。

## 第 4、5 節的更正

- 第 5 節寫「完整屏障殘差未變好也未變壞」**不成立**，撤回。離線數字是：刁難上游 C 違反 8,297 拍、B 2,376 拍；可行上游 C 3,575 拍、B 2,571 拍。三種串接的閉迴路軌跡不同，不能互相歸因。
- 第 4 節只列了「靜態碰撞 0」。同一組離線結果裡，**與移動物重疊的場景**也要列：C 在可行上游組為 111／300。這個離線測試的移動物是直直朝機器人走來的圓柱，機器人被上游命令逼著朝障礙走；護盾只保證「自己不再靠近」，不會主動逃開。所以不能用這份離線結果說整體安全通過。
- 離線腳本的殘差是用「最終命令」重算停止距離，和護盾當拍實際建立的列（用輸入命令算）不是同一組條件。下面的真節點結果改用護盾自己回報的殘差（對它當拍的列）。
