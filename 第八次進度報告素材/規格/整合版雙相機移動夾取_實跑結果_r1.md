## 四、可以說與不能說

- 可說：新版雙相機／站位／航向／相位協調下，**無移動物的移動抓放完整成功（nom_3，n＝1）**；起步到閉爪的接近段底盤在本量測口徑下未停（原始速度最低 0.056 m/s）。
- 「接近未停」只限起步→閉爪；不擴寫成整段抓取到離桌完全不停（A_2 在切換→離桌確立之間有 0.05 s 低於 0.01 m/s）。
- 可說：固定 A 行人交會下，**含移動物的移動抓放流程完成（A_2，n＝1），但抓持品質依判準不合格**。
- 不能說：動態移動夾取成功；接觸中／閉爪中動態閃避已驗證（交互在接近段 12–20 s，INSERT 23.9 s 才開始）；整體提速（相位策略與有效期政策同時變更）；即時部署（倍率 0.4，求解控制拍 p95 49–56 ms、最大 195–237 ms）。
- 名目與 A 的站位不同（0.40 vs 0.36），耗時與滑移差異不能全部歸因於行人。

## 五、A_2 滑移只讀分析（`evaluation/slip_readonly_analysis.py` → `results/bottle/slip_readonly_r1.json`）

沿用判定器的抓持基準（t_grasp 時的 TCP→瓶相對位姿），不排除 LOWER、不重設零點；重算值與報告一致（A_2 5.0126 mm、nom_3 0.8684 mm）。

| 段 | A_2 滑移（段初→段末，mm） | nom_3 |
|---|---|---|
| 抓持→離桌 | 0 → 0.63 | 0 → 0.005 |
| 離桌→PARKED（運送） | 0.63 → 3.68 | 0.005 → 0.56 |
| PARKED→支撐判定成立（LOWER 中、支撐判定成立前） | 3.68 → 5.01（52.63 s 越過 5 mm） | 0.56 → 0.75 |
| 支撐判定成立→鬆爪 | 5.01 → 5.00 | 0.75 → 0.73 |

- A_2 的滑移方向主要是 TCP −x，從離桌起即持續爬升（底盤只有 0.05 m/s 時也在增加），放置停車後底盤靜止的 LOWER 期間仍以約 0.3–0.4 mm/s 增加；超標發生在 LOWER 中、支撐判定成立（52.73 s）之前。
- 「支撐判定成立」＝放置判定器量到瓶對第二桌支撐力 fz > 0.5 N 的時刻，不等同物理上第一次接觸；52.63 s 已接近下降末尾。
- nom_3 運送段幾乎不動，只在 42–43 s 減速時跳約 0.5 mm。
- 兩趟指力相近（約 2.2–2.5 N）。
- **成因未定**：不能只歸因於 LOWER，也不能排除抓持姿態（站位 0.36）或先前動態的影響；分支的關節限位餘裕（0.357）不能當作抓持穩定性指標。本包不加診斷趟、不調夾力或摩擦，滑移追查暫停。
