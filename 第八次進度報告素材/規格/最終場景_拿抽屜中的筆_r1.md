## 1　任務流程

```
S（A 房起點）
 → 導航：A 房內有未知靜態箱體與行人
 → 門（關閉、向 A 房開）：找把手 → 拉開 → 通過
 → 導航：B 房（書房）內有未知箱體與行人
 → 找櫃子與抽屜把手 → 開抽屜
 → 找抽屜內的筆 → 抓筆、取出
 → （關抽屜：待定）
 → 返程：B 側推門 → 通過 →（關門：待定）
 → 回 S 交付筆
```

## 4　保留什麼、換掉什麼

保留：GMPC 全身控制、手臂執行模型、導航 CBF＋Shield、已驗證的抓持與接觸監看。
換掉（物件相關的預設答案）：

1. 把手、筆的精確位置 → 當次視覺定位。
2. 固定停位、固定展臂與轉向時機 → 依量測目標、當下構型與障礙在線算。
3. 段間停車重啟 → 承接狀態連續交接。
4. 依腳本時刻認定完成 → 依觀測與接觸證據。

## 5　要先定的決策

1. **筆的尺寸**：(a) 用粗馬克筆代理（直徑約 20–26 mm，夾得住），揭露不是一般原子筆；(b) 換更適合細物的指形或夾爪；(c) 其他。我建議 (a)，理由是 10 mm 已確認夾不住，換夾爪會牽動已驗證的接觸設定。
2. **門把手視覺**：目前沒有門把手的視覺模型（瓶子模型不能直接用）。用既有抽屜把手的幾何法（D1／DL3 路線）延伸，或另訓練。
3. **筆的視覺**：同上，抽屜內（俯視、近距、背景單純）。
4. 去程是否關門、取筆後是否關抽屜、返程是否關門。
5. 動態物數量與配置：沿用 seed1 r2（A 房 2 人、B 房 1 人，加未知箱體）或重抽。

## 6　實作順序（照 Codex 面板建議）

1. 固定最終場景：筆放進抽屜、障礙與行人接進同一世界與掃描鏈；之後都在這個場景累積，不再換展示場景。
2. 視覺定位 → 全身操作：先門，再抽屜。確認目標來自感知，不是場景生成座標。
3. 串成完整任務並加入動態交互：先導航與運送中的動態障礙，再研究接觸操作期間的干擾，兩者分開驗收。
4. 抽屜內取筆並返回。

瓶子「先看見再生成接近計畫」那包（Codex 151057／175227）只當技術前置：它驗的是「觀測後才產生物件相關的接近計畫」，不能代替取筆任務。
