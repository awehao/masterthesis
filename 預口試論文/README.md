## 建議修訂順序

1. 先修第一章 1.1、1.2，確認研究問題、目的、範圍及貢獻。
2. 補第二章的平台、設備與介面，固定各結果對應的版本。
3. 深化第三章推導及基線，再完成第四章既有批次的表圖與分析。
4. 依方法及實驗需要擴充第一章 1.3，重新檢查研究缺口。
5. 同步更新第五章與摘要；現階段持續使用 Markdown。

## 共用寫作規則

- 每個結果標明平台、版本、情境、樣本數與時間來源，不將不同批次合併成功率。
- 含接觸的物理模擬仍稱物理模擬；完成、品質、安全與耗時分開判定。
- 導航 A、抽屜 B 與後續全身 C 的實際啟用模組分開，不能混用歷史最佳結果。
- 感知、場景先驗、控制所用真值與事後評估真值分開揭露。
- 模擬時間、牆鐘、QP 與整拍耗時分別呈現；影片速度不作即時部署證據。
- 本次重整沿用既有數據，沒有執行新實驗。數值來源及核對層級見 E01–E10。

題目依近期報告與研究定位沿用；根目錄較早的 `題目.md` 另有歷史名稱。正式封面仍需與指導教授確認，章節重整不等於更改研究題目。
