## system_control_architecture

- 建議位置：第二章 2.4「導航、視覺與操作之系統整合」開頭。
- 圖說：導航、視覺與操作之整體控制架構設計。
- 性質：本文之系統整合設計，呈現全身控制的目標架構，不據此宣稱所有歷史實驗或完整住宅任務已使用並驗證同一控制鏈。
- 資料流：雷射至障礙資訊；RGB-D 至視覺目標，與地圖及任務資訊共同形成參考；障礙資訊與任務參考輸入全身控制。控制器區分協同預測模型與共同最佳化問題，再經底盤及手臂各自的命令介面作用於移動機械臂。
- 狀態與執行資訊模組彙整模擬器回授及執行介面的命令紀錄，包含底盤位姿、關節、設定點、實際命令與在途命令；在途命令來自命令紀錄，並非由機器人感測器量測。
- 原始掃描另直接提供底盤命令處理中的防護，不經障礙分類與追蹤後才送入。
- 依據：`預口試論文/overleaf/02_software_and_integration.tex`、`預口試論文/論文章節架構.md`、`src/ammr_wholebody_mpc/ammr_wholebody_mpc/gmpc_wb.py`、`evaluation/bottle_seg3d_candidates_dual_node.py`。

## navigation_architecture

- 建議位置：第二章 2.4.1「全域路徑規劃與導航參考」。
- 圖說：底盤幾何模型預測導航架構。
- 性質：底盤導航與命令執行之功能架構，繪出速度平滑、原始掃描防護與輪級限制均啟用時的串接。各實驗實際啟用項目仍依其實驗配置說明。
- 已核對順序：GMPC → 速度平滑器 → 近距離安全層 → 輪級命令限制器 → 底盤執行。
- 「路徑規劃與參考生成」為功能分組：Nav2 提供全域路徑，控制端另進行路徑取樣與航向參考生成，不表示這些步驟全由 Nav2 執行。
- 定位模組的 AMCL＋EKF 與雷射感知細節承接前期 Gazebo 導航配置；本圖不宣稱所有 Isaac 實驗使用同一定位來源。正文與第四章仍依實際實驗配置說明。
- 原始雷射至防護層的支路直接取原始量測；障礙估測與預測模組包含掃描前處理、群集、追蹤、動靜分流及運動預測。
- 最終命令回授至安全層，用於其輪級條件建立；下方主要回路則呈現底盤運動、里程計及定位回授。為維持圖面可讀性，地圖、雷射至定位等次要依賴以模組內文字表達。
- 依據：`第一階段實作總結.md`、`第八次進度報告素材/規格/導航修改紀錄_GUARD與Shield串接_r1.md`、`src/my_omnibot_description/launch/omni_bot_dynamic.launch.py`、`src/ammr_wholebody_mpc/ammr_wholebody_mpc/gmpc_node_m8.py`、`src/ammr_wholebody_mpc/ammr_wholebody_mpc/scan_safety_shield.py`。
- 圖中以功能模組呈現，不表示防護層提供無條件避碰保證，也不將模擬模型視為實機驗證。

## 圖形與字型

- 黑線、白底，無彩色或灰色填色；主控制器外框略粗，內部子模組使用較細外框。
- 實線：量測、參考及命令資料流。虛線：狀態與執行資訊回授。原始雷射支路採實線，表示感測資料直接提供予防護層。
- 圖內不放大型標題；圖名由 LaTeX 圖說提供。
- 圖中文字使用學姐模板所附的 `fonts/kaiu.ttf`，已核對字型名稱為「標楷體／DFKai-SB」，不以其他楷體替代。標題沿用相同字形並略加粗筆畫；PDF 嵌入所用字型子集，SVG 保留字形輪廓。
- 重新繪製時，程式預設讀取本專案的 `fonts/kaiu.ttf`；若移動程式位置，可由環境變數 `THESIS_KAIU_FONT` 指定同一標楷體字型檔。圖檔包不另外附上原始字型檔，使用 PDF 無須安裝字型。
- 原生繪圖來源：`draw_architecture.py`。修改標籤或模組配置後可重新產生 PDF、SVG 與 PNG。
- Overleaf 使用 PDF；SVG 及 Python 原稿供後續編修。
- `第二章_插圖片段.tex` 與 `第二章_架構圖插入.tex` 均已更新為這兩張架構圖，內容相同，擇一複製。整體控制架構圖放在 2.4 開頭；導航架構圖放在 2.4.1。
