# 第三章開頭與 3.1

本稿依 `論文章節架構.md` 中的第三章安排，包含章導言、座標與位姿定義、底盤 SE(2) 誤差模型、正向運動學與全身幾何雅可比。接續第二章貼入學姐專案；若已有同名章標題，只保留一份 `\chapter`。3.2 及之後各節隨後續撰寫接入。

章名調整為「研究方法與全身模型預測控制器設計」，導言先交代幾何預測基礎、控制器輸入及底盤與手臂命令輸出，再說明各節安排。3.1 的編號、公式及符號定義沿用原稿。

## 符號與實作對應

- 世界座標 `W`、底盤平面座標 `B`、手臂基座 `A`、工具中心點 `E`。底盤平面基準原點的高度為零，底盤高度及固定安裝偏移納入 `B` 至 `A` 的固定變換。
- `X_B` 是 3×3 平面位姿；`{}^{W}T_B` 是其 4×4 三維嵌入；避免混用兩者維度。
- 底盤輸入順序為 `(v_x^B, v_y^B, omega_B)`，採本體座標。`se2.py` 使用 `dot X=X hat(xi)`、`E=X_ref^{-1}X` 與 `e=log(E)^vee`。
- 本稿定義 `ad(xi) eta=[hat(xi),hat(eta)]^vee`。因此誤差線性化矩陣為 `-ad(xi_ref)`，與程式一致。Tang 原文將此矩陣記為 `adm`；不可不說明慣例就將兩個符號的矩陣正負號互換。
- `wholebody_kinematics.py` 的 `jacobian` 是世界座標幾何雅可比，對應 `(dot x_B, dot y_B, dot theta_B, dot q_a)`。本文透過 `diag(R_B,1,I_6)` 轉為底盤本體速度與實際關節速度輸入。
- 末端六維速度排列為 `[TCP 原點的線速度；末端角速度]`，不是將空間旋量的平移分量直接當成 TCP 線速度。
- 實際關節速度 `dot q_a` 與設定點變化率 `u_a` 分開；執行模型留至 3.2，未在本節假設兩者相等。

## 程式來源

- `src/ammr_wholebody_mpc/ammr_wholebody_mpc/se2.py`：`hat`、`ad`、`geodesic_error`。
- `src/ammr_wholebody_mpc/ammr_wholebody_mpc/gmpc.py`：逐預測步的 `I-dt*ad(xi_ref)` 誤差模型。
- `src/ammr_wholebody_mpc/ammr_wholebody_mpc/gmpc_wb.py`：`FastChain.fk_jac`、末端成本中的 `_pose_jac` 與 `Gamma` 映射。
- `src/ammr_wholebody_mpc/ammr_wholebody_mpc/wholebody_kinematics.py`：`fk`、`jacobian`。
- `evaluation/models/omni_bot_wholebody_expanded.urdf`：本輪數值檢查的運動鏈；不作各次實驗皆使用相同模型版本的證據。

## 查核

以既有展開模型抽樣 32 個構型，核對本文底盤雅可比與廣義座標轉換，並以獨立正向運動學中央差分檢查線速度與世界角速度。雅可比最大元素誤差分別約為 `3.71e-10` 及 `2.55e-10`。此為數學與程式表示的核對，不是動態模型、閉迴路任務或實機效果驗證。

另外，以群上的精確定速演進計算局部誤差微分，擾動幅度連續減半時，線性化殘差約下降至四分之一，符合所忽略之二階項。數值結果見 `第三章_3.1核對紀錄.json`。
