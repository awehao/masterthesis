# 第三章 3.3 初稿

`03_03_objective_constraints.tex` 接在 3.2 後方，依既定架構包含四小節、14 個自動編號公式。本文先建立底盤／末端追蹤、輸入正則化與一階命令差分的基本問題；障礙、鬆弛與操作幾何條件由後續各節擴充。不將各次歷史實驗的成本或求解策略視為完全一致。

## 與實作對應

- `gmpc_wb.py` 的 `_build_Q_bar`、`_build_smoothness_terms`：底盤終端權重與包含參考速度變化的完整命令差分。
- `gmpc_wb.py` 的 active-arm 成本：世界座標末端位置差及旋轉殘差、`_pose_jac`、`FastChain.fk_jac`、`Mq`，以及手臂輸入與差分權重。
- 本節用 `R_xi` 表示底盤輸入權重，避免與 3.1 的平面旋轉矩陣 `R_B(theta)` 混淆。
- 末端局部映射為 `[J_chi,B C, J_chi,A, 0]`。幾何誤差須經 `C` 轉換為底盤平面位姿座標擾動，不能直接將本體速度雅可比套在誤差狀態上。
- 姿態部分明確採用小誤差近似；不把幾何雅可比宣稱為任意非零旋轉誤差下的精確殘差導數。
- 世界座標末端目標可形成底盤／手臂的成本交叉項。底盤相對持物目標另行定義，不宣稱每個任務的交叉項皆非零。
- `_build_constraints`、`wheel_matrix`：底盤速度、命令差分、輪速及輪速命令差分。第一步差分對應預測起點之前的生效命令。
- active-arm 的 `Mq`、`Ms` 限制：預測實際關節位置與設定點分開限位。`v_arm`、`a_arm` 約束設定點命令，未將其直接當成實測關節速度與加速度。
- 耦合問題的預設求解路徑為 `qp_dual_active`，未取得合格解再走 OSQP；未將 OSQP 描述為全部模式唯一的求解器。
- 作用集法內的 `qp_kkt_check`，及 active-arm 外層的限制殘差、有限值與 `seq_consistent` 核對。保持、減速、逾時及在途命令留至 3.7。
