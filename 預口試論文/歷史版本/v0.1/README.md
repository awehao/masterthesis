預口試目前可建立的主線是：**以預測導航與原始掃描保護處理動態接近，再以包含手臂執行模型的全身預測控制協調操作，檢驗安全、追蹤品質與任務效率之間的取捨。**

住宅中的「開門、通過、開抽屜、取粗馬克筆代理物、返回」是整合目標。目前住宅格局已建立，門把手已有局部非接觸接近案例；這些與完整任務成功分別陳述。

## 建議寫作順序

1. 先修第一章，讓研究問題與可驗證目標收斂。
2. 整理第三章核心方法，逐一對照實際啟用的控制版本。
3. 把第四章已有的正式批次寫完整，包含不利結果與限制。
4. 依第三章方法及第四章比較項目補第二章，避免文獻與研究主線脫節。
5. 更新第五章與中英文摘要，再套用學校論文格式。

這是寫作順序，不代表後續實驗必須等全部章節寫完才進行。

## 共用寫作規則

- 每個結果標明平台、版本、情境、樣本數與時間來源；不同批次不合併成單一成功率。
- 模擬器含接觸的物理模擬仍稱「物理模擬」，不寫成實機實驗。
- 流程完成與原品質判準合格分開；不因接近完成而放寬滑移門檻。
- 感知輸入、場景先驗、控制使用的模擬真值、事後評估真值分開交代。
- 導航 GMPC、既有抽屜 W-GMPC、後續導航擴充全身 GMPC 分別標示；不將所有歷史批次都描述成最新架構。
- 計算時間與模擬時間分開；影片播放速度不作為即時部署證據。
- 本版引用 E01–E10 的來源見證據索引。數字已核對既有彙整，部分另對照原始結果檔；尚未重新分析全部 bag、影格或完整幾何軌跡。
