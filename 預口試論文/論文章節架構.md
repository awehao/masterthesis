# 碩士計畫書章節架構

架構版本：v0.5（2026-11-21）。

本檔整理預口試計畫書的五章目錄，細分至「章、節、小節」三層（例如 3、3.1、3.1.1），供後續完成論文時延續使用。「問題定義與基本假設」置於第二章；第三章以幾何預測、增廣執行模型與全身協同最佳化為核心，章末收束為整體控制流程。

本版保留五章結構，將 1.2.3 改為「研究目的與預期貢獻」，3.7 改為「執行動態補償與控制實現」，並新增 3.7.4「整體控制流程與演算法」。住宅整合任務以開門、穿門、茶几取物及持物返回為主線；抽屜保留於 4.4 的協同控制比較。

這是章節規劃稿，不表示各節已完成撰寫或實驗；現有分章 Markdown 初稿尚未同步重編。第四章依實際結果呈現成功與失敗案例，不將尚未完成的任務預設為成功，也不將既有版本的比較實驗視為最新版整合系統的直接驗證。

## 檔案放置與使用方式

- 完整目錄規劃：本檔 `預口試論文/論文章節架構.md`。
- LaTeX 章節骨架：[overleaf/chapters_outline.tex](overleaf/chapters_outline.tex)，含完整五章的 `\chapter`、`\section`、`\subsection`，尚無正文。
- Overleaf 編譯入口：[overleaf/main.tex](overleaf/main.tex)，由它載入 [overleaf/thesis.tex](overleaf/thesis.tex)。
- 本次未更動摘要、既有分章正文、LaTeX 主檔或既有 ZIP 上傳包。

若要在 Overleaf 產生目錄，先上傳 `chapters_outline.tex` 至與 `thesis.tex` 相同的目錄，將 `thesis.tex` 中從 `\input{00_abstract}` 到原本註解的正文載入區塊替換為：

```tex
\input{00_abstract}

% 致謝暫時關閉；之後有該檔案再啟用。
% \input{00_acknowledgements}

% book 類別中，2 表示顯示與編號到 subsection（例如 3.1.1）。
\setcounter{tocdepth}{2}
\setcounter{secnumdepth}{2}
\tableofcontents

% 有圖、表後再啟用。
% \listoffigures
% \listoftables

\mainmatter
% 沿用原主檔規劃：正文切回雙面排版。
\makeatletter
\@twosidetrue
\@mparswitchtrue
\makeatother

\input{chapters_outline}
```

保留原本的 `\end{document}`，不要重複加入 `\documentclass` 或 `\begin{document}`。編譯器維持 XeLaTeX；目錄通常需兩輪編譯才會更新完整。

章節名稱與頁碼由 LaTeX 自動產生，不要手動把編號寫進章節標題。這份骨架只有標題，現階段產生的頁碼不是正文完成後的正式頁碼；填入正文後會自動更新。正式轉為分章檔時，應以分章載入取代 `\input{chapters_outline}`，避免重複章節。

## 章節分工與寫作界線

- 第一章：說明研究背景、問題動機、相關研究與研究定位；1.2.3 明列研究目的與預期貢獻，與方法及實驗對應。
- 第二章：交代平台、介面、系統組成、問題定義、假設與研究範圍。
- 第三章：3.2 推導增廣預測模型，3.3 建立基本最佳化形式；3.4–3.6 展開避障限制、視覺參考與物件操作。3.7 說明延遲及偏置補償與控制實現，3.7.4 以完整控制流程圖及偽程式串起觀測更新、狀態與在途命令、參考及限制組裝、求解、命令處理與回授。
- 第四章：依研究目的評估預測誤差、追蹤品質、任務完成與時間成本。4.4 以抽屜操作作為預測時域與移動／停駐策略比較案例；4.5 集中於開門、穿門、茶几取物及持物返回。已有結果與規劃中的驗證分別說明，並標明不同版本、平台與測試條件。
- 第五章：總結已獲證據支持的貢獻與後續工作，不新增未經驗證的成果主張。
- 單一控制器：以同一全身控制器延續狀態、更新任務目標與約束為設計主線。2.4.3 用架構圖區分感知、任務參考、全身求解與命令執行的介面；3.6.3 說明任務切換時目標、約束及預測狀態如何更新或延續；3.7.1 說明求解輸入與實際放行命令的銜接。各階段的實際啟用方式由對應版本與實驗交代。
- 移動中操作：僅對實際在移動中完成的操作使用此名稱；移動接近後停駐抓取須明確區分。
- 實機適用性：位置命令與增廣模型可以作為實機部署的研究方向；模擬辨識參數、固定命令延遲與理想抓持假設不直接視為實機已驗證。
